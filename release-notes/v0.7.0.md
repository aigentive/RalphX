# RalphX.app v0.7.0

RalphX.app 0.7.0 focuses on managed agent model selection, Codex model/effort routing, and more reliable merge-scope retry recovery.

## User-Facing Changes
- **Agents runtime selection** now keeps provider, model, and reasoning effort in one grouped selector with Provider, Model, and Effort sections; model-specific effort choices avoid invalid combinations such as Codex `max` while keeping Claude `max` distinct from `xhigh`. [0b67185d](https://github.com/aigentive/ralphx.app/commit/0b67185d75d0e2d2157d4059cfa26978ffd2564f)
- **Settings / Models** now exposes built-in models plus persistent custom provider/model entries with labels, allowed efforts, default effort, and enabled state; custom future model IDs can also be typed directly from the Agents selector. [0b67185d](https://github.com/aigentive/ralphx.app/commit/0b67185d75d0e2d2157d4059cfa26978ffd2564f)
- **Agent and lane runtime preferences** now use the same managed registry shape, so saved preferences without an effort receive a model-specific default and project-agent starts/follow-ups send normalized provider, model, and effort values. [0b67185d](https://github.com/aigentive/ralphx.app/commit/0b67185d75d0e2d2157d4059cfa26978ffd2564f)
- **Codex model presentation and launch routing** now align with the registry-supported Codex model family, including cleaner labels for supported Codex models and launch coverage that preserves selected `gpt-5.5` plus supported reasoning efforts. [f9667f57](https://github.com/aigentive/ralphx.app/commit/f9667f576de8e5ed31c402b20fd2f5d3e83fca31)

## Fixes And Polish
- **Merge retry recovery** now reroutes `MergeIncomplete` retries with out-of-scope drift into `RevisionNeeded` re-execution instead of accepting the retry and immediately falling back to `MergeIncomplete` again. [8c8e5e2b](https://github.com/aigentive/ralphx.app/commit/8c8e5e2b375e736abbd457d01813cde979a56d32)

## Developer And Maintainer Changes

- Refreshes Settings visual snapshots and regression coverage for model registry behavior, effort normalization, lane resolution, custom model persistence, and Codex launch arguments.
