# RalphX.app v0.35.0

RalphX.app 0.35.0 focuses on Plan-mode agent chat, plan/artifact workflow visibility, and project-level PR automation defaults.

## User-Facing Changes
- **Agent chat now routes broad Chat/Edit requests into Plan mode** when planning is useful before implementation, with explicit prompt gating and a dedicated plan profile for ideation sessions. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
- **Plan-aware conversations now surface planning context directly in the UI**, including plan artifacts, attached ideation sessions, plan display/editing, and plan-related actions such as plan verification. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
- **Agent question prompts are now treated as durable workflow state**, making ask-user-question flows behave as first-class conversation interactions instead of scattered special cases. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
- **Project-level defaults for new agent conversations now cover PR automation**, including `Autofix CI & Reviews` and `GitHub auto-merge`, so new workspaces can inherit the project’s preferred execution behavior. [f883abf2](https://github.com/aigentive/ralphx.app/commit/f883abf2f04d84912b0897264ec39cbe05774953)

## Fixes And Polish
- **Plan-mode chat controls were refined** and the plan agent was registered in the roster guard so plan conversations are available through the intended agent surfaces. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
- **PR automation setting help is easier to reach**: the Agents publish panel reuses the same explanatory tooltip copy as Settings, and those tooltips can open the Execution settings section directly. [f883abf2](https://github.com/aigentive/ralphx.app/commit/f883abf2f04d84912b0897264ec39cbe05774953)

## Developer And Maintainer Changes
- Expanded backend, MCP, prompt, and frontend plumbing for plan artifacts, question state, plan complexity, plan-mode command/HTTP surfaces, and conversation-level plan ownership. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
- Threaded the new PR automation defaults through config, settings schemas, API transforms, persistence, workspace/bootstrap paths, and SQLite migration coverage. [f883abf2](https://github.com/aigentive/ralphx.app/commit/f883abf2f04d84912b0897264ec39cbe05774953)
- Updated coverage reporting so Codecov patch coverage focuses on explicit Rust, frontend, and plugin coverage records instead of composition-heavy orchestration scaffolding. [4452b6f6](https://github.com/aigentive/ralphx.app/commit/4452b6f60c8565262d1359c2f63884ccecf77b34)
