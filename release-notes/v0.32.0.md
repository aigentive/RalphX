# RalphX.app v0.32.0

RalphX.app 0.32.0 improves workspace PR automation controls, long-running operation progress, and update release-note display.

## User-Facing Changes
- **Agent workspace publishing** now has a persisted **Auto Publish** gate for workspaces with an existing PR; pausing it stops automatic committing/publishing, disables dependent PR automation switches, and leaves manual **Commit & Publish** available. [cb32b172](https://github.com/aigentive/ralphx.app/commit/cb32b172c2713a967cd9edc2d92872fbcb9c7316)
- **Publish-panel automation controls** are clearer, with shorter labels and info tooltips for **Auto Publish**, **Autofix CI & Reviews**, and **GitHub auto-merge**. [cb32b172](https://github.com/aigentive/ralphx.app/commit/cb32b172c2713a967cd9edc2d92872fbcb9c7316)
- **Update from base** and **Rebase branch** now use persistent progress toasts with elapsed status instead of blocking progress dialogs, so long-running branch operations keep visible feedback without leaving the modal disabled. [367a283b](https://github.com/aigentive/ralphx.app/commit/367a283b5b5addbc032e157d6bdaf99d00f057b3)
- **Commit & Publish** now mirrors publish pipeline progress into a toast while preserving the existing publish dialog flow. [367a283b](https://github.com/aigentive/ralphx.app/commit/367a283b5b5addbc032e157d6bdaf99d00f057b3)

## Fixes And Polish
- **Update Available toast release notes** now open the new version’s notes even when the local release index has not caught up yet. [099025f9](https://github.com/aigentive/ralphx.app/commit/099025f90912a64f74d0a0bc36585ddfe524a008)

## Developer And Maintainer Changes
- Adds persisted workspace state, migration, command/API plumbing, and backend enforcement for the Auto Publish gate across background publish, stale-base scanning, PR autofix routing, and merge-related automation. [cb32b172](https://github.com/aigentive/ralphx.app/commit/cb32b172c2713a967cd9edc2d92872fbcb9c7316)
- Adds regression coverage for stale update-metadata release notes and toast-backed publish progress behavior. [099025f9](https://github.com/aigentive/ralphx.app/commit/099025f90912a64f74d0a0bc36585ddfe524a008) [367a283b](https://github.com/aigentive/ralphx.app/commit/367a283b5b5addbc032e157d6bdaf99d00f057b3)
