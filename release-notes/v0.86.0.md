# RalphX.app v0.86.0

RalphX.app 0.86.0 delivers feature-gated Team collaboration, duplicate-free live chat with reasoning views, and database/log-space maintenance.

## User-Facing Changes
- **Team mode (feature-gated; off by default):** enables durable, named teammates that retain delegated context between assignments. The lazy Team tab shows the roster, shared task board, activity, usage, and member controls, while the composer can target the coordinator, a broadcast, or a member by name. [72c7435a](https://github.com/aigentive/ralphx.app/commit/72c7435a31d977cb6dcb1c020b4574f8e20ea56d)
- **Team safeguards and lifecycle:** delivers attributed messages with coordinator wake-ups, prevents overlapping write scopes, reports per-member usage, and provides explicit **Suspend Team** and **Drain and Close** actions; state recovers after restart without automatically resuming write work. [72c7435a](https://github.com/aigentive/ralphx.app/commit/72c7435a31d977cb6dcb1c020b4574f8e20ea56d)
- **Live chat:** fixes duplicate assistant bubbles during active responses and renders assistant text incrementally instead of waiting for the full message. [536db79c](https://github.com/aigentive/ralphx.app/commit/536db79cd480c1b1d2816af6109f17c8386ccba8)
- **Reasoning visibility:** shows thinking and Codex reasoning in collapsible, scrollable groups with duration indicators, preserving detail without crowding the transcript. [536db79c](https://github.com/aigentive/ralphx.app/commit/536db79cd480c1b1d2816af6109f17c8386ccba8)
- **Database maintenance:** adds a Settings section for scheduling one-time SQLite compaction before the next launch, with backup and disk-headroom checks; retention also trims older full raw tool payloads. [6576ce93](https://github.com/aigentive/ralphx.app/commit/6576ce93471f8640e3bfeeb996d910d1fcf11490)

## Fixes And Polish
- **PR autofix:** accepts a repair as fixed only after verifying a new repair-head commit; transient GitHub Actions failures can re-run the failed job automatically, and base-update retries now show a **Repair started** confirmation. [51cef369](https://github.com/aigentive/ralphx.app/commit/51cef369cfaa1c4e6b37d35cbdfb07902a1e89b5)
- **Startup diagnostics:** shows actionable guidance to free disk space when a database migration cannot proceed. [536db79c](https://github.com/aigentive/ralphx.app/commit/536db79cd480c1b1d2816af6109f17c8386ccba8)
- **Log handling:** stops a sidebar-polling log flood, caps each launch log at 1 GB, and prunes previous launch logs at startup, retaining five by default. [6576ce93](https://github.com/aigentive/ralphx.app/commit/6576ce93471f8640e3bfeeb996d910d1fcf11490)
- **Settings layout:** removes redundant section cards and duplicate headings across all 26 settings sections, leaving each page with a single authoritative heading and direct content rows. [e4c8a987](https://github.com/aigentive/ralphx.app/commit/e4c8a9875ae6f87c2ad17a5ed11095b3739415b8)

## Developer And Maintainer Changes
- **Team-agent integrations:** coordinator and member tool surfaces now cover roster management, assignment, messaging, and lifecycle control, while models address teammates by name rather than internal identifiers. [72c7435a](https://github.com/aigentive/ralphx.app/commit/72c7435a31d977cb6dcb1c020b4574f8e20ea56d)
- **PR-fixer contract:** repair completion now requires a typed resolution—`fixed`, `transient_ci`, `pre_existing_on_base`, or `needs_human`—with dispatch-time evidence used to validate reported fixes. [51cef369](https://github.com/aigentive/ralphx.app/commit/51cef369cfaa1c4e6b37d35cbdfb07902a1e89b5)

## Known Issues
- Team members currently use a shared workspace; separate member worktrees are not included in this release. [72c7435a](https://github.com/aigentive/ralphx.app/commit/72c7435a31d977cb6dcb1c020b4574f8e20ea56d)
- A thinking group opened for the latest reasoning remains open after it settles until manually collapsed. [536db79c](https://github.com/aigentive/ralphx.app/commit/536db79cd480c1b1d2816af6109f17c8386ccba8)
