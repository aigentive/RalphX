# RalphX.app v0.18.0

RalphX.app 0.18.0 focuses on PR annotation visibility, preserved publish diffs, and read-only historical review flows.

## User-Facing Changes
- Agents Commit & Publish diff viewers now surface GitHub PR annotations alongside diff content, including review comments, check-run annotations, and CodeQL/code-scanning alerts, with per-row GitHub links when available. [3b78900a](https://github.com/aigentive/ralphx.app/commit/3b78900a482f7426cb2b0387506395830d453cb5)
- Historical Agents conversations keep their inline publish diff list after a PR has been opened or reached a terminal state, so users can reopen an old conversation and inspect the published changes. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)
- Review diffs now fall back to read-only historical sources when the original workspace is gone, using the active worktree first, then a fetched PR-head ref, then a stored GitHub PR patch when needed. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)
- Historical review UI now hides staged/unstaged worktree-only controls when the backend cannot inspect those modes, keeping the diff filter aligned with the available review source. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)

## Fixes And Polish
- Annotation loading is non-blocking and preserves hidden diff context plus partial-source reporting, so annotation-heavy PRs can still render diff content while GitHub metadata is collected. [3b78900a](https://github.com/aigentive/ralphx.app/commit/3b78900a482f7426cb2b0387506395830d453cb5)
- Unified multi-file PR patches now parse into file lists and single-file diffs, including file status, line counts, and binary handling for historical review paths. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)

## Developer And Maintainer Changes
- Annotation fetching now aggregates multiple GitHub sources with short-lived caching/coalescing, bounded check-run fan-out, and config-backed latency controls for TTL and check-run breadth. [3b78900a](https://github.com/aigentive/ralphx.app/commit/3b78900a482f7426cb2b0387506395830d453cb5)
- Review responses now expose `supports_worktree_modes`, with frontend plumbing through the publish panel, inline diff viewer, and diff filter. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)
- Git and GitHub service abstractions now include review-only PR-head ref fetching and PR patch retrieval to support cleaned-up workspace review. [ada9a772](https://github.com/aigentive/ralphx.app/commit/ada9a77280d74a73e4688bd327df64c6e11f82d0)
