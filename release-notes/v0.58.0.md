# RalphX.app v0.58.0

RalphX.app 0.58.0 focuses on plan reuse, PR-backed workspace reliability, and clearer runtime/validation visibility.

## User-Facing Changes
- **Plan seeding and reuse:** expands the Plan start surface with project-plan search, version preview/selection, copy into the active conversation, and Markdown import; seeded plans update the workspace/artifact state without a full page refresh. [be2bd935](https://github.com/aigentive/ralphx.app/commit/be2bd935351022b81a0e289b2c8c320853987a25)
- **Plan implementation controls:** accepted plan views can show progress, expose restart implementation, preserve plan/proposal tabs, and place appended tasks using backend-inferred graph dependencies instead of caller-computed placement. [cdc1c315](https://github.com/aigentive/ralphx.app/commit/cdc1c315e33d497f2fd6c2d7fe8b80aee4c89c42) [726c758e](https://github.com/aigentive/ralphx.app/commit/726c758e6d825856f5e0fe5ade40c2bf6ba4aabd)
- **Plan references in agent conversations:** attached plan references now resolve against the active workspace-linked cloned plan/session, so reviewer and chat flows read the current working copy rather than stale source-session provenance. [ecb5091a](https://github.com/aigentive/ralphx.app/commit/ecb5091a6df32f2e54c604bfc0d4fdfd4ea95bd2)
- **PR-backed agent workspace lifecycle:** linked ideation workspaces participate in plan-branch PR supervision/recovery, archive cleanup stops the running agent and closes the effective PR, and terminal PR worktrees are retried for cleanup without requiring app restart. [14052f4e](https://github.com/aigentive/ralphx.app/commit/14052f4ee8a3ad939e954c4052b630575c05ba30) [a7959d04](https://github.com/aigentive/ralphx.app/commit/a7959d04cacbef4f5cf698295685098612a8a0a4) [aa7a48dc](https://github.com/aigentive/ralphx.app/commit/aa7a48dc78a94c9d761c2a678a43b14baf9789f2)
- **Runtime and composer UX:** runtime activity now lives in the Runtimes tab backed by a conversation runtime index, nonfocused child runtimes no longer repin or mark the workspace chat as generating, and pasted Jira/Confluence URLs can resolve into native Atlassian reference pills. [1cade727](https://github.com/aigentive/ralphx.app/commit/1cade727aad4b3d4f4fca1eac03e46b18f546a1b) [4052d4f4](https://github.com/aigentive/ralphx.app/commit/4052d4f4440f38490cea99e3ab55d08c18188417) [2228c7e7](https://github.com/aigentive/ralphx.app/commit/2228c7e7d435603682fdb1a51a498b10f4b17b75)

## Fixes And Polish
- **Task validation:** task detail screens now render validation inline with setup/install-style progress, merging persisted summaries with live run/command events and bounded log snippets. [cdcbd3d5](https://github.com/aigentive/ralphx.app/commit/cdcbd3d54ce5ab02b2e439a90b1dfc3be7d154f3)
- **Merge publication and validation:** freshness-based merge completion publishes the updated PR branch before returning to PR polling, fails closed into `MergeIncomplete` when publication cannot be confirmed, and renders stopped/aborted merge outcomes distinctly from success. [95f522fe](https://github.com/aigentive/ralphx.app/commit/95f522fe297536b8e07e9c50715295e0a018a2e7)
- **Incomplete PR merge actions:** `Mark Resolved` is hidden for PR-backed plan merges while the linked PR is still open or branch data is missing, with the UI steering local recovery toward `Retry Merge`. [12fa3f46](https://github.com/aigentive/ralphx.app/commit/12fa3f46412addce445a6d18fa1f82b40ff5eda7)
- **Automatic merge recovery:** merge failure recovery is hardened around PR branch publication recovery and source-update conflict re-entry, including stack-safe retry paths. [6ce79ba3](https://github.com/aigentive/ralphx.app/commit/6ce79ba3b1452137a84fd471e0637cf5b3ae7977)
- **Agent issues:** repeated reports of the same blocker now attach to backend-owned canonical issue identity, showing occurrence counts, report summaries, and explicit candidate attach/confirm-new flows. [72efe694](https://github.com/aigentive/ralphx.app/commit/72efe6946914e458fcff75af264ae9aff6708fc7)
- **Navigation and task visibility:** Insights is reachable from the sidebar for new or smaller installs, and merge pipeline views filter tasks whose parent agent workspaces are archived. [27b2ca16](https://github.com/aigentive/ralphx.app/commit/27b2ca1660c46f375f41d2262d6adfcbac826fe3) [dba1f1b2](https://github.com/aigentive/ralphx.app/commit/dba1f1b20d2d1eb203598748581135c8594f49b1)
- **PR-mode cleanup polish:** PR-mode and scheduled plan-merge flows now share the same PR description drafting path, and deferred merge cleanup can remove empty non-git scratch directories while still preserving non-empty paths. [72ab9455](https://github.com/aigentive/ralphx.app/commit/72ab9455c1938b6a5b177245ab2370b8978d3a38)

## Developer And Maintainer Changes
- **Event delivery seam:** backend event emission is routed through shared event-sink wiring across AppState/HTTP and merge/verification paths, with coverage for merge validation, recovery failure status, and verification emitters. [e204d580](https://github.com/aigentive/ralphx.app/commit/e204d5804659ac73d8717b81e8149ba78288b7ff) [4ed34ff5](https://github.com/aigentive/ralphx.app/commit/4ed34ff5d4e85886f02fd5055a7e4a2414c8d600)
- **Provider-generic coordination model:** chat/conversation records now default coordination mode to `solo`, carry native team intent/message-target metadata, and validate requested team modes against selected harness capabilities. [7905ab41](https://github.com/aigentive/ralphx.app/commit/7905ab41aacff05847c05664f105d96daafb244f)
- **Agent/tool contract alignment:** merger, PR reviewer, append-task, and issue-registration surfaces were aligned with native validation, active-plan artifact reads, backend-inferred append placement, and backend-owned issue dedupe. [95f522fe](https://github.com/aigentive/ralphx.app/commit/95f522fe297536b8e07e9c50715295e0a018a2e7) [ecb5091a](https://github.com/aigentive/ralphx.app/commit/ecb5091a6df32f2e54c604bfc0d4fdfd4ea95bd2) [726c758e](https://github.com/aigentive/ralphx.app/commit/726c758e6d825856f5e0fe5ade40c2bf6ba4aabd) [72efe694](https://github.com/aigentive/ralphx.app/commit/72efe6946914e458fcff75af264ae9aff6708fc7)
- **Cleanup configuration:** terminal PR local cleanup interval and retry timing are now configurable through Git runtime configuration and `config/ralphx.yaml`. [aa7a48dc](https://github.com/aigentive/ralphx.app/commit/aa7a48dc78a94c9d761c2a678a43b14baf9789f2)
