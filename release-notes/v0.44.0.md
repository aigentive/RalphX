# RalphX.app v0.44.0

RalphX.app 0.44.0 expands the Jira/Linear ticketing dashboard, improves PR review workflows, and hardens workspace update recovery.

## User-Facing Changes

- **Ticketing dashboard:** Adds a unified Jira/Linear browse surface behind the dashboard flag, with list and kanban views, provider/project filtering, Jira project selection before browse, Linear project loading, sticky status groups, and per-column kanban scrolling. [487a24ce](https://github.com/aigentive/ralphx.app/commit/487a24ceba6e733b39bef34b2e88891da3838caa)
- **Ticket detail workflows:** Expands provider write-back from the detail sheet with status moves, assign/clear assignee, label editing, comments with Cmd/Ctrl+Enter, and safer external/provider link handling through the app opener with failure toasts. [487a24ce](https://github.com/aigentive/ralphx.app/commit/487a24ceba6e733b39bef34b2e88891da3838caa)
- **RalphX context on tickets:** Surfaces linked RalphX work directly in ticket rows/cards and details, including RX conversation counts, representative PR number/status, a Pull Requests tab that distinguishes open PRs from branch-only work, exact linked-conversation navigation, “Start RalphX work”, and “Bind existing conversation”. [487a24ce](https://github.com/aigentive/ralphx.app/commit/487a24ceba6e733b39bef34b2e88891da3838caa)
- **PR review sessions:** Review-mode conversations now include reviewed PR metadata in session naming, the monitor card can open the PR in GitHub, and failed GitHub review submissions remain retryable while preserving the last failure message. [32a0f96d](https://github.com/aigentive/ralphx.app/commit/32a0f96d254d162514a0c985acc82e91f7dcb253)
- **Workspace flow resilience:** Project conversation mode switches now stop a running project agent before applying public mode changes, while update-from-base uses deferred repair/recovery instead of getting stuck behind active or stale agent state. [82b3b75c](https://github.com/aigentive/ralphx.app/commit/82b3b75c8fe4446904a7342cf7a14fdd8244ccc4) [70162c6c](https://github.com/aigentive/ralphx.app/commit/70162c6c49e31697a064764cf2b6504bcee9278d)

## Fixes And Polish

- **Chat timeline:** Single-tool assistant turns now render with the same grouped summary row used for multi-tool turns, keeping live streaming and finalized chat history aligned. [8c5f4915](https://github.com/aigentive/ralphx.app/commit/8c5f4915a53dea52d16d2a32906082af2811a857)
- **Workspace publish recovery:** Stale `needs_agent` and transient publish states such as `refreshing`, `checking`, `committing`, and `describing` now recover or reset more consistently, including periodic background recovery every 120 seconds. [70162c6c](https://github.com/aigentive/ralphx.app/commit/70162c6c49e31697a064764cf2b6504bcee9278d)
- **PR publishing:** Ready plan PRs preserve the repository PR template when no explicit description override is supplied. [82b3b75c](https://github.com/aigentive/ralphx.app/commit/82b3b75c8fe4446904a7342cf7a14fdd8244ccc4)
- **Ticketing detail polish:** Switching tickets now shows a matching header plus a loading skeleton instead of flashing stale detail content; failed assignee avatars fall back to initials, and provider images that cannot load inline become browser-openable “View image” actions. [487a24ce](https://github.com/aigentive/ralphx.app/commit/487a24ceba6e733b39bef34b2e88891da3838caa)

## Developer And Maintainer Changes

- **Ticketing foundation:** Adds normalized provider models, ticketing commands, Jira/Linear browse and write helpers, durable provider-operation history, cache invalidation paths, frontend API/hooks/store coverage, and visual regression updates for the new dashboard surface. [487a24ce](https://github.com/aigentive/ralphx.app/commit/487a24ceba6e733b39bef34b2e88891da3838caa)
- **Focused regression coverage:** Extends tests for grouped live tool rendering, PR review context/retry behavior, stop-before-switch mode changes, ready-state PR templates, and transient publish status recovery. [8c5f4915](https://github.com/aigentive/ralphx.app/commit/8c5f4915a53dea52d16d2a32906082af2811a857) [32a0f96d](https://github.com/aigentive/ralphx.app/commit/32a0f96d254d162514a0c985acc82e91f7dcb253) [82b3b75c](https://github.com/aigentive/ralphx.app/commit/82b3b75c8fe4446904a7342cf7a14fdd8244ccc4) [70162c6c](https://github.com/aigentive/ralphx.app/commit/70162c6c49e31697a064764cf2b6504bcee9278d)
