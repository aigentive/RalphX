# RalphX.app v0.10.0

RalphX.app 0.10.0 improves update discovery, chat readability, and Agents workspace status freshness.

## User-Facing Changes

- **Updates and release notes** can now be reached from the native macOS menu, including manual update checks, current-version release notes, update-prompt notes, and a startup “What’s new” toast for unseen notes. [6b0e9b04](https://github.com/aigentive/ralphx.app/commit/6b0e9b0405e5a31d843db0b89240ba40a7bc96b9)
- **Chat messages render more predictably while live work is running**: sent messages appear immediately in existing conversations, streamed text keeps timestamps and copy affordances attached to each text block, and the typing indicator stays as its own final row. [b2e88f6c](https://github.com/aigentive/ralphx.app/commit/b2e88f6c5a7796339a58f3ad00a67683fadfaac1)
- **Queued prompts are easier to scan without losing content**: long queued messages now show compact read-only excerpts in chat and paused-agent surfaces, while edit mode still opens the full original message. [a0b7c00d](https://github.com/aigentive/ralphx.app/commit/a0b7c00d6ce5573d424edd81ac271f51b906a567)
- **Agents workspace status appears sooner and with less idle churn**: the Agents “New run” screen avoids polling merge-pipeline and running-process data when no conversation is selected, and project conversation selection now preflights branch freshness / Behind Base status earlier. [a2f3b602](https://github.com/aigentive/ralphx.app/commit/a2f3b602e741fc4e3fa351a60d60653e1a92952c) [99e61de9](https://github.com/aigentive/ralphx.app/commit/99e61de9cb5716da7c02a669b370c2967b2f2b4f)
- **Verification child chats appear in the Agents selector while live**: newly created verification children can show up as a `Verification` focus option without closing and reopening the conversation, with archived/completed children still hydrated through the latest-child lookup. [8c113e31](https://github.com/aigentive/ralphx.app/commit/8c113e317af5fa9d388f7b9eae6835c1a41eadef)

## Fixes And Polish

- **Icon-only queued-message controls** now use the app tooltip component and lucide icons, improving consistency on the affected chat controls. [a0b7c00d](https://github.com/aigentive/ralphx.app/commit/a0b7c00d6ce5573d424edd81ac271f51b906a567)
- **Streaming assistant rows** no longer render an empty assistant group/avatar wrapper when there is no visible streamed content or widget to group. [b2e88f6c](https://github.com/aigentive/ralphx.app/commit/b2e88f6c5a7796339a58f3ad00a67683fadfaac1)

## Developer And Maintainer Changes

- Added shared queued-message excerpt formatting and shared chat cache helpers for optimistic insertion, backend replacement, duplicate avoidance, and rollback/removal flows. [a0b7c00d](https://github.com/aigentive/ralphx.app/commit/a0b7c00d6ce5573d424edd81ac271f51b906a567) [b2e88f6c](https://github.com/aigentive/ralphx.app/commit/b2e88f6c5a7796339a58f3ad00a67683fadfaac1)
- Added opt-in query controls and view-aware App shell hydration for execution status, running processes, merge pipeline, ideation, and settings data. [a2f3b602](https://github.com/aigentive/ralphx.app/commit/a2f3b602e741fc4e3fa351a60d60653e1a92952c)
- Added centralized verification-child query key/data helpers, shared Agent workspace query keys/stale timings, and focused frontend coverage for selector refreshes and workspace freshness preflights. [8c113e31](https://github.com/aigentive/ralphx.app/commit/8c113e317af5fa9d388f7b9eae6835c1a41eadef) [99e61de9](https://github.com/aigentive/ralphx.app/commit/99e61de9cb5716da7c02a669b370c2967b2f2b4f)
- Added backend release-note commands, app-state persistence for `last_seen_release_notes_version`, a SQLite migration, typed frontend release-note API wiring, lazy markdown rendering, and targeted Rust/frontend coverage for update and release-note flows. [6b0e9b04](https://github.com/aigentive/ralphx.app/commit/6b0e9b0405e5a31d843db0b89240ba40a7bc96b9)
