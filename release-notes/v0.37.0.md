# RalphX.app v0.37.0

RalphX.app 0.37.0 improves ideation dependency handling, provider-aware session naming, and automatic conversation renaming.

## User-Facing Changes
- **Ideation proposals can now express dependencies through the live MCP tool surface.** `create_task_proposal` exposes optional `depends_on`, and `update_task_proposal` exposes optional `add_depends_on` and `add_blocks`, matching backend-supported proposal dependency handling. [9344a0eb](https://github.com/aigentive/ralphx.app/commit/9344a0ebdff46ccd58178f02a8a93d3a32068d2c)
- **Session title generation now preserves the selected provider harness.** Project conversations route auto-titling through the same provider that started the conversation instead of losing provider context when the session namer runs. [7435a748](https://github.com/aigentive/ralphx.app/commit/7435a74843a08e2b375f33cb5ce9b29f8eca736c)
- **Conversation rename dialogs now include automatic renaming.** Users can trigger `Auto rename` from the Agents sidebar rename dialog in both project and publication views, using the first non-empty user message as the title source. [7435a748](https://github.com/aigentive/ralphx.app/commit/7435a74843a08e2b375f33cb5ce9b29f8eca736c)

## Fixes And Polish
- **Auto-generated title persistence is now owned by RalphX.** The session namer returns a title string, and the app writes it back to the correct conversation or session target instead of relying on the model to call a title-update tool. [7435a748](https://github.com/aigentive/ralphx.app/commit/7435a74843a08e2b375f33cb5ce9b29f8eca736c)

## Developer And Maintainer Changes
- Added focused schema coverage to keep MCP ideation tool inputs aligned with backend-supported dependency fields. [9344a0eb](https://github.com/aigentive/ralphx.app/commit/9344a0ebdff46ccd58178f02a8a93d3a32068d2c)
- Expanded session-namer test coverage for rename fallback behavior, title patching, and path-sink handling. [7435a748](https://github.com/aigentive/ralphx.app/commit/7435a74843a08e2b375f33cb5ce9b29f8eca736c)

## Known Issues
- Existing stale conversation titles are not rewritten automatically; run auto-rename again to regenerate them. [7435a748](https://github.com/aigentive/ralphx.app/commit/7435a74843a08e2b375f33cb5ce9b29f8eca736c)
