# RalphX.app v0.22.0

RalphX.app 0.22.0 expands native agent task coordination, improves Commit & Publish visibility, and makes startup and terminal-docking feedback more precise.

## User-Facing Changes
- Agent task coordination now appears as structured product UI: agent conversations can create, read, list, update, claim, and complete tasks, with task activity rendered in chat widgets and surfaced alongside workspace changes in composer and publish views. [9c61599f](https://github.com/aigentive/ralphx.app/commit/9c61599f28a93d8c64774478191d93b916df3787)
- Commit & Publish now represents GitHub auto-merge as part of the publish lifecycle: publish confirmation waits for pending supervision-setting saves, and the pipeline can show a distinct “Request auto-merge” post-publish step. [ca1cc178](https://github.com/aigentive/ralphx.app/commit/ca1cc178ed7effd5403a4d5fcae1418689275f59)
- Agent startup feedback now shows specific typing-indicator stages for conversation creation, workspace setup, agent start, and active work, including restored in-progress state after navigating away and back. [844d3e36](https://github.com/aigentive/ralphx.app/commit/844d3e366b00a2ba608811fe50047b4571825ce8)
- Terminal docking now uses the terminal’s resolved height and native Tauri drag-position signals, so dragging a terminal header toward a dock target can activate a correctly sized target. [b4caa005](https://github.com/aigentive/ralphx.app/commit/b4caa005be1ff89a5ff9de6ea7d67d8ce3249659)

## Fixes And Polish
- Commit & Publish now preserves loading feedback while merged-workspace diffs hydrate, avoiding the misleading “No changed files” state before the actual unified file list appears. [f913d12e](https://github.com/aigentive/ralphx.app/commit/f913d12ed948e2ac257c21c6169aeb69cc14d151)
- Expanded unchanged context in agent workspace diffs now reads from the same old/new sources as the visible live diff, preventing old `HEAD` content from appearing under new-file line numbers after “Show unchanged lines.” [0c8fa371](https://github.com/aigentive/ralphx.app/commit/0c8fa371cccce48ba4ac2635aa935c1a3c719cdc)
- Terminal dock targeting is separated from composer drag highlighting, reducing cases where composer drag handling masks terminal placement feedback. [b4caa005](https://github.com/aigentive/ralphx.app/commit/b4caa005be1ff89a5ff9de6ea7d67d8ce3249659)

## Developer And Maintainer Changes
- Adds the native agent-task domain, SQLite and memory persistence, service layer, HTTP endpoints, frontend API bindings, and MCP server support, with internal sidecar tooling kept separate from the external public MCP surface. [9c61599f](https://github.com/aigentive/ralphx.app/commit/9c61599f28a93d8c64774478191d93b916df3787)
- Extends focused coverage for task tool paths, task widgets, publish auto-merge states, startup-status rendering, and diff range/layout behavior. [9c61599f](https://github.com/aigentive/ralphx.app/commit/9c61599f28a93d8c64774478191d93b916df3787) [ca1cc178](https://github.com/aigentive/ralphx.app/commit/ca1cc178ed7effd5403a4d5fcae1418689275f59) [844d3e36](https://github.com/aigentive/ralphx.app/commit/844d3e366b00a2ba608811fe50047b4571825ce8) [0c8fa371](https://github.com/aigentive/ralphx.app/commit/0c8fa371cccce48ba4ac2635aa935c1a3c719cdc)

## Known Issues
- Patch-backed GitHub fallback diffs still render available patch context only; full-file lazy expansion remains unavailable when no local full-file source exists. [0c8fa371](https://github.com/aigentive/ralphx.app/commit/0c8fa371cccce48ba4ac2635aa935c1a3c719cdc)
