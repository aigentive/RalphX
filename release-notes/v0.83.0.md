# RalphX.app v0.83.0

RalphX.app 0.83.0 reworks automation workflows, introduces an inbox-oriented agents sidebar, and stabilizes agent messaging and plan handoff.

## User-Facing Changes
- **Agents sidebar:** Defaults to an Inbox view with collapsible **Needs you**, **Working**, **Stale**, and **Done** lanes; pinned conversations remain at the top of their lane. [872fae64](https://github.com/aigentive/ralphx.app/commit/872fae648db790da5a294bc746ee0cabc963202f)
- **Conversation attention controls:** Expands session actions with **Mute until it changes**, moving muted conversations out of **Needs you** until they are modified; bulk mute is available separately from archive. [872fae64](https://github.com/aigentive/ralphx.app/commit/872fae648db790da5a294bc746ee0cabc963202f)
- **Automations list:** Reworks the list into priority-ordered sections—Needs attention, Running, Finished, and Drafts—with status counts, filter pills, name search, and explicit no-match states. [0114bfd8](https://github.com/aigentive/ralphx.app/commit/0114bfd86222ece2d0fea980e49b2f3dec3b9ffe)
- **Automation details:** Surfaces status, phase progress, execution metadata, spec, and inputs directly in the Overview, with theme-token styling across light, dark, and high-contrast themes. [6426d96d](https://github.com/aigentive/ralphx.app/commit/6426d96ddc15ea93f18d82637e884f0ea641dd45)
- **Plan-to-implementation handoff:** Direct implementation now uses the plan bundle linked to the workspace; if that bundle changes, implementation and review flows require re-approval against the current plan. [dc4a3cad](https://github.com/aigentive/ralphx.app/commit/dc4a3cad2b1255cc1aba532a635694dd76745946)

## Fixes And Polish
- **Agent follow-up messages:** Stabilizes delivery to a matching live Claude CLI process, while genuine model changes continue to start a fresh session; a message delivered to the agent but not persisted now remains visible with a warning rather than appearing as a send failure. [3b758406](https://github.com/aigentive/ralphx.app/commit/3b7584069128f3cb33b0446521e2aab4bbd24c88)
- **Conversation artifact focus:** Fixes plan and verification panes so switching conversations cannot show artifacts or focus state from another conversation. [ae7bf82b](https://github.com/aigentive/ralphx.app/commit/ae7bf82b2b947242b8c5677a537fcdab34f6337f)

## Developer And Maintainer Changes
- Expands focused regression coverage for live interactive-process message routing, conversation-scoped artifact focus, linked-plan admission, and automation views across supported themes. [3b758406](https://github.com/aigentive/ralphx.app/commit/3b7584069128f3cb33b0446521e2aab4bbd24c88) [ae7bf82b](https://github.com/aigentive/ralphx.app/commit/ae7bf82b2b947242b8c5677a537fcdab34f6337f) [dc4a3cad](https://github.com/aigentive/ralphx.app/commit/dc4a3cad2b1255cc1aba532a635694dd76745946)
