# RalphX.app v0.34.3

RalphX.app 0.34.3 focuses on Atlassian composer reliability, Jira/Confluence search coverage, and release coverage enforcement.

## User-Facing Changes
- Stabilizes Atlassian composer handling for Jira and Confluence references, with coverage for quoted Confluence alias triggers, malformed trigger fallbacks, and invalid integration metadata normalization. [a4e2ad74](https://github.com/aigentive/ralphx.app/commit/a4e2ad74c5a48457486ae0a71dc2be0e709af05d)

## Developer And Maintainer Changes
- Restores `atlassian_client.rs` to Codecov patch coverage enforcement and updates the Codecov upload workflow to use the PyPI installer path. [a4e2ad74](https://github.com/aigentive/ralphx.app/commit/a4e2ad74c5a48457486ae0a71dc2be0e709af05d)
- Adds deterministic Atlassian client test coverage through a JSON requester seam, including Jira exact-key lookup, picker fallback after JQL failure, Confluence page-id lookup, search merging/fallbacks, and Jira/Confluence content rendering. [a4e2ad74](https://github.com/aigentive/ralphx.app/commit/a4e2ad74c5a48457486ae0a71dc2be0e709af05d)
