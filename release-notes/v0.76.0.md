# RalphX.app v0.76.0

RalphX.app 0.76.0 reworks automation and persona workflows, centralizes agent runtime selection, and improves publish/review reliability.

## User-Facing Changes
- **Automation details** now separate Overview from Runs, promote run outcomes such as judge verdicts and failure reasons, hide raw prompts until requested, group configuration, expose the current PR, and let goal items open produced plans. [6db3fb14](https://github.com/aigentive/ralphx.app/commit/6db3fb14399b4ed356288072ba71fbbd851a85bb) [9372715b](https://github.com/aigentive/ralphx.app/commit/9372715b7425b226faad8cb3b8794d7a0c020391)
- **Automation runs** now appear as runtime-style items in the Agents Runtime tray, ordered newest-first after Main, with status labels and non-navigable rows when no conversation is attached. [8121f788](https://github.com/aigentive/ralphx.app/commit/8121f7882f35040b37077e83744799cafc675c70)
- **Personas** expand management and inspection workflows: archived personas can be restored, picker and preview surfaces are richer, builder artifacts can show changes and recover stale refinements, and “Build with Agent” opens a fresh project-scoped persona conversation. [097d3b9a](https://github.com/aigentive/ralphx.app/commit/097d3b9ab21b2967ff15938172fe30cc3274d136) [e41b1cb4](https://github.com/aigentive/ralphx.app/commit/e41b1cb4921c0e7161d03df7850f7be069949052)
- **Agent runtime selection** now uses one shared override model for eligible conversation-scoped provider, model, effort, speed, and persona choices across chat, plan continuations, Workspace Review flows, and Settings. [b2c1d8b6](https://github.com/aigentive/ralphx.app/commit/b2c1d8b6e1ecff35f72fabdd4d5ff689af9a7aa1)
- **Linked ClickUp artifacts** now render full ticket context in Agents, including Markdown descriptions, image previews, attachments, comments and replies, and activity. [14c450ed](https://github.com/aigentive/ralphx.app/commit/14c450ed2f7046d909b0d74524cfd435fef3ad85)

## Fixes And Polish
- **Commit & Publish** now nests Workspace Review under Changes and Review subtabs, while live unstaged counts, file lists, and diffs stay synchronized with the conversation footer. [a8bff03b](https://github.com/aigentive/ralphx.app/commit/a8bff03b682cc8dc52c8002608b9922c5ecea8d9) [4164e4e4](https://github.com/aigentive/ralphx.app/commit/4164e4e4377ca83b9f7e5e11bac3bbc0e4eb9e35)
- **Publish progress** is scoped to the conversation’s active attempt, preventing progress indicators from lingering after completion or leaking across conversation switches. [c8bd40ac](https://github.com/aigentive/ralphx.app/commit/c8bd40acfe6abe4e3faf4942ff5c3e8041f7541f)
- **Workspace repair and PR autofix recovery** keep active repairs in `fixing`, reserve agent launch ownership before spawning, and correlate recovery with the exact PR issue attempt rather than an unrelated later run. [a3d0bb28](https://github.com/aigentive/ralphx.app/commit/a3d0bb2821fd34453f2b54b58824fbbded96a7c3) [c2abf4f6](https://github.com/aigentive/ralphx.app/commit/c2abf4f6247b0b582b86f846be0656247e06baaf)
- **Usage statistics** now preserve an unavailable state for partially uncounted data and apply provider-aware token accounting, avoiding misleading inflated totals. [0ac37169](https://github.com/aigentive/ralphx.app/commit/0ac37169584f97cee13f51c258c6ee74764da97f)
- **Queued-message UI** no longer appears for running Claude interactive-process agents, while Codex-style queued delivery remains visible where applicable. [62f34db2](https://github.com/aigentive/ralphx.app/commit/62f34db215a089545e885565aef40bf4dba38e81)

## Developer And Maintainer Changes
- Removed the retired Claude-only team-mode implementation in favor of the active provider-neutral native delegation path; generated MCP plugin output is now checked for drift. [0f8341a7](https://github.com/aigentive/ralphx.app/commit/0f8341a7a3559ac9a857249b796ceeed0db772e9)
