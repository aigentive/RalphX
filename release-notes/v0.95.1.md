# RalphX.app v0.95.1

RalphX.app 0.95.1 improves agent-chat attribution and streaming stability, makes Workspace Review more accurate and faster to open, and recovers blocked repair publication and delegation workflows.

## User-Facing Changes
- **Agent chat** now shows run attribution for new completed turns, including elapsed-time chips such as “Agent worked for 3m 12s”; live turns show “Agent working for …,” and attribution remains available when the final message is inside a collapsed tool or thinking group. Existing conversations without persisted run IDs are unchanged. [572baca9](https://github.com/aigentive/RalphX/commit/572baca984c960ac5a2fc6c91c3b0ec27dd7d446)
- **Streaming chat** no longer repeatedly pins the viewport above its current position or conflicts with virtualized-item alignment, eliminating the backward jumps and oscillation during message appends. [4882c937](https://github.com/aigentive/RalphX/commit/4882c93755233edf5700d4ed4e18e5907df38dc4)
- **Workspace Review** now distinguishes loading, unavailable, target-mismatch, and genuinely empty states instead of incorrectly reporting “No reviewable changes”; retry actions resolve the owning review conversation, and full review packets are deferred until needed. [83d19a70](https://github.com/aigentive/RalphX/commit/83d19a70b31aa6040885248c8c4734ca509f24bf)
- **Workspace repair publication** now presents a focused “Retry publication” action when a repair push cannot be confirmed remotely, allowing a validated repair head to be retried rather than remaining blocked. [8c17a6ca](https://github.com/aigentive/RalphX/commit/8c17a6caa9b3d8726402f8f107ebcf7430421cbc)
- **Delegation and Team workflows** now authorize live caller runs by liveness rather than timestamp recency, restoring wake-resume re-parking and multi-wave delegation when stale sibling runs exist. [1371c8b0](https://github.com/aigentive/RalphX/commit/1371c8b0ae1cf3358fce31335b2d5b4b8cab0814)

## Developer And Maintainer Changes
- Trusted-run authority rejections now log the caller conversation, run identity, and observed run status to make delegation failures diagnosable. [1371c8b0](https://github.com/aigentive/RalphX/commit/1371c8b0ae1cf3358fce31335b2d5b4b8cab0814)

## Known Issues
- A hydrated chat transcript at rest can still jitter because the virtualizer publishes item and padding measurements in separate frames; this residual behavior is captured in expected-fail browser coverage. [4882c937](https://github.com/aigentive/RalphX/commit/4882c93755233edf5700d4ed4e18e5907df38dc4)
- A virtualizer tail-measurement collapse can still cause bottom-position oscillation; resolving it requires the virtualizer to retain an extent floor. [4882c937](https://github.com/aigentive/RalphX/commit/4882c93755233edf5700d4ed4e18e5907df38dc4)
