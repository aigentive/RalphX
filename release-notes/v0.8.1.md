# RalphX.app v0.8.1

RalphX.app 0.8.1 focuses on installed-app CLI reliability, visible agent-send failures, and restored Agents sidebar controls.

## User-Facing Changes
- **Installed macOS app agent launches are more reliable** when Codex or Claude are installed through Node-managed locations such as NVM; Codex probes and Claude MCP startup registration now use the same normalized subprocess PATH as real agent spawns, avoiding failures like `env: node: No such file or directory`. [ad40990c](https://github.com/aigentive/ralphx.app/commit/ad40990c8e86667f958a3293c106a680c678a6bd)
- **Agent-send failures now surface in the chat UI** when they happen before a chat run is created; instead of an Agents conversation appearing idle after input is cleared, RalphX now shows a visible error toast. [ad40990c](https://github.com/aigentive/ralphx.app/commit/ad40990c8e86667f958a3293c106a680c678a6bd)
- **Agents sidebar controls are restored**, including the resize handle plus show-all, sort, and archived controls. [a3e8508b](https://github.com/aigentive/ralphx.app/commit/a3e8508b09c4710fc9ff016646c87b42abe715c5)

## Fixes And Polish
- **Agents project rows behave more predictably**: expanding a project no longer auto-selects a remembered conversation, and only explicit conversation clicks select conversations. [a3e8508b](https://github.com/aigentive/ralphx.app/commit/a3e8508b09c4710fc9ff016646c87b42abe715c5)
- **Sidebar presentation is cleaner**: row menus no longer overlap counts or status dots, expanded project styling only appears while the project is actually expanded, and native macOS window controls are no longer duplicated. [a3e8508b](https://github.com/aigentive/ralphx.app/commit/a3e8508b09c4710fc9ff016646c87b42abe715c5)

## Developer And Maintainer Changes
- Added regression coverage for NVM-style Codex and Claude shims under a stripped macOS GUI PATH, with shared environment-test locking for isolated PATH/HOME mutation. [ad40990c](https://github.com/aigentive/ralphx.app/commit/ad40990c8e86667f958a3293c106a680c678a6bd)
- Reworked Agents sidebar state ownership so show-all and project sort remain store-backed, while conversation selection is written only through explicit conversation selection. [a3e8508b](https://github.com/aigentive/ralphx.app/commit/a3e8508b09c4710fc9ff016646c87b42abe715c5)
