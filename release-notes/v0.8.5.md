# RalphX.app v0.8.5

RalphX.app 0.8.5 focuses on Codex MCP reliability by enforcing noninteractive launch defaults across exec/resume and background utility-agent paths.

## User-Facing Changes
- Codex-backed MCP workflows now launch with `approval_policy=never` and `sandbox_mode=danger-full-access` at command construction, preventing utility agents such as PR describers and session namers from falling back to `workspace-write` and failing MCP submit/update calls. [49133760](https://github.com/aigentive/ralphx.app/commit/49133760906c7594c496eda52b483aad6cd6fb6f)
- Codex exec/resume launches now receive the required MCP-safe defaults even when a caller passes stale or weaker settings. [49133760](https://github.com/aigentive/ralphx.app/commit/49133760906c7594c496eda52b483aad6cd6fb6f)

## Developer And Maintainer Changes
- Centralizes Codex approval and sandbox constants in the domain harness model so future policy changes have a single default path to update. [49133760](https://github.com/aigentive/ralphx.app/commit/49133760906c7594c496eda52b483aad6cd6fb6f)
- Updates background utility runtime resolution so effective Codex helper configs report the enforced launch settings while keeping configured lane values visible for compatibility and audit. [49133760](https://github.com/aigentive/ralphx.app/commit/49133760906c7594c496eda52b483aad6cd6fb6f)
- Adds regression coverage for Codex command construction, reexecutor spawn defaults, background runtime resolution, lane defaults, session naming, and PR description helpers. [49133760](https://github.com/aigentive/ralphx.app/commit/49133760906c7594c496eda52b483aad6cd6fb6f)
