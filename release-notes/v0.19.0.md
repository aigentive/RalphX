# RalphX.app v0.19.0

RalphX.app 0.19.0 improves Commit & Publish diff handling, expands PR supervision controls, and aligns execution-state UI across agent workflows.

## User-Facing Changes

- **Agent workspace PR supervision** can now be enabled per workspace from Commit & Publish, keeping PR repair work tied to the originating agent conversation for failed checks, review change requests, and base-refresh follow-up. [02a7adf2](https://github.com/aigentive/ralphx.app/commit/02a7adf21f1d82c041d791242c02413307e49388)
- **Commit & Publish diff browsing** now uses virtualized file rows and visible-range diff hydration, reducing scroll-time pressure on larger change sets while keeping jump-to-file navigation aligned with the list. [5c090dce](https://github.com/aigentive/ralphx.app/commit/5c090dceffa138b48e740a46a8a99a8b03c46710)
- **Merged agent workspaces** can still show their published cumulative file changes, using preserved PR-head refs when available instead of depending on a deleted post-merge worktree. [af64e076](https://github.com/aigentive/ralphx.app/commit/af64e076293a517f08dedb04d12bcdb7a16d4d18)
- **Agents screen execution state** now appears in the same main-content footer position used by Ideation, with the left sidebar remaining fixed and the execution bar scoped beneath chat and artifacts. [a4c2145e](https://github.com/aigentive/ralphx.app/commit/a4c2145e578653bb86de5d0f0d36480de0f7cc68)
- **Agent composer workspace diffs** now render as a slimmer inline summary, and the Commit & Publish file list keeps wide paths or expanded diff content contained without horizontal list scrolling. [de38a694](https://github.com/aigentive/ralphx.app/commit/de38a6947be798acb8fed742a6fb8ed17321b7c8)

## Fixes And Polish

- **Published workspace status** now treats merged and closed PRs as terminal, so workspaces no longer remain stuck in stale “behind base”-style states after GitHub has already finalized the linked PR. [91e6d454](https://github.com/aigentive/ralphx.app/commit/91e6d454c5c377f8bc9cfcd21bee00e9b9edd3ef)
- **Refreshed published workspaces** remain eligible for active PR polling, allowing their displayed PR state to continue reconciling after publication refreshes. [91e6d454](https://github.com/aigentive/ralphx.app/commit/91e6d454c5c377f8bc9cfcd21bee00e9b9edd3ef)

## Developer And Maintainer Changes

- Persisted PR supervision preferences on agent-workspace records and exposed them through backend/API and Commit & Publish wiring. [02a7adf2](https://github.com/aigentive/ralphx.app/commit/02a7adf21f1d82c041d791242c02413307e49388)
- Aligned in-memory and SQLite active workspace selection rules for terminal PR states and refreshed publication push status. [91e6d454](https://github.com/aigentive/ralphx.app/commit/91e6d454c5c377f8bc9cfcd21bee00e9b9edd3ef)
- Expanded regression and visual coverage for merged-workspace diffs, terminal freshness, refreshed PR polling, and the new Agents execution-bar placement. [af64e076](https://github.com/aigentive/ralphx.app/commit/af64e076293a517f08dedb04d12bcdb7a16d4d18) [91e6d454](https://github.com/aigentive/ralphx.app/commit/91e6d454c5c377f8bc9cfcd21bee00e9b9edd3ef) [a4c2145e](https://github.com/aigentive/ralphx.app/commit/a4c2145e578653bb86de5d0f0d36480de0f7cc68)
