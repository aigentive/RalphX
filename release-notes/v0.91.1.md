# RalphX.app v0.91.1

RalphX.app 0.91.1 improves thinking-transcript readability, bounds external-MCP shutdowns, and preserves publish consent through workspace repair.

## User-Facing Changes
- **Thinking transcripts:** Consecutive visible thinking segments now appear under one expandable block in both live chat and saved messages; settled multi-segment groups can show aggregate duration and a step count, such as “12 steps.” [98d454e9](https://github.com/aigentive/ralphx.app/commit/98d454e945a65ba9c3962c07db74e7019dcb7acc)
- **Exit and update restart:** Shutdown now has a bounded cleanup path for external MCP processes, reducing cases where the app can stall on exit—including after an updater-triggered restart. [8b7233e3](https://github.com/aigentive/ralphx.app/commit/8b7233e3147705b8a420f63169dfef88f2ebccc4)
- **Workspace repair publishing:** With Auto Publish disabled, background repair retries no longer publish a workspace or promote an UpdateOnly repair to Publish. A repair started through an explicit **Publish** action can still complete that one publish after repair. [349796d7](https://github.com/aigentive/ralphx.app/commit/349796d790eee918e68a82885f96c89766e82f1f)

## Developer And Maintainer Changes
- **Shutdown configuration:** Adds runtime controls for the exit-watchdog deadline and external-MCP shutdown grace period, including environment overrides and bounds for oversized values. [8b7233e3](https://github.com/aigentive/ralphx.app/commit/8b7233e3147705b8a420f63169dfef88f2ebccc4)
- **Thinking presentation coverage:** Updates the chat architecture notes and visual fixtures for grouped live and persisted thinking blocks. [98d454e9](https://github.com/aigentive/ralphx.app/commit/98d454e945a65ba9c3962c07db74e7019dcb7acc)
