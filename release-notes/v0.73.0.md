# RalphX.app v0.73.0

RalphX.app 0.73.0 brings artifact-text selections into agent conversations, preserves selected context in message history, and stabilizes persisted excerpt chips.

## User-Facing Changes
- **Agents artifact pane:** Select text in displayed Plans, Reviews, issues, task details, automation specs, pull requests, diffs, Jira, Linear, or Granola content, then use **Add to conversation** to stage the passage as context. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)
- **Composer context:** Selected passages appear as independently removable, source-aware chips—such as a Plan, Jira, or Diff excerpt—without sending a message automatically. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)
- **Conversation history:** Sent messages retain excerpt provenance, including source identity and available version, revision, file-path, or locator details, so the selected context is preserved after reload. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)

## Fixes And Polish
- **Persisted excerpt chips:** Fixes a rendering collision where two excerpts with identical text but different version, revision, or locator metadata could hide or overwrite one another after reload. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)

## Developer And Maintainer Changes
- Expands selection-provider regression coverage for dismissal and guard paths, including Escape, scrolling, outside interaction, collapsed selections, and byte limits. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)
- Speeds up the dialog accessibility contract scan by pre-filtering candidate files before TypeScript parsing, avoiding CI timeouts without weakening violation detection. [a80e4922](https://github.com/aigentive/ralphx.app/commit/a80e4922a535d833ec7a83d7d30ae850c035a515)
