# RalphX.app v0.12.0

RalphX.app 0.12.0 improves chat transcript pagination, agent running-state recovery, and release/update UI polish.

## User-Facing Changes

- **Chat transcripts now paginate by rendered timeline items** instead of raw provider message rows, so latest pages match the visible text and tool-call widgets users see, older history loads in sequence, and live turns replay more reliably after switching away and back. [860ab73f](https://github.com/aigentive/ralphx.app/commit/860ab73f5d3d8330a7b7c08f23fd03fd647d5e34)
- **Agent running indicators now reconcile against backend process state** for the selected conversation and visible Agents sidebar rows, reducing cases where an active agent appears idle after missed lifecycle events or lost local UI state. [39f2e6e4](https://github.com/aigentive/ralphx.app/commit/39f2e6e4d4acf415c4385f90bef3c18bb8690c5d)
- **New Agents conversations avoid extra first-response hydration work** when no eligible linked ideation bridge events are ready, and breadcrumbs can render from cached project conversation metadata instead of issuing an additional history fetch. [37a1b604](https://github.com/aigentive/ralphx.app/commit/37a1b604b4709dec9570544661fe457e425104e4)
- **Publish confirmation dialogs now show in-flight progress** for slower backend actions such as Commit & Publish, Update from base, and close-PR flows, with pending text, a spinner, disabled actions, and blocked dismissal while submission is running. [b6b1e93d](https://github.com/aigentive/ralphx.app/commit/b6b1e93d81fa235fa7af35d7020e352e05d694d3)
- **Utility background agents now default to lightweight models** while preserving the selected harness/provider, so scoped work such as session naming, PR descriptions, and project analysis no longer inherits heavier lane/default models. [b320a3bd](https://github.com/aigentive/ralphx.app/commit/b320a3bd01be57a5b5eaadc0f730d0cec2b2244e)

## Fixes And Polish

- **What’s New release notes render cleaner markdown** by removing generated GitHub metadata markers from previews, dialogs, and update notification notes; the startup toast also waits for the settings modal to close instead of becoming an unclickable overlay. [92085804](https://github.com/aigentive/ralphx.app/commit/92085804cabe1363b5c00c93a5f3cdd457f25f89)
- **Agents sidebar pagination stays stable on selection**: selecting an already-loaded conversation after loading more sessions no longer moves that row to the top or collapses the sidebar back to the first page. [81769f8b](https://github.com/aigentive/ralphx.app/commit/81769f8b74ab85d79929d166b1dcf94e94d26007)

## Developer And Maintainer Changes

- Added an additive persisted `chat_message_blocks` timeline read model, block-level pagination via `get_agent_conversation_timeline_page`, streaming block persistence, and compatibility backfill from existing `content_blocks`. [860ab73f](https://github.com/aigentive/ralphx.app/commit/860ab73f5d3d8330a7b7c08f23fd03fd647d5e34)
- Added backend/frontend bulk running-state lookup through `get_agent_running_states`, with visible-sidebar polling and selected-conversation recovery polling. [39f2e6e4](https://github.com/aigentive/ralphx.app/commit/39f2e6e4d4acf415c4385f90bef3c18bb8690c5d)
- Added focused regression coverage for release-note sanitization, modal-aware toasts, async confirmation states, sidebar pagination selection, cached breadcrumb hydration, bridge wake-up dispatch, and utility-agent model locks. [92085804](https://github.com/aigentive/ralphx.app/commit/92085804cabe1363b5c00c93a5f3cdd457f25f89) [b6b1e93d](https://github.com/aigentive/ralphx.app/commit/b6b1e93d81fa235fa7af35d7020e352e05d694d3) [81769f8b](https://github.com/aigentive/ralphx.app/commit/81769f8b74ab85d79929d166b1dcf94e94d26007) [37a1b604](https://github.com/aigentive/ralphx.app/commit/37a1b604b4709dec9570544661fe457e425104e4) [b320a3bd](https://github.com/aigentive/ralphx.app/commit/b320a3bd01be57a5b5eaadc0f730d0cec2b2244e)
