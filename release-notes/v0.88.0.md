# RalphX.app v0.88.0

RalphX.app 0.88.0 improves agent-thinking and turn attribution, makes interactive chat delivery durable, and bounds repeated PR-autofix repair work.

## User-Facing Changes
- **Thinking blocks** now settle consistently across live chat, hydrated history, and persisted timelines; token progress stays on the active block, while empty settled rows no longer render as visible pills. [6a0088f5](https://github.com/aigentive/ralphx.app/commit/6a0088f5a7cd2c9826ec5d8ec3e3494bad263e14)
- **Queued chat messages** no longer silently disappear when an interactive process exits or its provider session is unavailable: backend-confirmed messages remain visible, unanswered stdin turns are recovered, and blocked continuations replay in a fresh session. [15adaec9](https://github.com/aigentive/ralphx.app/commit/15adaec90ac30936deb097a65bf3015e75a45ad4)
- **Reviewer and fixer turns** now use persisted run data for displayed duration and attribution, while active role controls and badges remain scoped to the current turn. [c2452df4](https://github.com/aigentive/ralphx.app/commit/c2452df45e2597d5cc0b6945a5f05ac264c8a786)
- **PR autofix repairs** now recognize unchanged failures and default to a 45-agent-minute budget per failure fingerprint; exhausted budgets pause further work, show repair spend and a warning, and raise an Inbox notification. [dd1acc90](https://github.com/aigentive/ralphx.app/commit/dd1acc90273f79d402f5c00854a510e4d4233069)
- **Base-caused CI failures** are identified before spending a repair generation when every failing PR check is also proven failing on the base branch; RalphX hands off with an Inbox notification instead of starting an agent run. [dd1acc90](https://github.com/aigentive/ralphx.app/commit/dd1acc90273f79d402f5c00854a510e4d4233069)

## Developer And Maintainer Changes
- Thinking capture now uses a shared Claude/Codex event contract, with capability probing, persistence, rendering guidance, and shared fixtures aligned around the same payload shape. [6a0088f5](https://github.com/aigentive/ralphx.app/commit/6a0088f5a7cd2c9826ec5d8ec3e3494bad263e14)
- Workspace-repair completion now carries a classified resolution and accepts a validated fix commit SHA, aligning repair prompts, MCP tooling, and backend handling. [dd1acc90](https://github.com/aigentive/ralphx.app/commit/dd1acc90273f79d402f5c00854a510e4d4233069)
- Backend-generated repair assignments are covered by contract tests that verify referenced tools are available to the receiving agent. [dd1acc90](https://github.com/aigentive/ralphx.app/commit/dd1acc90273f79d402f5c00854a510e4d4233069)
