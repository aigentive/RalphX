# RalphX.app v0.42.0

RalphX.app 0.42.0 focuses on durable PR review artifacts, backend-owned queued chat messages, and more reliable contributor setup docs.

## User-Facing Changes
- PR Review workspaces now show generated reviews as a first-class, versioned markdown `Review` artifact tab that opens when the first review is created and can be revisited alongside other artifact tabs. [2ce1af10](https://github.com/aigentive/ralphx.app/commit/2ce1af105f7b8e85c3c29f393ef2f790857b05c8)
- PR review submissions now guard against stale output by blocking a pending review action when the stored Review artifact does not match the pending action head SHA. [2ce1af10](https://github.com/aigentive/ralphx.app/commit/2ce1af105f7b8e85c3c29f393ef2f790857b05c8)
- Queued chat messages are now persisted by the backend and hydrated back into the chat panel, so pending messages can survive navigation and app restarts before they are sent or deleted. [f6e2f401](https://github.com/aigentive/ralphx.app/commit/f6e2f4019ac850e95bb78ac537ed64a1860f33a0)

## Fixes And Polish
- Queued-message hydration now preserves local editing state when backend rows match existing queued items, reducing UI churn when returning to an active context. [f6e2f401](https://github.com/aigentive/ralphx.app/commit/f6e2f4019ac850e95bb78ac537ed64a1860f33a0)

## Developer And Maintainer Changes
- Adds backend persistence, recovery, PR review context metadata, and reviewer tool/prompt wiring for the new `pr_review` artifact type. [2ce1af10](https://github.com/aigentive/ralphx.app/commit/2ce1af105f7b8e85c3c29f393ef2f790857b05c8)
- Adds durable queued-message repository support with SQLite and in-memory implementations, covering main chat, verification auto-continue, and provider-pause queueing paths. [f6e2f401](https://github.com/aigentive/ralphx.app/commit/f6e2f4019ac850e95bb78ac537ed64a1860f33a0)
- Adds a stable `frontend/CLAUDE.md` instruction entrypoint and docs-contract coverage, with optional owner-strategy probes treated as non-fatal when absent. [173f1acd](https://github.com/aigentive/ralphx.app/commit/173f1acdd1797c7dfb157996cb21315324e39730)
