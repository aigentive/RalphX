# RalphX.app v0.12.3

RalphX.app 0.12.3 improves publish progress feedback, Codex usage accounting, and startup cleanup behavior while polishing hover states across themes.

## User-Facing Changes

- **Commit & Publish progress** now advances through the active publish phases in the compact dialog, and the Agents > Commit & Publish CTA stops spinning once publish completes and PR state is available. [01036f51](https://github.com/aigentive/ralphx.app/commit/01036f518cc86e5d7a7f08a7bac2994b1de6a3c2)
- **Codex conversation stats** now avoid inflated input, cache, and output totals for resumed sessions by treating cumulative provider usage as turn deltas for new writes and collapsing affected existing series for display. [66d5f4a6](https://github.com/aigentive/ralphx.app/commit/66d5f4a67ae61fea86662ceae5793d8daabba136)
- **Startup cleanup** is less likely to add latency or contend with active user work: maintenance fetches now skip when the fetch lock is busy or agents are already running. [b5b158b7](https://github.com/aigentive/ralphx.app/commit/b5b158b7924f3d2fc24f04999c47496252edfbfd)
- **Theme and navigation hover states** are more visible across Dark, Light, and High-Contrast themes, including Theme/Font selectors, left rail icons, Agents sidebar Filters/Sort controls, and New/Add project buttons. [bc1eb82b](https://github.com/aigentive/ralphx.app/commit/bc1eb82b87e14327a3515ee4d3a75578751d6cde)

## Developer And Maintainer Changes

- Reworks several UI components from inline hover-blocking styles to className-driven Tailwind utilities, with updated component assertions. [bc1eb82b](https://github.com/aigentive/ralphx.app/commit/bc1eb82b87e14327a3515ee4d3a75578751d6cde)
- Adds hover micro-interaction visual coverage for topbar, rail, and Agents sidebar states across themes. [bc1eb82b](https://github.com/aigentive/ralphx.app/commit/bc1eb82b87e14327a3515ee4d3a75578751d6cde)
- Routes startup terminal cleanup through the shared GitService fetch path and adds coverage for no-origin, active-agent skip, busy-lock skip, and fetch-through-GitService branches. [b5b158b7](https://github.com/aigentive/ralphx.app/commit/b5b158b7924f3d2fc24f04999c47496252edfbfd)
- Adds focused regressions for publish dialog phase advancement and post-publish loading-state cleanup. [01036f51](https://github.com/aigentive/ralphx.app/commit/01036f518cc86e5d7a7f08a7bac2994b1de6a3c2)
