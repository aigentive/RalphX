# RalphX.app v0.75.0

RalphX.app 0.75.0 strengthens Workspace Review safeguards and recovery, reorganizes Settings and folder context, and clarifies publishing and delegation workflows.

## User-Facing Changes
- **Workspace Review** now runs only in Edit and Ideation workspaces, and blocks review starts during unfinished merges or rebases with guidance to complete or abort the Git operation first. [41d99885](https://github.com/aigentive/ralphx.app/commit/41d998853daf86d3e3743a49da239208c3eb19ee) [17bb162f](https://github.com/aigentive/ralphx.app/commit/17bb162f5b3f83a7b5e9080225f06af4ff2de154)
- **Claude MCP recovery** now removes the reserved user-scoped `ralphx` registration in-app, preserves the draft, files, and folders, then replays the original start after verified cleanup. [fe413fbb](https://github.com/aigentive/ralphx.app/commit/fe413fbb043fe78251f8f774d9093c85b9a8c402)
- **Settings and folder context** now make folder attachments available in supported Project and Persona Builder conversations, with Settings reorganized around Tasks, Planning, Workspace, Capacity, and External MCP. [7546da0c](https://github.com/aigentive/ralphx.app/commit/7546da0ca5c01df05ee2adfaafadbd9cc799a8ad)
- **Delegated subagents** now inherit compatible Delegated Subagent provider defaults for omitted model and effort fields; live activity reconciles one delegation job into one card and count, such as “delegated 1 agent.” [55317d9a](https://github.com/aigentive/ralphx.app/commit/55317d9ad229533e1a50ee57df5013212435c264) [42f77a28](https://github.com/aigentive/ralphx.app/commit/42f77a280f2af6a69967846e55419e8bc4f2902b)
- **Commit & Publish** now shows state-specific headings such as “Published to GitHub” and labels terminal diff history as “Published changes” or “Pull request changes,” rather than live workspace changes. [c2bf0353](https://github.com/aigentive/ralphx.app/commit/c2bf0353e5ae31d7d92aea91cee8e1cd1c46980f) [1acc2a0e](https://github.com/aigentive/ralphx.app/commit/1acc2a0ec8cbb67fc01a375ce89b7084e099803c)

## Fixes And Polish
- **Conversation startup** preserves the runtime shown in the composer while role defaults are still loading; a visible Codex selection no longer starts with a pending Claude default. [dce2ab84](https://github.com/aigentive/ralphx.app/commit/dce2ab841be55972c5487bdce1ab384e2e9c9372)
- **Agents sidebar** defaults to showing selected empty project groups and adds a persistent **Show empty groups** visibility toggle. [827566e4](https://github.com/aigentive/ralphx.app/commit/827566e44a1b7988707356680f50a35800d2c311)
- **Agent workspace UI** removes actionless “Plan approved” banners and keeps current historical Tasks and Ideation modes labeled and first in the existing-conversation picker. [a1f7a973](https://github.com/aigentive/ralphx.app/commit/a1f7a9730a6e2c57f8d4e58bbc8482606a7ebc6b)
- **Publish repair state** keeps Auto Publish, Autofix CI & Reviews, and GitHub auto-merge controls available while repair remains pending. [bf05b827](https://github.com/aigentive/ralphx.app/commit/bf05b827c6a1421cc03dcdbaeb3ff92017a116e1)
- **Artifact excerpts** now use rendered-text selection as the single flow, including ClickUp task content; excerpt chips persist after a rejected send and clear after acceptance. [51aac9be](https://github.com/aigentive/ralphx.app/commit/51aac9be12e1c7268a207689b0f37d1e36f430ea)
- **Workspace Review banners** now include **View transcript** when a local review transcript is available, without exposing it for Review PR workspaces. [6532aaf1](https://github.com/aigentive/ralphx.app/commit/6532aaf124850ed2f046d48fd71e6cbddda428a2)
