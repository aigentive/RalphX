# RalphX.app v0.80.0

RalphX.app 0.80.0 improves Agent-to-Plan continuation recovery, expands Claude model selection with pinned Opus releases, and strengthens delegated-work coordination.

## User-Facing Changes
- **Agent-to-Plan transitions** now stage a durable, backend-owned continuation so an accepted proposal resumes automatically with a Plan agent in the same conversation, including when the original Claude runtime remains alive after completing its turn. [b4a10111](https://github.com/aigentive/ralphx.app/commit/b4a1011113df025ac61ba22007fbebbcef09e253)
- **Claude model selection** now includes pinned `claude-opus-4-7`, `claude-opus-4-8`, and `claude-opus-5` choices across RalphX model controls; each is available only when the installed Claude Code CLI meets its required version. The moving `opus` alias remains a separate selection. [9fb22064](https://github.com/aigentive/ralphx.app/commit/9fb220643680851523cefdda56d568224f715924)

## Fixes And Polish
- **Plan-mode handoff recovery** now suppresses overlapping mode switches and duplicate continuation sends when the backend has already accepted or is handling the proposal. [b4a10111](https://github.com/aigentive/ralphx.app/commit/b4a1011113df025ac61ba22007fbebbcef09e253)

## Developer And Maintainer Changes
- **Workspace Review diagnostics** now emit phase-level timing logs for dialog preparation, confirmation, recovery, review startup, fixer routing, and auto-merge coordination. [cdb2b24e](https://github.com/aigentive/ralphx.app/commit/cdb2b24e858ff534564246c914f63379570a2588)
- **Delegating agents** now receive coordinator guidance covering bounded ownership, safe parallelism, serialized heavyweight validation, and integrated final review; non-delegating agents do not receive the appendix. [31e38234](https://github.com/aigentive/ralphx.app/commit/31e38234ef3d96c9430ae9a3a6166ae8db8c8133)
