# RalphX.app v0.19.1

RalphX.app 0.19.1 focuses on Agents UI responsiveness, PR workspace recovery, and MCP/CLI shutdown reliability.

## User-Facing Changes

- **Agents sidebar selection is steadier:** clicking an already-selected conversation no longer bounces back to the starter composer, and conversations loaded through “Load more” remain selectable without waiting on full history hydration. [459a1815](https://github.com/aigentive/ralphx.app/commit/459a181528584d305f5172abe18c7296ccbec022)
- **Composer interaction is lighter while typing:** diff-summary hydration now waits until the composer is idle, while the review/publish summary still appears progressively and the starter heading animation pauses during active composition. [459a1815](https://github.com/aigentive/ralphx.app/commit/459a181528584d305f5172abe18c7296ccbec022)
- **PR workspace supervision recovers more cleanly after races:** stalled published workspace rows can rearm into monitoring without spawning a duplicate fixer run for the same workspace. [21f9f573](https://github.com/aigentive/ralphx.app/commit/21f9f573e0bce713d3d68a2c8243aa6a8e1afa0a)
- **Agent workspace publish/status tools now resolve the active workspace conversation UUID directly:** agents can call `get_agent_workspace_status` and `publish_agent_workspace` without reverse-mapping IDs from folder suffixes or database state. [fedc942f](https://github.com/aigentive/ralphx.app/commit/fedc942f282e4bf5a8019fab7efc61905d7973b2)
- **Heavy agent sessions shut down with less local socket/process fallout:** MCP calls reuse backend connections, the Rust HTTP server drains on app exit, and Claude/Codex process trees receive group teardown, addressing the macOS ephemeral-port exhaustion path that could surface as `ERR_ADDRESS_INVALID` or backend loopback failures. [aeddcaf0](https://github.com/aigentive/ralphx.app/commit/aeddcaf09de804bf89c58dc87f49bec72ccd6122) [0aa41e15](https://github.com/aigentive/ralphx.app/commit/0aa41e1562d978a3f09bc94b6d88b9be24a4423b)

## Developer And Maintainer Changes

- **Dev/test networking is more deterministic:** Vite, HMR, `dev-fresh`, and Playwright now pin loopback behavior to IPv4, warn on stuck `TIME_WAIT` buildup for port `5173`, and give Playwright web servers a SIGTERM drain window. [aeddcaf0](https://github.com/aigentive/ralphx.app/commit/aeddcaf09de804bf89c58dc87f49bec72ccd6122)
- **MCP/backend lifecycle internals gained connection reuse and graceful shutdown coverage:** internal and external MCP servers install undici keep-alive pools, and the backend now uses a managed HTTP shutdown handle wired through Tauri exit events. [aeddcaf0](https://github.com/aigentive/ralphx.app/commit/aeddcaf09de804bf89c58dc87f49bec72ccd6122)
- **Agent harness process isolation is now provider-neutral:** Claude and Codex CLI spawns use Unix `setsid()` where available, safe process-group signalling, and explicit app-exit cleanup paths. [0aa41e15](https://github.com/aigentive/ralphx.app/commit/0aa41e1562d978a3f09bc94b6d88b9be24a4423b)
- **Regression coverage was expanded around the changed paths:** sidebar selection, deferred composer/publish hydration, bridge wakeup cleanup, shutdown trigger behavior, and clippy cleanup were updated alongside the fixes. [459a1815](https://github.com/aigentive/ralphx.app/commit/459a181528584d305f5172abe18c7296ccbec022) [aeddcaf0](https://github.com/aigentive/ralphx.app/commit/aeddcaf09de804bf89c58dc87f49bec72ccd6122) [0aa41e15](https://github.com/aigentive/ralphx.app/commit/0aa41e1562d978a3f09bc94b6d88b9be24a4423b)
