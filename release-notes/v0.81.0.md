# RalphX.app v0.81.0

RalphX.app 0.81.0 expands local-only Git workflows, adds explicit local commits, and makes PR publishing capability-aware.

## User-Facing Changes
- **Repository setup** now distinguishes GitHub-capable, local-only, and inspection-unavailable repositories; projects without an `origin` are treated as a supported local workflow, while inspection failures show repository-setup guidance. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)
- **Agent changes** now offer **Commit locally** for local-only and non-GitHub remotes, committing the isolated Agent workspace branch without pushing or merging the project base branch. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)
- **Publish controls** now choose between local commit and GitHub PR publication based on the repository’s current capability; local-only workflows no longer enter a PR path that cannot be completed. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)
- **Existing PR workflows** retain their linked PR when remote capability is temporarily unavailable, showing configuration guidance instead of relabeling the work as local-only or discarding PR state. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)

## Fixes And Polish
- **Local commits** use workspace-review gating and stale-result protection; repeated same-baseline requests report an already-committed result rather than creating a second commit. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)
- **Repository settings and project creation** now show local-first setup states, including an unconfigured remote and the backend-resolved base branch. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)

## Developer And Maintainer Changes
- Added shared repository-capability handling across backend, IPC/HTTP APIs, frontend models, fixtures, mocks, and focused workflow coverage for local commits, PR recovery, and local-project visual states. [6010816e](https://github.com/aigentive/ralphx.app/commit/6010816e5082f89df0f6f65f94f33d84e77a011b)
