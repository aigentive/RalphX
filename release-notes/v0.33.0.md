# RalphX.app v0.33.0

RalphX.app 0.33.0 improves multi-turn chat state, conversation-attributed workspace toasts, and execution-footer notification placement.

## User-Facing Changes

- **Interactive chat state now distinguishes waiting from generating:** retained multi-turn agents can show `awaiting input` instead of `running`; the composer keeps **Send** available while waiting and only shows **Stop** during active generation. [d5a5b41e](https://github.com/aigentive/ralphx.app/commit/d5a5b41ee8c9cf314b6263df5a80c0cdee64fa87)
- **Workspace operation toasts are attributed to conversations:** publish, rebase, and update-from-base feedback now uses stable conversation-aware titles with separate detail metadata instead of a single concatenated toast string. [1ebd30f0](https://github.com/aigentive/ralphx.app/commit/1ebd30f0d19a2854fcc2624a2e4d610e700603bf)
- **Update-from-base failures surface repair progress when available:** if the workspace has already moved into agent repair, the UI can show a repair-started info toast instead of only a terminal failure toast. [1ebd30f0](https://github.com/aigentive/ralphx.app/commit/1ebd30f0d19a2854fcc2624a2e4d610e700603bf)

## Fixes And Polish

- **Bottom-left toasts stay clear of chat content:** notification placement now keeps the left gutter while lifting above the execution footer. [1ebd30f0](https://github.com/aigentive/ralphx.app/commit/1ebd30f0d19a2854fcc2624a2e4d610e700603bf)

## Developer And Maintainer Changes

- Reworks the running-state IPC contract from booleans to structured `AgentRunningState` objects with `isRunning` and `agentStatus`, while keeping frontend normalization for legacy boolean responses. [d5a5b41e](https://github.com/aigentive/ralphx.app/commit/d5a5b41ee8c9cf314b6263df5a80c0cdee64fa87)
- Expands running-state hydration through backend registry and run-repository lookups, including bulk `get_by_ids` support and repository handling for runs moved back to `running`. [d5a5b41e](https://github.com/aigentive/ralphx.app/commit/d5a5b41ee8c9cf314b6263df5a80c0cdee64fa87)
- Adds frontend coverage for conversation-aware workspace toast payloads, update-from-base unmount fallback paths, and toaster placement behavior. [1ebd30f0](https://github.com/aigentive/ralphx.app/commit/1ebd30f0d19a2854fcc2624a2e4d610e700603bf)
