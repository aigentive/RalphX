# RalphX.app v0.92.0

RalphX.app 0.92.0 improves workspace repair recovery, keeps agent conversations and thinking views in sync, and strengthens native delegation and Team-mode workflows.

## User-Facing Changes
- **Workspace repair and PR supervision** now re-drive completed local repairs that were not yet published, heal recoverable continuation leases, and move unrecoverable attempts to an actionable blocked state instead of leaving them indefinitely pending. Repair retries also retain the prior human blocker and repair/base context rather than exposing internal scheduling markers. [efd19f78](https://github.com/aigentive/ralphx.app/commit/efd19f78e2bc0e09f37016f57b674528c32f3764) [57739ec4](https://github.com/aigentive/ralphx.app/commit/57739ec4313ec2a9bad8831e25e2a357f288ffd0) [6d847286](https://github.com/aigentive/ralphx.app/commit/6d847286464f4b5047b2ee8ecf6fe9d2b3a7757a)
- **Implement Directly** now performs a real Plan-to-Edit runtime handoff, retiring an idle Plan process so the next message starts an Edit-mode agent rather than receiving a Plan-mode response. [d7d31b3e](https://github.com/aigentive/ralphx.app/commit/d7d31b3e625c1a2d3552d816b681ff6655525c95)
- **Delegated specialist runs** can request bounded, read-only parent context on demand when context inheritance is authorized, including the immediate caller’s context for nested delegation. [52ae578e](https://github.com/aigentive/ralphx.app/commit/52ae578e25aa8b4c5494448a77b6f8acc9887901)
- **RX-Native Team mode** now resolves coordinator and member authority from persisted Team state, and leaving Team mode completes the staged Team exit before changing coordination mode. [8003ac67](https://github.com/aigentive/ralphx.app/commit/8003ac670bd3aa3bbad25ec3ce403187ecf403c9)
- **CI repair handling** now rejects deterministic test, lint, coverage, and code failures from transient-rerun treatment; it waits for an in-progress workflow run rather than spending rerun budget prematurely. [01894e21](https://github.com/aigentive/ralphx.app/commit/01894e21729399c31321f6ec36113cacfb39978f)

## Fixes And Polish
- **Plan-mode questions** from `ask_user_question` are visible again whether they arrive on the workspace conversation or attached planning session; answers return to the session that owns the active question. [69ecf548](https://github.com/aigentive/ralphx.app/commit/69ecf548d4132f300b11acbe884c167616158d36)
- **Workspace maintenance toasts** can be dismissed for the current operation, offer an **Open conversation** action, stay hidden while that conversation is visible, and truncate overly long progress details. [d0182877](https://github.com/aigentive/ralphx.app/commit/d0182877d42e92b359d1a79368d10bd9b2be7617)
- **Thinking blocks** remain expanded across live and hydrated conversations, group adjacent persisted entries, render inline bold text, and show Codex reasoning-token counts when reported. [d0e3d483](https://github.com/aigentive/ralphx.app/commit/d0e3d483c37a8e57136f98688a97ac220887084f)
- **Oversized implementation plans** no longer deadlock plan review: the judge requests one condensed revision, then evaluates the visible portion on later rounds. Terminal run diagnostics also prioritize the actual terminal cause over recovered tool noise. [b367aa07](https://github.com/aigentive/ralphx.app/commit/b367aa076b459ff9fffbfbfb60405b501963ef43)

## Developer And Maintainer Changes
- **Claude rule loading and CI selection** now use matching path scopes, keeping rule-only changes on automation/documentation lanes while preserving relevant product checks for frontend, Rust, plugin, coverage, and CodeQL changes. [e4f97e34](https://github.com/aigentive/ralphx.app/commit/e4f97e34b9bed9e1f7c8c688ea5a2dcffeef106a)
