# RalphX.app v0.28.0

RalphX.app 0.28.0 improves task-list history, workspace file navigation, and chat rendering/continuity behavior.

## User-Facing Changes

- **Tasks panel** now separates agent tasks by work slice: the current list stays first, while previous completed slices are grouped, collapsed by default, and loaded on expansion. [9153c72b](https://github.com/aigentive/ralphx.app/commit/9153c72b55d3a1d90f84aa2421421445b25d3ee3)
- **Workspace file references** now route through the code editor menu flow, making linked files actionable instead of inert. [cb93ec92](https://github.com/aigentive/ralphx.app/commit/cb93ec92c2d84567306aee933b5a5959506f921a)
- **Chat task widgets** preserve structured fields from trimmed tool-result previews, so task numbers, titles, badge counts, and empty-state copy remain meaningful even when large payloads are previewed. [7eb9c01d](https://github.com/aigentive/ralphx.app/commit/7eb9c01d14b9946f6ef4f9c5f02c57cdb1704a37)
- **Conversation continuity with attachments** now works when sending into terminal agent conversations that auto-fork; pending attachments are re-parented into the child conversation before send. [4ceb2291](https://github.com/aigentive/ralphx.app/commit/4ceb2291d2c8abbdd72637c96761b30c4e248f0d)
- **Chat markdown rendering** now preserves ASCII art, box-drawing diagrams, and flowcharts by rendering detected diagram-like paragraphs as monospace `<pre>` blocks. [617fc6a6](https://github.com/aigentive/ralphx.app/commit/617fc6a6956105d5ad1a10d509b5fc2bde7d9170)

## Fixes And Polish

- **Publish failure handling** now classifies wrapped git timeouts and similar transient operational failures as operational errors instead of incorrectly routing them into the agent repair flow. [1bee556e](https://github.com/aigentive/ralphx.app/commit/1bee556e745158b612ed884b6f20a71fd510c4ce)

## Developer And Maintainer Changes
