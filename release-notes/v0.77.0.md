# RalphX.app v0.77.0

RalphX.app 0.77.0 expands update-channel choice, makes startup progress explicit, and strengthens Agents, automation, and publishing workflows.

## User-Facing Changes
- **Updates** now support Stable and Nightly channels: Stable is the default, while Nightly is an opt-in channel with its own release history and update target. [ba1dbd67](https://github.com/aigentive/ralphx.app/commit/ba1dbd67da603fbbf35fdbb8c407ee9af448735e)
- **Startup** now shows a dedicated, backend-driven readiness experience instead of revealing the main shell before initialization is ready; failures can surface diagnostics, log access, and recovery actions. [9cac67b4](https://github.com/aigentive/ralphx.app/commit/9cac67b4c2af400fb65800ea9b0e397f69fb61f8)
- **Planning and task execution** are now centered in **Agents**: Plan, Tasks, Graph, and Kanban remain available as Agents artifacts, while standalone planning, task-detail, and battle-mode surfaces are retired. [fac87680](https://github.com/aigentive/ralphx.app/commit/fac87680e6df4c9a21883a61568a47ff478774f6)
- **Automations** can delete stuck runs or resume failed runs in place without discarding their conversation, worktree, or uncommitted changes; Smart Resume prefers reopening an eligible failed run. Run cards, task ledgers, and listings also use clearer status-driven layouts. [c52b877b](https://github.com/aigentive/ralphx.app/commit/c52b877bd680c607d6cdf6b1c1b44b57dc102a3c)
- **Commit & Publish** now shows a disabled `Publishing` state when background or Auto Publish work is already active, and preserves existing PR titles and descriptions unless an explicit metadata update is warranted. [fa6918e8](https://github.com/aigentive/ralphx.app/commit/fa6918e83ad45b5133cdb5116935f4d2f67c472a) [639e0861](https://github.com/aigentive/ralphx.app/commit/639e0861ce8449eb5f8bfcf078059bcffea7571f)

## Fixes And Polish
- **Launch reliability**: fixes a migration failure that could abort every startup for databases containing unrelated pre-existing foreign-key violations. [ac48f764](https://github.com/aigentive/ralphx.app/commit/ac48f76466908834145efe84dda7493cdbce61d4)
- **Agent chat** no longer breaks short user messages mid-word, and delegated-task cards remain singular and visible after conversation rehydration or snapshot suppression. [a1f4fab3](https://github.com/aigentive/ralphx.app/commit/a1f4fab35935945e17238b3d3a12e1065fa0243a) [d59c3202](https://github.com/aigentive/ralphx.app/commit/d59c32021a68a14b605a1b7bb4272cb44f1c9d45)
- **Workspace Review** now settles accepted review completions instead of remaining in `reviewing`, and the focused review chat immediately reflects the effort selected at launch rather than a stale Settings default. [bfb9ba28](https://github.com/aigentive/ralphx.app/commit/bfb9ba28b0c4b3505a3412bc2a6aa622275d0248) [c20b4fcf](https://github.com/aigentive/ralphx.app/commit/c20b4fcf285b7d6fbdec8dbb588e4deb8a3774f7)
- **Workspace diffs** now keep the selected mode’s count, file list, and range aligned—for example, clean worktrees with committed changes no longer show `Workspace changes (0 files)`. [af176ebf](https://github.com/aigentive/ralphx.app/commit/af176ebf3e8e6b737f50c84dd1f46a305160d3d0)
- **Publish feedback and recovery** now uses concise terminal toast details, resumes accepted PR-fix publication paths more reliably, and retains strict completion-authority checks. [58dd761c](https://github.com/aigentive/ralphx.app/commit/58dd761c776eaec0dd555e66416d5f34ca1d00cd) [4d4397e2](https://github.com/aigentive/ralphx.app/commit/4d4397e244e22bc7b37a63338b0339c13193c5f5)

## Developer And Maintainer Changes
- **Release operations** now separate Nightly publication from Stable promotion, including channel-specific updater manifests and Stable/Homebrew reconciliation; cask reconciliation also handles workflow-relative staged paths correctly. [ba1dbd67](https://github.com/aigentive/ralphx.app/commit/ba1dbd67da603fbbf35fdbb8c407ee9af448735e) [cc7cb70a](https://github.com/aigentive/ralphx.app/commit/cc7cb70aae71be81642ae5ab641f25ad7fc76dc1)
- **Supervision history** no longer records spurious `monitoring` rows for PR-autofix completion events, improving recovery replay and metrics accuracy without changing the user-facing workflow. [2178dd54](https://github.com/aigentive/ralphx.app/commit/2178dd544a1440ab9280d60d4bea5742bb3cbcca)
