# RalphX.app v0.50.0

RalphX.app 0.50.0 expands Granola note integration, adds Codex Fast mode controls, and smooths chat composer behavior.

## User-Facing Changes

- **Granola integration settings** now expose configuration, validation, and API-key guidance, with API keys stored through secure secret references instead of app responses or persistence. [a1649c79](https://github.com/aigentive/ralphx.app/commit/a1649c7941b1114d15828574b56dd7cd3f7adc5b)
- **Granola note references** can be carried through chat workflows and expanded into prompts for both direct sends and queued replay, including summary/transcript intent metadata. [a1649c79](https://github.com/aigentive/ralphx.app/commit/a1649c7941b1114d15828574b56dd7cd3f7adc5b)
- **Codex Fast mode** is now available in provider settings, composer controls, and active conversation runtime selection when the selected Codex model/provider reports support for it. [eaad73f5](https://github.com/aigentive/ralphx.app/commit/eaad73f53a1b2763db98aaf33d8be704ab95a2e0)
- **Codex conversation startup** now preserves the selected Fast mode service tier through frontend/backend payloads, agent run records, and Codex launch configuration. [eaad73f5](https://github.com/aigentive/ralphx.app/commit/eaad73f53a1b2763db98aaf33d8be704ab95a2e0)

## Fixes And Polish

- **Chat scrolling** now refreshes transcript layout when the composer collapses, expands, or settles, reducing oscillation when switching between normal and mini composer states near the bottom of an active conversation. [57b55cb3](https://github.com/aigentive/ralphx.app/commit/57b55cb3bc7d29870ecd3b665ee95bc157c9ff60)
- **Worker agent failures** now report more reliably when a worker agent fails. [a4fed3ef](https://github.com/aigentive/ralphx.app/commit/a4fed3ef783dd96516209e3836b27b780a993f70)

## Developer And Maintainer Changes

- Granola backend support adds settings persistence, SQLite/memory repositories, secure secret handling, AppState wiring, and Tauri get/save/validate commands. [a1649c79](https://github.com/aigentive/ralphx.app/commit/a1649c7941b1114d15828574b56dd7cd3f7adc5b)
- Integration reference expansion is generalized through provider dispatch while preserving existing Atlassian metadata and queue compatibility. [a1649c79](https://github.com/aigentive/ralphx.app/commit/a1649c7941b1114d15828574b56dd7cd3f7adc5b)
- Codex Fast mode adds service-tier fields across provider settings, IPC contracts, SQLite persistence, run models, and Codex CLI launch plumbing, with fixture updates for provider and start-conversation contracts. [eaad73f5](https://github.com/aigentive/ralphx.app/commit/eaad73f53a1b2763db98aaf33d8be704ab95a2e0)
- Composer layout regression coverage now exercises stale bottom refs, ResizeObserver wiring, and the custom composer layout callback path. [57b55cb3](https://github.com/aigentive/ralphx.app/commit/57b55cb3bc7d29870ecd3b665ee95bc157c9ff60)
