# RalphX.app v0.63.0

RalphX.app 0.63.0 focuses on Automation v2 plan-gated runs, Agent Team workflows, and Codex/Git recovery reliability.

## User-Facing Changes

- Automation runs are now visible and controllable from the Agents panel: the run ledger shows newest-first statuses with PR/error detail, open runs can be canceled individually, draft/paused automations can raise Max runs, and run rows surface phase chips, branch copy, and compact PR links. [c54bcb5d](https://github.com/aigentive/ralphx.app/commit/c54bcb5d941cfa61bbc60a74cf5db6c17b390e01)
- Automation implementation now goes through a per-run plan gate: runs provision in Plan mode, park at Awaiting plan approval, default to manual approval, can use an automatic plan judge/revision flow, can run deep plan verification, and can opt into GitHub native auto-merge where allowed. [c54bcb5d](https://github.com/aigentive/ralphx.app/commit/c54bcb5d941cfa61bbc60a74cf5db6c17b390e01)
- Agent conversations now have a plain Team switch in both new and existing composer surfaces; Team state persists on the conversation across creation, message sends, mode changes, queues, resumes, and app restarts instead of relying on legacy Claude-only behavior. [ea9b5a5f](https://github.com/aigentive/ralphx.app/commit/ea9b5a5fb85109c378499ce4db5d3341ff6b2f14)
- Plan-to-proposals activation now focuses the linked Ideation chat only for the conversation that triggered it, pins the returned ideation conversation, and avoids retargeting another conversation if async activation finishes after selection changed. [3eb83215](https://github.com/aigentive/ralphx.app/commit/3eb83215d2e83678dd848acf98a5efe4325ab289)
- Codex model selection adds GPT-5.6 family support for supported CLI/account catalogs, prefers `gpt-5.6-terra` when available, falls back to `gpt-5.5` on older installs, and shows provider/model-specific effort labels. [fb2f9a23](https://github.com/aigentive/ralphx.app/commit/fb2f9a23bb9775462c76d1ab4d2d07becbb65896)

## Fixes And Polish

- Starting a new Agent conversation now keeps the created conversation selected instead of returning to the starter/sidebar state. [a05169ba](https://github.com/aigentive/ralphx.app/commit/a05169bab5733f40d74b67c2066538dd449485fe)
- Plan and review guidance is more context-specific: approved-plan copy stays CTA-oriented in Plan mode, Plan approval prompts only render in Plan mode, and review disabled reasons live on the button tooltip instead of duplicated inline text. [219cd3de](https://github.com/aigentive/ralphx.app/commit/219cd3de1923fa98d71a48f2c598d79fef2b8688) [02d71e9e](https://github.com/aigentive/ralphx.app/commit/02d71e9e2e6872dcad7f5866a031078198905591) [a96a912a](https://github.com/aigentive/ralphx.app/commit/a96a912af61a35c4de42ddf7b20c9d82e1f7da79)
- The chat composer now uses slash-only skill invocation: mid-message `/skill-name` opens skill suggestions, `$` no longer opens the skill popover or triggers hidden internal skill directives, and provider-native insertion text is preserved after selection. [0f6bf9f8](https://github.com/aigentive/ralphx.app/commit/0f6bf9f84ba5ab9934529896b0c63dd148945338)
- Task detail history breadcrumbs are easier to navigate on long histories, with clipped-state left/right controls and chat/no-chat markers moved under each state so status labels stay readable. [8eddb612](https://github.com/aigentive/ralphx.app/commit/8eddb6122f1f0b9a4d52a0e714c62b2004b45ab2)
- Merge and reconciliation recovery now classify auth failures, disk-full errors, deterministic infra/database failures, target-branch-busy deferrals, and true transient git errors separately, so non-retryable failures park instead of burning automatic retry loops. [0f1adc8a](https://github.com/aigentive/ralphx.app/commit/0f1adc8a021b2ef1b234b255d85a8974291d12b8) [da828d5b](https://github.com/aigentive/ralphx.app/commit/da828d5b2b7628aa4ee6af6fd112b03298ae4b0c)

## Developer And Maintainer Changes

- Automation plan-gate internals were expanded with new run status/config/judge fields, CAS-guarded approval and delivery paths, MCP `update_automation` fields, scheduler hardening, and behavioral coverage for plan approval, review, publication, cancellation, and recovery paths. [c54bcb5d](https://github.com/aigentive/ralphx.app/commit/c54bcb5d941cfa61bbc60a74cf5db6c17b390e01)
- Security and diagnostics hygiene removed credential-adjacent harness metadata dumps and raw Codex override vectors from logs/assert messages while retaining fixed-key diagnostics. [c54bcb5d](https://github.com/aigentive/ralphx.app/commit/c54bcb5d941cfa61bbc60a74cf5db6c17b390e01)
- Git recovery maintainability now uses a shared classifier in git command and merge outcome paths, structured PR-mode recovery metadata, typed retry fixtures, and stronger provider-installer fake-CLI safeguards. [0f1adc8a](https://github.com/aigentive/ralphx.app/commit/0f1adc8a021b2ef1b234b255d85a8974291d12b8) [da828d5b](https://github.com/aigentive/ralphx.app/commit/da828d5b2b7628aa4ee6af6fd112b03298ae4b0c)
