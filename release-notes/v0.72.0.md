# RalphX.app v0.72.0

RalphX.app 0.72.0 focuses on provider-native MCP controls, a default-off Tasks switch, and clearer Agent workspace review and archive workflows.

## User-Facing Changes
- **Tasks controls** now default to off in Settings; Task-only settings and actions are hidden while approved Plans offer **Implement Directly**, with already-attached task pipelines allowed to finish. [61edd0ee](https://github.com/aigentive/ralphx.app/commit/61edd0ee55fcbcaa80b526a2f3b943e0f328b916)
- **MCP settings** now provide provider-scoped server and tool policies, including tri-state overrides and redacted diagnostics, while retaining provider-native configuration, trust, and authentication ownership. [8f1587d9](https://github.com/aigentive/ralphx.app/commit/8f1587d9f11511c854d5d8caf588acb8350d5f3c)
- **Workspace Review** now distinguishes an outdated prior Review from an authorized active refresh, and follows the effective **Reviewer** role runtime instead of a separate utility-model fallback. [86616863](https://github.com/aigentive/ralphx.app/commit/866168631a45b300b83f3258fe21cc62f46a5910) [e852b2d2](https://github.com/aigentive/ralphx.app/commit/e852b2d2ca6d960f652bc84049accccb4a39df0d)
- **Conversation archiving** now reports local workspace-cleanup status, including warnings when cleanup is pending or unsafe; bulk archive can include sessions with open remote pull requests while making local-deletion behavior explicit. [a7c55092](https://github.com/aigentive/ralphx.app/commit/a7c550929b4fa644336d88a63630114dffdae05b)
- **Agent role defaults** use compact overview rows and dedicated editors, showing each role’s description, inheritance source, local-override action, and unavailable-option context. [b60940d7](https://github.com/aigentive/ralphx.app/commit/b60940d7a04cc87c887de29c6658edfa05b9bf4f)

## Fixes And Polish
- **Notifications** now remain actionable until the exact Agent workspace or automation run is visible; permission notifications resolve the live pending request before opening its dialog. [7348798f](https://github.com/aigentive/ralphx.app/commit/7348798f1f56b9c7c696461d4b14166ebefde6ed)

## Developer And Maintainer Changes
- Rust CI now builds integration tests once and executes them through archived shards, with synchronized shard-topology guards and per-shard timing artifacts. [0ae00fbf](https://github.com/aigentive/ralphx.app/commit/0ae00fbf1cbd4f547c1d168c638e64eafb4fcf2b)
- Automation run documentation and scheduler regressions now distinguish current completed planning turns from stale completions, including the publishable-workspace rule for **Commit & Publish** on run conversations. [082fc38e](https://github.com/aigentive/ralphx.app/commit/082fc38ed8fed75206dffa258c5d93967b4b924b)
