# RalphX.app v0.64.0

This release improves execution-plan control, task/review correctness, and PR automation safety.

## User-Facing Changes
- **Plan tab:** shows explicit **Overview** and **Proposals** controls, so linked proposals no longer toggle the plan artifact implicitly. [f1742254](https://github.com/aigentive/ralphx.app/commit/f1742254f97730d29ba7c06a2f26c34d4e0f90b8)
- **Accepted plans:** provide confirmed, plan-scoped **Pause**, **Resume**, and **Stop** actions that affect only the current execution plan—not unrelated project work. [f1742254](https://github.com/aigentive/ralphx.app/commit/f1742254f97730d29ba7c06a2f26c34d4e0f90b8)
- **Task progress:** excludes skipped steps from displayed totals and renders active work as a faded animated segment; for example, one completed and one active step out of three completable steps displays solid progress to 33% and an active layer to 66%. [6716645c](https://github.com/aigentive/ralphx.app/commit/6716645cd3a8d1c689f9a432a795e85ffcfd8bbf)
- **Codex model selection:** preserves supported GPT-5.6 selections in the composer and workspace runtime, while validating provider aliases at launch and retry. [c8a84550](https://github.com/aigentive/ralphx.app/commit/c8a84550e44dd70db1c2c577ec488120136d784d)
- **Task review and validation:** evaluate task-owned changes against the immutable branch base captured when the task started; code-change tasks with an empty or missing authoritative diff now fail closed rather than completing successfully. [d25921c5](https://github.com/aigentive/ralphx.app/commit/d25921c5d80f01a1ea74c09a937df640b7ab8556)

## Fixes And Polish
- **PR autofix publishing:** resumes publishing to the existing PR after a passed Workspace Review only when that review still applies to the current workspace state; stale reviews no longer reopen publishing. [e5c85382](https://github.com/aigentive/ralphx.app/commit/e5c853823152d975a5c9e9f783f8dec35aa19783)
- **PR repair lifecycle:** stops active fixer runs when their PR is merged or closed, and temporarily disarms GitHub auto-merge before starting repair or correction work. [716b4ce5](https://github.com/aigentive/ralphx.app/commit/716b4ce5f8be077340da9ce740afa94b5b5df611)
- **Provider-aware runtime startup:** prevents disabled Claude configurations from launching during recovery, while chat-start availability recognizes configured RX-managed or custom Codex CLIs instead of relying only on PATH discovery. [b6df9425](https://github.com/aigentive/ralphx.app/commit/b6df94251a2295ce1bb4f031319afa3af260d3c3) [861ef31c](https://github.com/aigentive/ralphx.app/commit/861ef31cf057799811db1125ea48fe15e4a0131a)
