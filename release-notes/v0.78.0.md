# RalphX.app v0.78.0

RalphX.app 0.78.0 reworks Commit & Publish navigation, makes existing-PR description updates safer, and improves Workspace Review and agent runtime controls.

## User-Facing Changes
- **Commit & Publish** reworks its header into an action strip with an expanded **Changes, Review, Checks, History, and Automation** tab row; the active sub-tab now remains selected, and narrow layouts scroll the tab row instead of overflowing the pane. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Existing pull-request descriptions** now keep the reviewer-editable prefix separate from RalphX-managed Plan/signature content and later third-party footer content, allowing safe updates even when generated PR bodies are large. [3cb8a72a](https://github.com/aigentive/ralphx.app/commit/3cb8a72a8e8777861ac30c227f4714dfdb82865d)
- **Agent role settings** expand runtime selection with a shared provider picker and scoped runtime overrides. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Workspace Review** now blocks while Git operations are unfinished and avoids repair deadlocks when conflicts occur. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Usage statistics** correct agent usage accounting and mark uncounted totals as unavailable rather than displaying incorrect values. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)

## Fixes And Polish
- **Agent chat and delegate cards** wrap user messages correctly and rehydrate delegates without duplicate widgets after streaming or snapshot updates. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Publishing feedback** shows active publishing state and settles obsolete progress toasts instead of leaving orphaned notifications. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Startup migrations** no longer treat pre-existing foreign-key violations as migration damage, preventing affected databases from aborting app launch. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
- **Linked-PR publish failures** now name the linked target and accurately state that an unsafe description replacement was not applied, rather than implying no pull request exists. [3cb8a72a](https://github.com/aigentive/ralphx.app/commit/3cb8a72a8e8777861ac30c227f4714dfdb82865d)

## Developer And Maintainer Changes
- Aligns the PR-description backend flow, MCP schema, live prompt, and generated MCP package around the editable-description and preserved-suffix contract. [3cb8a72a](https://github.com/aigentive/ralphx.app/commit/3cb8a72a8e8777861ac30c227f4714dfdb82865d)
- Retires the legacy Claude-only team-mode implementation while preserving native team runtime behavior. [6650c136](https://github.com/aigentive/ralphx.app/commit/6650c136521b3e474ae498f6b3a7cf4440588c4a)
