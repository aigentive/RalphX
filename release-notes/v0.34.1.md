# RalphX.app v0.34.1

RalphX.app 0.34.1 improves large inline diff responsiveness, Commit & Publish diff review, and production-state repro workflows.

## User-Facing Changes
- Commit & Publish inline diffs now render large files through a single-scroll paged view, so merged PR conversations with very large source/test diffs should remain responsive instead of hanging WKWebView. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)
- Large non-generated file diffs can now be inspected incrementally, while generated files still require explicit user intent before hydration to avoid loading heavy patches accidentally. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)

## Fixes And Polish
- Inline diff paging now avoids nested scrolling and prunes out-of-view rows while preserving scroll geometry with spacer rows. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)

## Developer And Maintainer Changes
- Adds `./dev-fresh --from-prod-db` to seed local development from the installed app’s production SQLite DB, backing up the current dev DB, sanitizing runtime state, and disabling startup recovery for the seeded run. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)
- Expands backend and frontend coverage for the paged diff API, large-file fetch gating, single-scroll rendering, out-of-view cleanup, and generated-file override behavior. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)

## Known Issues
- Diff spacer heights are estimated from row height, so unusually wrapped rows can make scroll positioning approximate in very large inline diffs. [d1ee4f5c](https://github.com/aigentive/ralphx.app/commit/d1ee4f5c58f8ea9cb19b1791e0818d4f19606ec0)
