# RalphX.app v0.27.0

RalphX.app 0.27.0 focuses on agent conversation forking, clearer multi-task/chat rendering, and cleaner Git auth visibility.

## User-Facing Changes

- **Agent conversations can now be forked** from the composer actions menu or with `/fork`, with confirmation before creation and optional follow-up message handling in the new child conversation; forked conversations also carry model and effort metadata for more reliable runtime hydration. [a9d80ac5](https://github.com/aigentive/ralphx.app/commit/a9d80ac5dc8af6dfdb25846079b28a7b0a10d4b5)
- **Task composer progress is easier to scan** with `X/Y` task counts, completed-task checkmarks, an active-task spinner, and a “See N older tasks” pagination link when the visible task list fills up. [21c5566c](https://github.com/aigentive/ralphx.app/commit/21c5566c55200b9d61dc3d26ccb52d32e47d1296)
- **Live chat streams stay bounded and stable** during long-running turns: recent transcript content is windowed, active task cards remain pinned, and the visible stream no longer jumps while the user is scrolled away from the live tail. [0f52bafc](https://github.com/aigentive/ralphx.app/commit/0f52bafc5db1010a65ce71de4eaf3c6f5610520d)
- **Chat Markdown renders structured content more legibly**: tables fill the message container and wrap cells, code blocks and ASCII layouts avoid character-level wrapping artifacts, and prose keeps a readable width. [22251091](https://github.com/aigentive/ralphx.app/commit/2225109183d7cdee07ec254e234e96738dd2b060)
- **Git auth status is less noisy on Publish**: the Git auth card now hides when authentication is healthy and no blocking action is needed, while remaining available in Settings for SSH/HTTPS preference management. [63117119](https://github.com/aigentive/ralphx.app/commit/631171196d90d1b821a65361c3036b3a36b389b9)

## Developer And Maintainer Changes

- **Rust coverage publishing is more failure-safe**: lib coverage now runs in two matrix shards with separate artifacts, missing or empty coverage outputs fail closed, and Codecov publishing requires the relevant coverage jobs plus both Rust lib LCOV files. [09b80f30](https://github.com/aigentive/ralphx.app/commit/09b80f303eec068c566143eede0a02c7528baa48)
- **Focused test and visual coverage was updated** for the task composer progress/pagination states, fork session flows, streaming transcript windowing, Git auth surface visibility, and chat rendering snapshot changes. [21c5566c](https://github.com/aigentive/ralphx.app/commit/21c5566c55200b9d61dc3d26ccb52d32e47d1296) [a9d80ac5](https://github.com/aigentive/ralphx.app/commit/a9d80ac5dc8af6dfdb25846079b28a7b0a10d4b5) [0f52bafc](https://github.com/aigentive/ralphx.app/commit/0f52bafc5db1010a65ce71de4eaf3c6f5610520d) [63117119](https://github.com/aigentive/ralphx.app/commit/631171196d90d1b821a65361c3036b3a36b389b9) [22251091](https://github.com/aigentive/ralphx.app/commit/2225109183d7cdee07ec254e234e96738dd2b060)
