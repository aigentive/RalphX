# RalphX.app v0.57.1

RalphX.app 0.57.1 focuses on workspace review diagnostics, best-effort hunk annotations, and more accurate failed-review recovery.

## User-Facing Changes
- Workspace reviews are less likely to block on large review packets: reviewers can now annotate the hunks they actually inspect instead of needing coverage for every returned anchor. [71591466](https://github.com/aigentive/ralphx.app/commit/715914668b2d161c3b3137c0108a35f8de9d440b)
- Failed workspace-review runs now surface as failed reviews after startup or waiter reconciliation, rather than falling back to a generic missing-review state. [71591466](https://github.com/aigentive/ralphx.app/commit/715914668b2d161c3b3137c0108a35f8de9d440b)

## Fixes And Polish
- Preserved review failures are now scoped to the active review target/run, reducing the chance that stale terminal state is carried forward for the wrong target. [71591466](https://github.com/aigentive/ralphx.app/commit/715914668b2d161c3b3137c0108a35f8de9d440b)

## Developer And Maintainer Changes
- Updated the reviewer prompt and MCP tool schema to make partial hunk coverage an explicit contract: missing anchors are handled separately, and annotations are best-effort for inspected or important hunks. [71591466](https://github.com/aigentive/ralphx.app/commit/715914668b2d161c3b3137c0108a35f8de9d440b)
- Includes a base-sync PR with no additional user-facing product diff; planned PR artifact tab UX work was documented there but is not claimed as shipped in this release. [d7cc3491](https://github.com/aigentive/ralphx.app/commit/d7cc349110b5e8b800e5b5f9cb4b4e9fc7a5d127)
