# RalphX.app v0.94.1

RalphX.app 0.94.1 stabilizes chat scrolling with a pinned composer and keeps sidebar conversations visible when individual transcript reads fail.

## User-Facing Changes
- **Chat transcript layout** now keeps a constant-height message viewport while the composer remains pinned at the panel bottom; composer focus/blur and banner height changes no longer resize the viewport, preserving scroll position and empty/loading layouts. [696731dc](https://github.com/aigentive/ralphx.app/commit/696731dcc40a86a2a6a0e2aef3fc17a980f9d14e)
- **Chat scrolling** now accounts for the pinned composer inset, improving bottom-follow behavior after manual scroll-to-bottom actions and thinking or tool-group toggles. [696731dc](https://github.com/aigentive/ralphx.app/commit/696731dcc40a86a2a6a0e2aef3fc17a980f9d14e)
- **Sidebar conversations** continue to render when one conversation’s transcript hydration is unavailable, rather than suppressing the broader list. [277f006c](https://github.com/aigentive/ralphx.app/commit/277f006cde4311772b2df23ca2b628de8c164103)

## Developer And Maintainer Changes
- **Linked-worktree setup** now materializes symlinked MCP installs locally during `./dev-fresh` preparation, preventing symlinked dependencies from remaining in packaged output. [696731dc](https://github.com/aigentive/ralphx.app/commit/696731dcc40a86a2a6a0e2aef3fc17a980f9d14e)
- **CI coverage** now includes a dedicated Playwright integration job for the chat scroll lifecycle regression. [696731dc](https://github.com/aigentive/ralphx.app/commit/696731dcc40a86a2a6a0e2aef3fc17a980f9d14e)
