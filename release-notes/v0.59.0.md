# RalphX.app v0.59.0

RalphX.app 0.59.0 introduces Automations, improves Plan/chat conversation workflows, and hardens task/PR recovery paths.

## User-Facing Changes

- **Automations:** introduces a project-scoped Automations workflow with dedicated navigation, list/detail views, setup conversations, activation/finalize controls, run-now controls, run timelines, an artifact tab, scheduler/judge lifecycle support, and automation-owned conversations kept out of the generic Agents list. [7404350b](https://github.com/aigentive/ralphx.app/commit/7404350b3eebf97fff4ae901a90c84a9af0c4ab5)
- **Plan workspace:** moves plan import/start into the empty Plan tab, keeps chat-composer uploads on the normal attachment path, preserves explicit Plan-tab selection when the plan is empty, and hides the `View Plan` prompt until an attached plan artifact exists. [91a88e98](https://github.com/aigentive/ralphx.app/commit/91a88e981f8d6f55cbeba95fac2e82a7756d5c17), [93306ef8](https://github.com/aigentive/ralphx.app/commit/93306ef8836d733d6e947ec3173d52365b6d98a0)
- **Chat transcripts:** stabilizes active conversation switching by preferring timeline-backed transcript windows, refreshing the timeline when returning to a visible active conversation, and collapsing consecutive ordinary tool calls into `Agent called n tools`. [2061381b](https://github.com/aigentive/ralphx.app/commit/2061381b5c91ab4a9192b8c1f0fc64e40cb2dea9)
- **Agent composer state:** resets task-history state when switching to a different Agent conversation or returning to the starter composer, preventing unrelated conversations from inheriting a stale `Viewing historical state (read-only)` composer. [5e82c922](https://github.com/aigentive/ralphx.app/commit/5e82c92216c5c2ec7360ba40a49172805eeb675d)

## Fixes And Polish

- **PR supervision:** fixes behind-base plan PR handling so isolated linked plan worktrees can update from base and continue supervision, while the primary-checkout safety refusal still applies to the actual project checkout. [8b6dc8bf](https://github.com/aigentive/ralphx.app/commit/8b6dc8bf3bf6355727bf97769471d1559c667ddb)
- **Task execution recovery:** hardens backend recovery so stale or missing worktree state and freshness retry errors fail closed with structured diagnostics instead of falling through to ambiguous resume/spawn behavior. [bc50d56a](https://github.com/aigentive/ralphx.app/commit/bc50d56a07df6a535cd086c1f34e78551f7d144c)

## Developer And Maintainer Changes

- **Ideation test isolation:** moves ideation launch-plan and Claude command-builder tests onto fake/test-only seams so CI no longer depends on installed provider CLIs, while the real spawn guard remains enforced for production-facing paths. [f3822d17](https://github.com/aigentive/ralphx.app/commit/f3822d17b37d4d11ec71e74f9431dc29990a2321)
- **Automation platform plumbing:** wires automations through backend domain models, state machines, repositories/migrations, Tauri/HTTP command surfaces, MCP setup/judge agent surfaces, frontend API contracts/hooks, config, docs, and coverage scaffolding. [7404350b](https://github.com/aigentive/ralphx.app/commit/7404350b3eebf97fff4ae901a90c84a9af0c4ab5)
- **Regression coverage:** expands focused coverage across plan artifact gating, empty Plan-tab selection, chat timeline hydration, grouped tool rendering, composer resets, linked-worktree PR freshness, recovery retry metadata, freshness guard decisions, and retry error branches. [93306ef8](https://github.com/aigentive/ralphx.app/commit/93306ef8836d733d6e947ec3173d52365b6d98a0), [91a88e98](https://github.com/aigentive/ralphx.app/commit/91a88e981f8d6f55cbeba95fac2e82a7756d5c17), [2061381b](https://github.com/aigentive/ralphx.app/commit/2061381b5c91ab4a9192b8c1f0fc64e40cb2dea9), [5e82c922](https://github.com/aigentive/ralphx.app/commit/5e82c92216c5c2ec7360ba40a49172805eeb675d), [8b6dc8bf](https://github.com/aigentive/ralphx.app/commit/8b6dc8bf3bf6355727bf97769471d1559c667ddb), [bc50d56a](https://github.com/aigentive/ralphx.app/commit/bc50d56a07df6a535cd086c1f34e78551f7d144c)
