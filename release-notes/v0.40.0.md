# RalphX.app v0.40.0

RalphX.app 0.40.0 expands PR review workflows, Linear integration, and agent-workspace repair status handling.

## User-Facing Changes

- **Review PR mode** lets users start an agent conversation as a PR review workflow, with a dedicated review card showing review state, proposed actions, and submit/skip controls. Blank starts can use the default review prompt. [a376ed15](https://github.com/aigentive/ralphx.app/commit/a376ed15df70b961ce94af5d7ccddbc497107281)
- **Linear integration** adds a settings panel plus Linear issue reference support across search, conversation issue context, and message/reference rendering, including fixes so Linear references work after token save and use the current Linear issue search API. [25640534](https://github.com/aigentive/ralphx.app/commit/25640534839f514151fd79eefe630099ab059c7f)
- **PR review actions** now support RalphX-owned review workflows for Request Changes, Approve PR, or Skip decisions, with durable monitoring/action state instead of treating review approval as generic chat input. [a376ed15](https://github.com/aigentive/ralphx.app/commit/a376ed15df70b961ce94af5d7ccddbc497107281)
- **Workspace publish/repair status** now distinguishes a workspace that merely needs agent repair from one with a queued or started repair, so publish status better reflects what repair routing has actually happened. [0ae3318c](https://github.com/aigentive/ralphx.app/commit/0ae3318ca9ebe558f74633422ff2849629c2704f)

## Fixes And Polish

- **Deferred workspace repair** can resume when the active interactive slot becomes idle, covering both reusable interactive-process lifecycles and process-exit lifecycles. [0ae3318c](https://github.com/aigentive/ralphx.app/commit/0ae3318ca9ebe558f74633422ff2849629c2704f)
- **Linear UI/action guards** improve issue-panel behavior, empty client metadata handling, and provider-specific Jira search separation. [25640534](https://github.com/aigentive/ralphx.app/commit/25640534839f514151fd79eefe630099ab059c7f)
- **Plan-mode verification and auto-publish test cleanup** resolve release-blocking validation issues around the Linear integration work. [25640534](https://github.com/aigentive/ralphx.app/commit/25640534839f514151fd79eefe630099ab059c7f)

## Developer And Maintainer Changes

- Adds backend domain, repository, migration, HTTP/MCP, and frontend API/UI coverage for `review_pr` as a first-class agent conversation mode. [a376ed15](https://github.com/aigentive/ralphx.app/commit/a376ed15df70b961ce94af5d7ccddbc497107281)
- Adds Linear conversation issue domain, repositories, service wiring, webhook/workflow-state reconciliation, external issue link storage, and expanded test coverage for Linear client, command, webhook, workflow, and patch paths. [25640534](https://github.com/aigentive/ralphx.app/commit/25640534839f514151fd79eefe630099ab059c7f)
- Splits workspace repair failure classification so queue indicators are derived from persisted repair events instead of `needs_agent` alone, with regression coverage for running-update rejection and idle-vs-running repair waits. [0ae3318c](https://github.com/aigentive/ralphx.app/commit/0ae3318ca9ebe558f74633422ff2849629c2704f)
