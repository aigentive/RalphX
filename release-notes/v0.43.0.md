# RalphX.app v0.43.0

RalphX.app 0.43.0 improves agent conversation entry points, composer skill discovery, and chat/publish review workflows.

## User-Facing Changes

- **Agent conversations from Plan:** the command-palette quick action now opens the Agents start composer prefilled in edit mode instead of immediately creating an ideation session, so users can review before sending. [a5a9b353](https://github.com/aigentive/ralphx.app/commit/a5a9b35377a5215f255996f9c9aa1cce8d9b112b)
- **Composer skills through `/`:** the agent composer now uses slash as the shared discovery surface for commands and skills while preserving provider-native send text, including Claude `/plugin:skill`, Codex `$skill`, and RalphX internal directives; enabled Claude plugin skills can appear in the same menu. [228731ba](https://github.com/aigentive/ralphx.app/commit/228731ba587cd5f6a6de4da774d5e19e7afa0993)
- **Agent issue reporting:** selected agent conversations now expose a left-rail Report Issue flow that builds a reviewable Markdown support report with redaction summaries, edit/preview, copy/export actions, and confirmed GitHub issue submission to the resolved destination. [6cb434ff](https://github.com/aigentive/ralphx.app/commit/6cb434ffe0fd5506326c6dc9e7ca82bde0cbd8c3)
- **Commit & Publish annotation focus:** the inline diff now opens on the first synced GitHub annotation in long publish reviews, focusing the annotated file first and then centering the annotation row once rendered. [038d3550](https://github.com/aigentive/ralphx.app/commit/038d3550dd6a558e226edd64c197b617d73c69ae)
- **Chat tool-call summaries:** chat timelines now render a consistent collapsible summary for one-tool and multi-tool groups, with stable expand/collapse scroll anchoring in both persisted and live streaming paths. [cb50fa83](https://github.com/aigentive/ralphx.app/commit/cb50fa83324aa401895a3702cffcefa1c2b7ddb5) [93b01f2b](https://github.com/aigentive/ralphx.app/commit/93b01f2b0f01573f9e847e4c3485dfcc7b31c67f)

## Fixes And Polish

- **Kanban task creation:** creating a task without an associated plan/ideation session now accepts `ideation_session_id: null` and no longer fails with `Invalid input: expected string, received null`. [e6aa11fa](https://github.com/aigentive/ralphx.app/commit/e6aa11fa948bd35c9ce8ac1e7bb02891a227dd25)
- **Conversation switching during streaming:** returning to an active streaming conversation now shows persisted streamed messages immediately while hydration completes, avoiding a temporary timeline gap. [be17164a](https://github.com/aigentive/ralphx.app/commit/be17164a2be0a9c342b4f93e8a10769c420c1246)
- **Publish/base-update toasts:** in-flight publishing progress toasts now keep the conversation title captured at operation start instead of changing when a different conversation is selected. [a92056b9](https://github.com/aigentive/ralphx.app/commit/a92056b92c29ba4ff1f3f31e1ef0ed169f0d8abe)
- **Plan approval CTA:** single-action plan approval cards, including “Approve draft plan”, now use a compact one-line layout with hint text and button on the same row. [28ea8583](https://github.com/aigentive/ralphx.app/commit/28ea8583cee36d32ae4facf7778300d27127c8f0)

## Developer And Maintainer Changes

- **Regression coverage:** expands targeted coverage for chat timeline anchoring, single-tool summaries, streaming hydration, composer skill insertion, GitHub annotation auto-scroll, Kanban null-session parsing, and agent issue-report paths. [93b01f2b](https://github.com/aigentive/ralphx.app/commit/93b01f2b0f01573f9e847e4c3485dfcc7b31c67f) [cb50fa83](https://github.com/aigentive/ralphx.app/commit/cb50fa83324aa401895a3702cffcefa1c2b7ddb5) [6cb434ff](https://github.com/aigentive/ralphx.app/commit/6cb434ffe0fd5506326c6dc9e7ca82bde0cbd8c3)
- **Publish-state bookkeeping:** records a repaired/republished branch state for existing PR supervision; the source packet reports no product code diff or runtime/UI impact for this item. [f0c6d737](https://github.com/aigentive/ralphx.app/commit/f0c6d737219adbd5c74b1fef719247772e80a2c1)
