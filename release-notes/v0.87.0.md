# RalphX.app v0.87.0

RalphX.app 0.87.0 improves agent-run transparency, restores Claude thinking visibility and progress, and surfaces database maintenance controls in Settings.

## User-Facing Changes
- **Agent turns** now show elapsed work time live (for example, “Agent working for 42s”) and a completed, expandable duration summary with provider, model, effort, capabilities, cost, token, and timing details. [a9145557](https://github.com/aigentive/ralphx.app/commit/a9145557c6d1662a3d74da2749502a8e18d4b592)
- **Role-scoped feedback runs** now target the active review, fixer, or edit runtime in the composer, then restore the conversation runtime after the role run settles. [a9145557](https://github.com/aigentive/ralphx.app/commit/a9145557c6d1662a3d74da2749502a8e18d4b592)
- **Settings → Application → Database** now exposes database size, reclaimable space, and scheduled compaction controls that were previously inaccessible in the live Settings dialog. [41a7cd91](https://github.com/aigentive/ralphx.app/commit/41a7cd9198cb746afd190f1fd86337e9c2215bba)
- **Claude thinking** now renders summarized thinking text, persists correctly when conversations are rehydrated, and shows active token estimates such as “Agent thinking… · ~2,000 tokens.” [b5e54723](https://github.com/aigentive/ralphx.app/commit/b5e54723e5700be1d01db0a7b241bbb9ba5358ba)

## Developer And Maintainer Changes
- Agent-run attribution now persists agent identity and launch role, with a migration and attribution API backing the conversation UI. [a9145557](https://github.com/aigentive/ralphx.app/commit/a9145557c6d1662a3d74da2749502a8e18d4b592)
