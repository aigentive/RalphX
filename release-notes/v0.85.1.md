# RalphX.app v0.85.1

RalphX.app 0.85.1 reworks the Agents inbox, improves recovery from component-load and workspace-publish failures, and polishes Settings.

## User-Facing Changes
- **Agents inbox** now uses three filters—Recent, Stale, and Done—with Recent grouping **Needs you** and **Working** into separate sections with independent “Load older” pagers. [a6477799](https://github.com/aigentive/ralphx.app/commit/a6477799a2eeaebc20f6f443c0f1ce874f37153b)
- **Agent selection** no longer causes inbox rows to move, disappear, or reappear; Stale and Done filter choices are also preserved across sessions. [a6477799](https://github.com/aigentive/ralphx.app/commit/a6477799a2eeaebc20f6f443c0f1ce874f37153b)
- **Lazy-loaded app areas** retry a transient module-load failure once after 350 ms; if loading still fails, the error screen identifies the issue and offers **Reload** and **Try Again**. [51ccda1e](https://github.com/aigentive/ralphx.app/commit/51ccda1e57cc71531e585d025d9e2799e2c8b215)
- **Workspace publishing and repair** no longer remain stuck after transient publish contention; Ready-phase repairs retry with backoff, and failing CI checks trigger repair dispatch or surface an actionable blocked state. [ff6f5720](https://github.com/aigentive/ralphx.app/commit/ff6f5720186df00b4b5fc3b462cb57ef589408af)

## Fixes And Polish
- **Settings** now use a more consistent card hierarchy across Agents, Tasks, Planning, Capabilities, and Personas; headings include clearer labels such as “Role defaults,” “Task policies,” and “Plan verification.” [89fb4629](https://github.com/aigentive/ralphx.app/commit/89fb4629701bc6075f173f3d1f964a0f7a585be9)
- **Settings feedback** now shows an empty MCP state when the selected provider has no configured servers, and fixes toggle-knob overhang and icon-input padding. [89fb4629](https://github.com/aigentive/ralphx.app/commit/89fb4629701bc6075f173f3d1f964a0f7a585be9)
- **Workspace operation toasts** can now be dismissed reliably, including after pane changes. [ff6f5720](https://github.com/aigentive/ralphx.app/commit/ff6f5720186df00b4b5fc3b462cb57ef589408af)

## Developer And Maintainer Changes
- Adds visual regression coverage for the Recent inbox’s sticky headers and independent group pagination. [a6477799](https://github.com/aigentive/ralphx.app/commit/a6477799a2eeaebc20f6f443c0f1ce874f37153b)
- Adds regression coverage for concurrent workspace-repair publishing and Ready-phase recovery behavior. [ff6f5720](https://github.com/aigentive/ralphx.app/commit/ff6f5720186df00b4b5fc3b462cb57ef589408af)
