# RalphX.app v0.93.0

RalphX.app 0.93.0 expands Jira ticket context, stabilizes agent-workspace publishing recovery, and keeps follow-up messages on active interactive processes.

## User-Facing Changes
- **Jira issue details in Agents** now show acceptance criteria and comments when available, with a clear “No acceptance criteria” state after an issue has loaded. [69839419](https://github.com/aigentive/ralphx.app/commit/69839419c745003112d068458f4591a1ca9365fe)
- **Agent Jira references** now include acceptance criteria plus bounded recent-comment context, including author and timestamp metadata, so ticket work starts with more of the issue’s relevant context. [69839419](https://github.com/aigentive/ralphx.app/commit/69839419c745003112d068458f4591a1ca9365fe)
- **Agent workspace publishing** now recovers stale publish ownership and re-drives unpublished rebased repairs, reducing cases where a repaired workspace remains blocked without manual intervention. [a3473c22](https://github.com/aigentive/ralphx.app/commit/a3473c223e4658f9f990231feb1faff9de67fe89)

## Fixes And Polish
- **Workspace repair status** now distinguishes repairs waiting for new CI evidence from automatic publish redrives; an automatic re-publish after a rebase is shown as in progress rather than as a manual action. [a3473c22](https://github.com/aigentive/ralphx.app/commit/a3473c223e4658f9f990231feb1faff9de67fe89)
- **Messages sent during an active interactive process** now stay with the live process when the requested model matches it, even if an older completed run used another model; genuine model changes continue to queue for a fresh provider session. [8237fbf0](https://github.com/aigentive/ralphx.app/commit/8237fbf0b3b3bbb45b4a6400be8199f3648a165a)

## Developer And Maintainer Changes
- Jira acceptance-criteria fields are discovered from Jira’s field catalog, with description-based extraction retained as a fallback; existing Jira-linked records are backfilled for refresh. [69839419](https://github.com/aigentive/ralphx.app/commit/69839419c745003112d068458f4591a1ca9365fe)
- Workspace publishing now uses lease ownership, fencing, and heartbeats across recovery, startup, polling, and terminal cleanup paths. [a3473c22](https://github.com/aigentive/ralphx.app/commit/a3473c223e4658f9f990231feb1faff9de67fe89)
