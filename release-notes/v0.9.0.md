# RalphX.app v0.9.0

RalphX.app 0.9.0 adds provider onboarding, improves agent conversation startup, and stabilizes chat tool and publish workflows.

## User-Facing Changes

- **Provider setup is now explicit before agents run.** The new `Harness > Providers` settings flow guides users through enabling Codex or Claude, validates CLI availability, applies the first enabled provider as the default, and limits Execution and Ideation lane choices to enabled providers. [4489751a](https://github.com/aigentive/ralphx.app/commit/4489751aacfedb2f40819eeda5bab76317d869f4)

- **Agent conversations now start optimistically.** The first submitted message appears immediately in the new conversation with the selected provider/model/effort metadata and active running/stop state, then reconciles with backend events without duplicating the starter message. [05cafe21](https://github.com/aigentive/ralphx.app/commit/05cafe2145c3c025618f6a601e3e15251444d763)

- **The agent Start from selector now preserves branch context.** RalphX shows cached branch choices while refreshing, remembers the last valid branch selection per project, and avoids falling back to the default branch while branch data is still loading. [05cafe21](https://github.com/aigentive/ralphx.app/commit/05cafe2145c3c025618f6a601e3e15251444d763)

- **Chat tool output renders more consistently during long runs.** Streaming text, tool widgets, task cards, and typing state now stay grouped inside one assistant row with the bot icon, and previewed `bash`/read/search-style calls keep their specialized widgets instead of collapsing into a generic preview card. [2bf50fb7](https://github.com/aigentive/ralphx.app/commit/2bf50fb7420144bdf8fdf63383f4841fbe262c4e) [135e0d93](https://github.com/aigentive/ralphx.app/commit/135e0d93138d61aa44c4e3392fddb0f7050a2eba)

- **Ideation and publish workflows are easier to recover and resize.** The desktop Ideation Plan Browser sidebar now has a draggable persisted width with double-click reset, and blocked publish branches can be recovered with a Rebase branch action when the saved base is no longer contained in the default branch. [743e4942](https://github.com/aigentive/ralphx.app/commit/743e4942e8e9f1d2eba89becd2c97442746c87dc) [6f39dc86](https://github.com/aigentive/ralphx.app/commit/6f39dc869ac847a70e3d5badf2c80cf3ae37a524)

## Fixes And Polish

- **Terminal PR-backed workspaces leave fewer local artifacts behind.** Merged PR-backed plan branches and terminal agent workspaces now get non-fatal cleanup attempts from live pollers and startup recovery, while dirty, unexpected, closed-unmerged, or non-RalphX-owned artifacts are preserved. [60a275dd](https://github.com/aigentive/ralphx.app/commit/60a275dd8cf32942f9c1c5c0b1f9f988aa11ed9e)

## Developer And Maintainer Changes

- Release automation now appends GitHub-generated contributor metadata, PR attribution, first-time contributor callouts, and changelog links to public GitHub Release notes while keeping in-app updater notes concise. [41607dcd](https://github.com/aigentive/ralphx.app/commit/41607dcdff8a057c57b1c76fc457f8df49b39144)
