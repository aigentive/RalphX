# RalphX.app v0.34.0

RalphX.app 0.34.0 improves chat diff previews, stabilizes chat replay/sidebar behavior, and polishes Agents workspace notifications and runtime selection.

## User-Facing Changes

- **Chat edit/write cards** now show compact diff hunk previews while collapsed, then render a tighter read-only full diff when expanded; confirmed new-file writes can be labeled as new-file diffs instead of baseline errors. [142625d2](https://github.com/aigentive/ralphx.app/commit/142625d2ac9bf3d8a64c168e03247bd653c1afb6)
- **Chat replay and live chat scrolling** now settle at the bottom only when the last rendered row is actually visible, reducing unwanted jumps while reading earlier messages. [248fa55d](https://github.com/aigentive/ralphx.app/commit/248fa55db853e357deecb4f8a99785108235f73c)
- **Agents sidebar ordering and pagination** now keep real pinned conversations ahead of temporary selected fallback rows, reducing reshuffles and scroll-position disruption when switching workspace conversations. [86cec021](https://github.com/aigentive/ralphx.app/commit/86cec0217f478e508522678654a68b43279f7ef7)
- **Single-project Agents sidebar views** now use the available vertical space more effectively instead of leaving unused list area under the remaining project group. [daf8cdab](https://github.com/aigentive/ralphx.app/commit/daf8cdabe17c894ff67feef9880cf9bc1f862811)
- **Agent composer runtime selection** now scrolls internally on shorter screens, so model and effort options that previously clipped below the viewport remain reachable. [ef4a6c5e](https://github.com/aigentive/ralphx.app/commit/ef4a6c5eab71af23cdffc684513a5f5f9337d134)

## Fixes And Polish

- **Workspace update/rebase toasts** now stay tied to the operation instead of the publish panel lifecycle, so switching conversations no longer leaves a stale loading toast; dismissed loading toasts also stay dismissed. [5fc3a44b](https://github.com/aigentive/ralphx.app/commit/5fc3a44b203d5f9c20e851fa6fdb32598086b65f)
- **Chat replay snapshots** now wait for the rendered bottom state before capture, reducing visual-test flake from in-between scroll positions. [248fa55d](https://github.com/aigentive/ralphx.app/commit/248fa55db853e357deecb4f8a99785108235f73c)

## Developer And Maintainer Changes

- Expanded regression coverage for workspace operation toast lifecycle, chat scroll intent and bottom-settle branches, sidebar priority-vs-pinned ordering, runtime popover overflow, and chat diff preview parsing/rendering paths. [5fc3a44b](https://github.com/aigentive/ralphx.app/commit/5fc3a44b203d5f9c20e851fa6fdb32598086b65f) [248fa55d](https://github.com/aigentive/ralphx.app/commit/248fa55db853e357deecb4f8a99785108235f73c) [86cec021](https://github.com/aigentive/ralphx.app/commit/86cec0217f478e508522678654a68b43279f7ef7) [ef4a6c5e](https://github.com/aigentive/ralphx.app/commit/ef4a6c5eab71af23cdffc684513a5f5f9337d134) [142625d2](https://github.com/aigentive/ralphx.app/commit/142625d2ac9bf3d8a64c168e03247bd653c1afb6)
- Updated Agents visual fixtures and cache/query-key handling so sidebar visual coverage continues to hydrate seeded data after the pagination and sizing changes. [86cec021](https://github.com/aigentive/ralphx.app/commit/86cec0217f478e508522678654a68b43279f7ef7) [daf8cdab](https://github.com/aigentive/ralphx.app/commit/daf8cdabe17c894ff67feef9880cf9bc1f862811)
