# RalphX.app v0.51.0

RalphX.app 0.51.0 expands GitHub/Granola visibility, improves branch-linked conversation starts, and stabilizes review, repair diff, terminal, and chat workflows.

## User-Facing Changes

- **GitHub workspace visibility** now has its own main-nav surface, defaulting to PRs with a secondary Branches mode; PR detail overlays can show description, comments, review/check context, and attached RalphX conversations. [b5288747](https://github.com/aigentive/ralphx.app/commit/b5288747ef48e9062b971178d012a6e22ae33bcf)
- **Granola, GitHub, and Ticketing associations** now share a dense list + overlay pattern: rows surface connected RX conversations, tickets, PRs, and Granola notes without forcing section navigation. [b5288747](https://github.com/aigentive/ralphx.app/commit/b5288747ef48e9062b971178d012a6e22ae33bcf)
- **New chat starts from selected branches or PRs** can now preserve the selected branch as a linked workspace, while default/current-branch starts remain isolated; publish copy now distinguishes creating a new PR from updating an already-linked PR. [ce3a53be](https://github.com/aigentive/ralphx.app/commit/ce3a53beeb2a51876cd66f25d0326d601e2a414b)
- **Plan and review workflows** now allow draft plan verification before approval, keep Review consistently before Commit & Publish, refresh Review after related runtimes finish, and scope review running state to the active conversation. [6a635968](https://github.com/aigentive/ralphx.app/commit/6a635968d00f552d27f8dbef469c6552907d07a5) [3a5fe848](https://github.com/aigentive/ralphx.app/commit/3a5fe848d10fa84c11237b1fd4bb09e9d2fafdd1)
- **PR publishing** now routes programmatic PR descriptions through the PR describer agent across publish and recovery flows; if describer output is unavailable, publication stops instead of silently using generic fallback text. [eb4ca6f4](https://github.com/aigentive/ralphx.app/commit/eb4ca6f45e847a7bf26533b6b3b17e3129a2d752)

## Fixes And Polish

- **Repair-mode diffs** now avoid eagerly rendering very large or conflict-heavy diffs, keep paged loading for staged/unstaged repair views, and show a lightweight shell before explicit full rendering. [24eb0eab](https://github.com/aigentive/ralphx.app/commit/24eb0eab2f5527a952675ab7a4751f76b2f4362d)
- **Execution bar terminal tracking** now follows terminal session status instead of drawer expansion state, so collapsed running terminals remain visible and explicitly closed terminals disappear. [9766e970](https://github.com/aigentive/ralphx.app/commit/9766e970db6c3d4959232dd2700af6835cd3d8e4)
- **Chat auto-scroll** now better preserves bottom-follow after manual scroll-away and return-to-bottom actions, reducing jitter during live appends, resize changes, streaming, and hydration. [de61d9fd](https://github.com/aigentive/ralphx.app/commit/de61d9fd6b960138e4917f032b3762cb55a02871)

## Developer And Maintainer Changes

- Added branch-mode plumbing across the frontend API, Rust domain model, SQLite storage, workspace lookup/reuse logic, and IPC coverage for linked vs. isolated conversation workspaces. [ce3a53be](https://github.com/aigentive/ralphx.app/commit/ce3a53beeb2a51876cd66f25d0326d601e2a414b)
- Built out the GitHub PR detail/read-model layer, `gh`-backed status/detail commands, PR/RX association queries, and React Query-backed frontend data surfaces. [b5288747](https://github.com/aigentive/ralphx.app/commit/b5288747ef48e9062b971178d012a6e22ae33bcf)
- Expanded targeted regression coverage for repair diff hydration, terminal lifecycle filtering, chat scroll ownership, workspace review refresh/state scoping, and PR describer failure/recovery paths. [24eb0eab](https://github.com/aigentive/ralphx.app/commit/24eb0eab2f5527a952675ab7a4751f76b2f4362d) [9766e970](https://github.com/aigentive/ralphx.app/commit/9766e970db6c3d4959232dd2700af6835cd3d8e4) [de61d9fd](https://github.com/aigentive/ralphx.app/commit/de61d9fd6b960138e4917f032b3762cb55a02871) [3a5fe848](https://github.com/aigentive/ralphx.app/commit/3a5fe848d10fa84c11237b1fd4bb09e9d2fafdd1) [eb4ca6f4](https://github.com/aigentive/ralphx.app/commit/eb4ca6f45e847a7bf26533b6b3b17e3129a2d752)
