# RalphX.app v0.29.0

RalphX.app 0.29.0 focuses on smoother streaming chat, scalable agent navigation, and clearer publish/review states.

## User-Facing Changes

- **Chat streaming stays pinned more reliably** while users follow the bottom of a conversation, including footer growth from typing/activity indicators, pending tool output, child-task results, and streaming transcript updates. [f562e049](https://github.com/aigentive/ralphx.app/commit/f562e049a6d1d0a563e5e777475b43ababa66e5a) [9be391e0](https://github.com/aigentive/ralphx.app/commit/9be391e07db7d88bac5d4cca021c56bec43c6b25) [68cfcf90](https://github.com/aigentive/ralphx.app/commit/68cfcf90ce38f01e75b461f1cf8f9ce510483c12)
- **Large agent sidebar lists are virtualized and paginated**, rendering only the visible row window, auto-loading the next page at the end of the list, and preserving scroll position when switching between project or publication groups. [59c37ae3](https://github.com/aigentive/ralphx.app/commit/59c37ae37b55708b8d5d4e3191e8667edfd21c0d)
- **The publish panel leaves more room for code review** by condensing branch, base, PR link, mode, and status into a single metadata strip, for example `agent-19e → main | PR #42 ↗ | Edit | Active`. [fb16ba83](https://github.com/aigentive/ralphx.app/commit/fb16ba83fcc90ce29bf1e00626d2aabcb2de34fc)
- **Publish recovery handles more Git failure states clearly**, routing dirty-worktree merge aborts such as “would be overwritten by merge” into the agent-fixable repair flow and showing “Auto-merge deferred” with a warning icon instead of an indefinite spinner when auto-merge cannot be enabled immediately. [826305c8](https://github.com/aigentive/ralphx.app/commit/826305c8485c2393a4e69a88a6def441f67774c3) [2fa88a29](https://github.com/aigentive/ralphx.app/commit/2fa88a29c980f2f0c04225f63cc81fc77ea1ddd7)
- **Agent task ledgers now enforce meaningful decomposition**: non-trivial work can no longer collapse into a single claimed task, while genuinely single-step work is guided toward dropping the unnecessary ledger item. [d6ad69e3](https://github.com/aigentive/ralphx.app/commit/d6ad69e332c6dc9d2f8c58d4b9c7556b1bb9ab2d)

## Fixes And Polish

- **Resumed Claude conversations keep their live idle process during read-only polling**, reducing the chance that a follow-up turn reuses stale or repeated assistant output instead of continuing the active conversation. [4556d7af](https://github.com/aigentive/ralphx.app/commit/4556d7afc22b1cbf99fc898e90e69484b2d17d38)
- **Ideation ask-question widgets render with more stable non-compact geometry**, improving visual consistency in chat rows. [68cfcf90](https://github.com/aigentive/ralphx.app/commit/68cfcf90ce38f01e75b461f1cf8f9ce510483c12)

## Developer And Maintainer Changes

- Expanded focused coverage for chat bottom-pinning, render-ready cache handoff, streaming window advancement, sidebar virtualization, publish state classification, deferred auto-merge rendering, task-ledger guardrails, and ask-question widget layout. - Regenerated and aligned MCP task-tool artifacts so the published MCP package matches the updated task decomposition guidance. [d6ad69e3](https://github.com/aigentive/ralphx.app/commit/d6ad69e332c6dc9d2f8c58d4b9c7556b1bb9ab2d)
