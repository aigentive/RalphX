# RalphX.app v0.41.0

RalphX.app 0.41.0 focuses on Insights metrics, smoother chat transcripts, and clearer agent workspace controls.

## User-Facing Changes
- **Insights now defaults to an all-project view** with project-scoped filtering, searchable/paginated project selection, PR performance cards, delivery throughput, agent workspace metrics, and read-only aggregate EDE for all-project scope. [7a0245e2](https://github.com/aigentive/ralphx.app/commit/7a0245e2d0b329561a5db3c7191f1e05bbacd199)
- **Chat transcripts are easier to scan** when assistants make several adjacent tool calls: consecutive tool-call runs collapse into one status row, while expansion still renders the existing tool widgets unchanged. [969a9772](https://github.com/aigentive/ralphx.app/commit/969a977253323c30ae5c7fad938c3b2af4a851a5)
- **Agent conversation branch and PR controls are clearer**: the editable base selector now appears in the chat header as `BASE:`, while the lower workspace line shows the active branch/status and a clickable `PR #` link when a publication URL exists. [e33aa067](https://github.com/aigentive/ralphx.app/commit/e33aa067b3852f4babe0551b17cf13d38825ec84)
- **Publish automation preferences can be configured earlier**: Autofix CI/review and GitHub auto-merge switches are visible before a PR exists and can persist independently from Auto Publish. [b8f3c203](https://github.com/aigentive/ralphx.app/commit/b8f3c20345f8ea3b4b9112cae241a0676963c606)
- **Linear and Atlassian settings now support disconnect/clear flows** with two-step confirmation, green/red status banners, and aligned status chips such as stored token, valid status, and search availability. [8dad18f3](https://github.com/aigentive/ralphx.app/commit/8dad18f3b375233402fb8e8f1c05ca2e5af508f0)

## Fixes And Polish
- **Chat bottom-follow behavior is more stable** during passive scrolling, composer resizing, first overflow, streaming growth, transcript resize, and queued-message UI height changes. [54932c05](https://github.com/aigentive/ralphx.app/commit/54932c05064cfb7827a41ea6938dfe1478f4e787), [9b185472](https://github.com/aigentive/ralphx.app/commit/9b185472b9e296ba147355c661f529b4619e374d), [4c4f9d9e](https://github.com/aigentive/ralphx.app/commit/4c4f9d9e448aa4c4e19e51915e6018a41aaeb96e)
- **Ideation starts now reuse an already-linked active session** for the same parent conversation, returning the existing session metadata instead of creating duplicate active sessions. [b71b2b88](https://github.com/aigentive/ralphx.app/commit/b71b2b88ecc7dc6a87e18726cf80347cdbd4b253)
- **Agent workspace tabs hide empty or irrelevant destinations**: `Proposals` appears only when proposal content exists in relevant planning/ideation modes, and Verification is hidden when it should not be exposed. [0abb6bba](https://github.com/aigentive/ralphx.app/commit/0abb6bba3d6d89205ffbaa83cb8b43236cba73f1)
- **Codex CLI updater reporting now matches the runtime-resolved CLI source**, reducing confusion when multiple Codex installs or older shims are present. [686b406f](https://github.com/aigentive/ralphx.app/commit/686b406f34d09ad2912f0ced373c5fe4920d8e80)
- **Ideation artifact panes can render plan artifacts from conversation context** even when no workspace link is attached. [3602f3b0](https://github.com/aigentive/ralphx.app/commit/3602f3b0246571270be1cb13c71f7f0159774dfa)

## Developer And Maintainer Changes
- **macOS dev builds use a lighter Dock icon** during `tauri dev`, making local development instances easier to distinguish from the production app. [3602f3b0](https://github.com/aigentive/ralphx.app/commit/3602f3b0246571270be1cb13c71f7f0159774dfa)
- **Metrics, chat, integration, ideation, and workspace-control paths gained targeted coverage** alongside the new all-project Insights commands, CLI updater resolution tests, scroll regressions, integration disconnect tests, and artifact-tab visibility tests. [7a0245e2](https://github.com/aigentive/ralphx.app/commit/7a0245e2d0b329561a5db3c7191f1e05bbacd199), [686b406f](https://github.com/aigentive/ralphx.app/commit/686b406f34d09ad2912f0ced373c5fe4920d8e80), [969a9772](https://github.com/aigentive/ralphx.app/commit/969a977253323c30ae5c7fad938c3b2af4a851a5), [8dad18f3](https://github.com/aigentive/ralphx.app/commit/8dad18f3b375233402fb8e8f1c05ca2e5af508f0)
