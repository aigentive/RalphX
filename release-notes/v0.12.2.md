# RalphX.app v0.12.2

RalphX.app 0.12.2 improves conversation startup responsiveness, timeline diff replay, and workspace publishing/rebase flows.

## User-Facing Changes

- **Agent conversations render sooner** with an optimistic chat shell and a visible `Starting agent` typing state while backend setup is still in progress. [3abe8bf5](https://github.com/aigentive/ralphx.app/commit/3abe8bf549826b52b092fdf0342f42d9cc695465)
- **Timeline-loaded edit/write tool calls show rich diff widgets again** when switching between conversations, including cases where the preview payload was truncated. [244a419e](https://github.com/aigentive/ralphx.app/commit/244a419edbfc5276010fde6f145eb5a173206338)
- **Workspace publication reads are safer and cheaper**: opening or rendering publication UI no longer schedules publish work, and plan-branch update-from-base stays on the isolated plan workspace instead of falling back to the active checkout. [ae374b89](https://github.com/aigentive/ralphx.app/commit/ae374b89a8b6c6d0ec5a95bf3175ae42e6c87bea)
- **Publish and rebase branch selection is more accurate**, with branch listing moved to the async GitService path and the rebase picker using the project’s configured base branch instead of assuming `main`. [ae374b89](https://github.com/aigentive/ralphx.app/commit/ae374b89a8b6c6d0ec5a95bf3175ae42e6c87bea)
- **Publish progress is easier to scan** with a compact modal header, removed duplicate helper copy, and adaptive pipeline columns that keep step labels readable. [222d5687](https://github.com/aigentive/ralphx.app/commit/222d56874e730021a1cc8fdb09f8e0e2f496fbf6)

## Fixes And Polish

- **Publish dialog accessibility and native rendering are tightened** by keeping the dialog description available to screen readers and using WKWebView-safe surface and border styling. [222d5687](https://github.com/aigentive/ralphx.app/commit/222d56874e730021a1cc8fdb09f8e0e2f496fbf6)

## Developer And Maintainer Changes

- Adds targeted regression coverage for timeline diff replay hydration, including truncated `edit` previews restoring widget-ready arguments and raw diff context. [244a419e](https://github.com/aigentive/ralphx.app/commit/244a419edbfc5276010fde6f145eb5a173206338)
- Expands agent conversation time-to-first-response coverage and adds timing instrumentation around workspace preparation phases. [3abe8bf5](https://github.com/aigentive/ralphx.app/commit/3abe8bf549826b52b092fdf0342f42d9cc695465)
- Stabilizes affected visual and publish confirmation tests, including refreshed merge widget baselines and more reliable replay snapshot setup. [222d5687](https://github.com/aigentive/ralphx.app/commit/222d56874e730021a1cc8fdb09f8e0e2f496fbf6)
