# RalphX.app v0.53.0

RalphX.app 0.53.0 focuses on Workspace Review gating, review-chat navigation, and ticketing/GitHub workflow polish.

## User-Facing Changes
- Workspace Review now gates publish/update workflows more explicitly, with review gate states, review outcomes, blocking summaries, and fixer-run state surfaced in the Review panel; base updates can also re-trigger review when the current review becomes stale. [0c792501](https://github.com/aigentive/ralphx.app/commit/0c792501b1e52a2868d6451a11afd93cf17caf45) [23b03fd4](https://github.com/aigentive/ralphx.app/commit/23b03fd428d1eac8a6dbb5d3cdbf564eb19d744c)
- Review workflow controls are easier to reach: Settings > Review Policy can disable required Workspace Review, and opening the Review tab or the Commit & Publish review CTA now focuses the related review chat with workspace model/effort controls available. [0cdfee65](https://github.com/aigentive/ralphx.app/commit/0cdfee65cc5b52172bd98cbaecfe28b19ddefed4)
- Forked or continued chats that own their own workspace remain visible in the agent sidebar and conversation lists, so running process links can resolve to the continued conversation instead of being hidden by parent-only filtering. [c0ee5567](https://github.com/aigentive/ralphx.app/commit/c0ee556720170d946a7b5ef88523ea3d8daec695)
- Ticketing status management expands with a backend status catalog, status manager UI, ClickUp status-scope synchronization fixes, and multi-select assignee filtering in the ticketing dashboard. [0c792501](https://github.com/aigentive/ralphx.app/commit/0c792501b1e52a2868d6451a11afd93cf17caf45)

## Fixes And Polish
- Starting a review now hydrates the shared review cache and invalidates the child conversation timeline immediately, preventing the review chat from appearing empty until navigating away and back. [29187434](https://github.com/aigentive/ralphx.app/commit/291874343bf1b17985865bcb1b1ade634a9dfa49)
- Chat handling is smoother: composer drafts persist per conversation, mid-stream user messages are ordered by send timestamp, and the chat scroller avoids bottom-edge rubber-band jiggle. [0c792501](https://github.com/aigentive/ralphx.app/commit/0c792501b1e52a2868d6451a11afd93cf17caf45)
- GitHub branch and PR summaries preserve PR author attribution through branch-match data, including merged and closed entries that previously lost the author field. [cb75c188](https://github.com/aigentive/ralphx.app/commit/cb75c188d9ee7adfaff5fb466e3bf5f00543240d)

## Developer And Maintainer Changes
- Restores the backend Clippy gate for `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings` by updating Codex CLI capability test fixtures and fixing test-only `await_holding_lock` lint failures. [7a724952](https://github.com/aigentive/ralphx.app/commit/7a724952409759541a859be6135ab37a16a081f6)
- Expands regression coverage for review routing/cache invalidation, auto-review trigger helpers, forked conversation listing, ticketing status catalog commands, and all-projects sidebar height behavior.
