# RalphX.app v0.11.1

RalphX.app 0.11.1 fixes release-profile plugin root resolution for Commit & Publish and the Codex PR describer path.

## User-Facing Changes

- **Commit & Publish** no longer fails before launching the Codex PR describer after an in-app release update creates the `generated/release/claude-plugin` runtime directory. [27033763](https://github.com/aigentive/ralphx.app/commit/270337631e8253ae4423885001d1df710d2bab83)

## Developer And Maintainer Changes

- Extends trusted generated plugin root detection to cover `generated/release/claude-plugin` and `generated/debug/claude-plugin`, while preserving symlink-aware runtime entry resolution. [27033763](https://github.com/aigentive/ralphx.app/commit/270337631e8253ae4423885001d1df710d2bab83)
- Adds regression coverage for resolving the generated release plugin path through symlinked runtime entries back to the RalphX app resource root. [27033763](https://github.com/aigentive/ralphx.app/commit/270337631e8253ae4423885001d1df710d2bab83)
