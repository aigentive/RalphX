# RalphX.app v0.14.1

RalphX.app 0.14.1 improves launch responsiveness, startup recovery targeting, and startup log signal.

## User-Facing Changes

- App launch becomes interactive sooner by moving Git-heavy and broad database recovery work off the awaited startup path; restart telemetry showed cleanup-loop startup reached in about 1.7s from the first log and Git auth preflight completed in 49ms. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)
- Startup recovery does less blocking work by replacing broad task hydration with targeted PR recovery and pending-merge cleanup queries. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)

## Fixes And Polish

- Startup logs are quieter by suppressing expected canonical Claude default-tool fills and duplicate active-project writes, so real startup issues are easier to identify. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)
- Startup cleanup paths avoid observed slow Git, database-contention, and canonical-Claude warning bursts; terminal cleanup no-op scans completed in 4ms and 2ms in the latest restart telemetry. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)

## Developer And Maintainer Changes

- Startup recovery phases now defer chat resumption, stuck reconciliation, verification startup scanning, existing-PR metadata refresh, and dependency safety-net work into delayed background phases with explicit telemetry. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)
- PR recovery and pending cleanup now use narrower repository queries, including candidate merge tasks, candidate merged regular plan keys, and merged tasks with `pending_cleanup` metadata. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)

## Known Issues

- Expected external MCP readiness lines may still be logged as `WARN` because they arrive over stderr. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)
- Vite may still report existing large chunk and plugin timing warnings during production builds. [29773c99](https://github.com/aigentive/ralphx.app/commit/29773c99648e0937770258c1bc691cac4284ecc5)
