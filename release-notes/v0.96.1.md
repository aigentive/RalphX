# RalphX.app v0.96.1

RalphX.app 0.96.1 stabilizes streamed chat bottom-following, preserves parked reader positions, and aligns the transcript tail with the composer.

## User-Facing Changes
- **Chat scrolling** no longer jitters or oscillates at the bottom during streaming; transcript follow behavior now settles cleanly at the latest message. [5466f1a0](https://github.com/aigentive/RalphX/commit/5466f1a018f377683d04e2e49f2c4891719280cc)
- **Reading earlier messages** remains stable when a run completes: resolving workspace data no longer remounts the chat subtree and pulls a parked reader back to the tail. [5466f1a0](https://github.com/aigentive/RalphX/commit/5466f1a018f377683d04e2e49f2c4891719280cc)
- **Transcript bottom alignment** now places the final timeline item at the composer boundary, preventing the last message from being obscured and making bottom navigation land at the visual bottom. [5466f1a0](https://github.com/aigentive/RalphX/commit/5466f1a018f377683d04e2e49f2c4891719280cc)

## Developer And Maintainer Changes
- **Chat-scroll regression coverage** now tests Virtuoso-owned follow behavior, spacer placement across virtualized timeline states, stable end-state convergence, and parked-reader behavior through run completion. [5466f1a0](https://github.com/aigentive/RalphX/commit/5466f1a018f377683d04e2e49f2c4891719280cc)
