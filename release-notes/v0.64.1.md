# RalphX.app v0.64.1

RalphX.app 0.64.1 focuses on automation run artifact focus, deterministic restart recovery, and clearer idle-after-cancelled automation state.

## User-Facing Changes
- **Automation run artifacts now stay pinned to the selected run:** opening a run from the automation panel or active conversation shows artifacts for that exact run instead of being redirected by the setup conversation’s workspace; plan-gated runs open on the Plan tab with the parked plan available when applicable. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
- **In-flight automation runs recover more deterministically after backend restarts:** edit-phase restart orphans redeliver the approved-plan prompt through the scheduler’s gated path instead of failing the run or consuming failure credits for restart artifacts. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
- **Automation resumption avoids stale “zombie” continuations:** automation-owned conversations are no longer revived by generic chat resumption, preventing old agents from continuing work in dead run worktrees alongside successor runs. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
- **Cancelled latest automation runs are now visible as idle:** the automation detail view shows an idle banner with a **Run now** action, while the agents automation panel shows a message-only banner for the same state. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)

## Fixes And Polish
- **Queued plan-gate delivery is retryable instead of terminal:** if a send is queued and purged while an agent is still live, the run can retry instead of entering an unrecoverable failed state. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
- **Revision recovery no longer races the judge:** pending revision instructions are restored after queued delivery, and judge dispatch waits while those instructions are pending. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)

## Developer And Maintainer Changes
- Added focused frontend and Rust regressions for run artifact focus, parked-plan fallback, restart-orphan recovery, queued delivery retry behavior, and automation-owned conversation resumption exclusion. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
- Hardened recovery ownership by requiring automation-aware checks in chat resumption paths and preserving scheduler ownership for automation run recovery. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)

## Known Issues
- Three narrow restart windows remain timeout-bounded rather than instantly recovered: a sub-second no-agent-run window at reminder count 0, an edit-phase orphan without a matching approval row, and a user turn in flight on a parked run at restart. [55d21eda](https://github.com/aigentive/ralphx.app/commit/55d21eda894b8bcf217f56ef094aba5208242440)
