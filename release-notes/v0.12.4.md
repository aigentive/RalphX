# RalphX.app v0.12.4

RalphX.app 0.12.4 focuses on faster startup, safer post-update relaunches, and clearer diagnostics for first-agent setup delays.

## User-Facing Changes

- **Post-update relaunches now show an explicit readiness state:** after installing an update, RalphX displays a lightweight full-window “Preparing RalphX” surface while the relaunched window and WebView settle, keeping the normal shell hidden until it is ready and reducing early-click activation races on macOS. [bd40feba](https://github.com/aigentive/ralphx.app/commit/bd40feba8cc725ec80e453cbfb7b353094d236e5)
- **Startup becomes usable sooner by moving non-critical work off the critical path:** external MCP startup and low-priority cleanup/recovery now run separately from initial readiness; the latest measured restart kept external MCP readiness near 16 seconds instead of the earlier roughly 297-second tail. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)
- **First agent responses should begin sooner in workspace-preparation flows:** continuation agents now resolve workspace base state from the local repo snapshot on the hot path instead of waiting on an origin fetch before the first response. [694ab4aa](https://github.com/aigentive/ralphx.app/commit/694ab4aadd3746e79eeb238307056ac5f6c1083f)
- **Agent setup and startup recovery do less repeated probing:** cleanup markers, cached provider/runtime probes, direct `.git/config` origin inspection, and stored agent-workspace path reuse reduced measured first-agent command setup from about 68.6 seconds to about 13.3 seconds. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)
- **Provider/model selection is guarded against unavailable harnesses:** unavailable providers remain visible for context, but selection is limited to enabled and validated providers to avoid accidental misconfiguration. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)

## Fixes And Polish

- **Startup cleanup now backs off while user work is active:** terminal artifact cleanup pauses when the running-agent registry is non-empty, avoiding background worktree or branch mutations during active conversations and recovery. [694ab4aa](https://github.com/aigentive/ralphx.app/commit/694ab4aadd3746e79eeb238307056ac5f6c1083f)
- **Running-agent inspection is less race-prone:** read-only checks no longer treat old `pid=0` placeholder entries the same way send-gate cleanup does, reducing the chance that live-but-unsettled registry entries are erased. [694ab4aa](https://github.com/aigentive/ralphx.app/commit/694ab4aadd3746e79eeb238307056ac5f6c1083f)
- **Relaunched windows are focused after being shown:** the native window setup now focuses the Tauri main window after display to reduce macOS relaunch activation/order handling issues. [bd40feba](https://github.com/aigentive/ralphx.app/commit/bd40feba8cc725ec80e453cbfb7b353094d236e5)

## Developer And Maintainer Changes

- **Startup and agent setup telemetry is more durable and granular:** logs now cover startup recovery, first-agent setup, follow-up sends, Git subprocess callers, PR metadata refreshes, DB contention, and Claude launch-plan phases. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)
- **Slow Git and launch diagnostics now identify the responsible phase or caller:** shared GitService slow logs include caller file/line attribution, and Claude launch planning reports subphase timings for prompt, MCP, environment, and command construction. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)
- **Recovery and readiness behavior gained targeted coverage:** tests now cover post-update preparing readiness, active-work startup cleanup pauses, and local-only workspace base resolution. [bd40feba](https://github.com/aigentive/ralphx.app/commit/bd40feba8cc725ec80e453cbfb7b353094d236e5) [694ab4aa](https://github.com/aigentive/ralphx.app/commit/694ab4aadd3746e79eeb238307056ac5f6c1083f)

## Known Issues

- Follow-up Claude messages can still miss Gate 1 and respawn between messages; interactive process reuse/resume remains a follow-up. [1ec634ac](https://github.com/aigentive/ralphx.app/commit/1ec634ac12cac3366b473e0f152971c96c771613)
