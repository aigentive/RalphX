# RalphX.app v0.14.0

RalphX.app 0.14.0 focuses on faster workspace publishing, more complete archive cleanup, and steadier long-running agent conversations.

## User-Facing Changes
- **Commit & Publish is more responsive:** the tab becomes interactive sooner, the main CTA no longer waits behind a slow freshness check, Review Changes loads heavy payloads only when opened, and publishing can reuse a precomputed PR description. [6e14336f](https://github.com/aigentive/ralphx.app/commit/6e14336f5d42f9e7b097693ea9d66f51c84cd04e)
- **Agent workspace archiving is now a complete cleanup action:** archiving closes any open GitHub PR, marks the workspace archived, and schedules the local workspace branch for cleanup on next app restart; archive dialogs now warn about PR closure and branch cleanup. [f7dc9512](https://github.com/aigentive/ralphx.app/commit/f7dc9512500c26ee5a171c31435102676c25bf74)
- **Long-running IPR and interactive agents are less likely to be interrupted incorrectly:** timeout handling now tracks idle time since meaningful activity instead of total process age, so agents that recently produced output are not killed just because they have been running for a long time. [1e155985](https://github.com/aigentive/ralphx.app/commit/1e155985481f3c35369368729cef35492ca78976)

## Fixes And Polish
- **Streaming agent chats refresh reliably after navigation:** switching away from an active conversation and back no longer leaves newly created messages hidden until the conversation is manually reselected. [257c5312](https://github.com/aigentive/ralphx.app/commit/257c531269912ce1fa2d0cd77a2596746f0357ff)
- **Agent conversation breadcrumbs update immediately:** when the background session namer finishes, the top-bar breadcrumb now reflects the new title without requiring a sidebar reselection. [3e34a626](https://github.com/aigentive/ralphx.app/commit/3e34a6264c3c0f330033e5a157cfffd1265d5bde)
- **Timeout and cancellation states render more clearly:** timeline blocks now finalize as errors on timeout, parse stall, or cancellation instead of remaining stuck as streaming. [1e155985](https://github.com/aigentive/ralphx.app/commit/1e155985481f3c35369368729cef35492ca78976)

## Developer And Maintainer Changes
- **Publish/review Git work is scheduled with clearer priority:** startup PR refreshes, auto-publish completion checks, and stale-base scans move to a background Git lane, while user-triggered publish and review actions get a foreground path. [6e14336f](https://github.com/aigentive/ralphx.app/commit/6e14336f5d42f9e7b097693ea9d66f51c84cd04e)
- **Workspace publish diagnostics are easier to attribute:** cache status, queue lane, and publish/review timing telemetry were added around the optimized publish path. [6e14336f](https://github.com/aigentive/ralphx.app/commit/6e14336f5d42f9e7b097693ea9d66f51c84cd04e)
- **Automated Claude workflows no longer prompt for `git push`:** the settings entry that required confirmation for `Bash(git push:*)` was removed while leaving `defaultMode` as `bypassPermissions`. [55749955](https://github.com/aigentive/ralphx.app/commit/55749955b1818599d59160dbc51e365d367329ad)
