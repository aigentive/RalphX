# RalphX.app v0.65.0

RalphX.app 0.65.0 focuses on a new notification center, native macOS alerts, and more stable chat transcript scrolling.

## User-Facing Changes
- **Notification center:** the reviews slot is now an Inbox-style notification center with a “Needs action” badge, urgency-grouped rows, in-place review handling, permission re-prompts with expiry countdowns, and a lazy-hydrated history tab. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Broader human-action coverage:** task reviews, QA failures, merge conflicts, blocked/failed or stuck tasks, provider pauses, permissions, questions, plan approvals, automation pauses/failures, GitHub auth prompts, and PR-review monitors now surface through the shared attention/notification flow. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Desktop and badge notifications:** native macOS notifications, focused toasts, per-project mute controls, retention settings, burst coalescing, and a macOS Dock badge are now driven from the same notification count as the app navbar. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Chat transcript scrolling:** chat scrolling now uses a single controller for pinned/free/returning states, so WKWebView scrollbar drags no longer get pulled back to bottom, sending while scrolled up intentionally pins, and timestamp jumps, tool-group toggles, older-history prepends, hidden hosts, and streaming growth are handled consistently. [ce228a8d](https://github.com/aigentive/ralphx.app/commit/ce228a8d57e2df5c2b81adf29ca33f544ee378cc)
- **Streaming message rendering:** markdown text now renders continuously with throttled updates instead of swapping plain-text and markdown subtrees per token, reducing stream-time flicker and height thrash. [ce228a8d](https://github.com/aigentive/ralphx.app/commit/ce228a8d57e2df5c2b81adf29ca33f544ee378cc)

## Fixes And Polish
- **Notification drawer reliability:** cross-project rows now select the target project before navigation, query errors show retryable states instead of false empty states, stale data is indicated, raw project UUIDs are hidden, focus returns to the trigger on close, and Esc defers correctly to open review modals. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Notification correctness:** resolved permissions now clear from attention lists, serde `null` payload fields hydrate correctly in the packaged app, desktop notification summaries share one coalescer across app states, and toasts fail closed until preferences load. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Automation recovery visibility:** cancelled latest automation runs now show an idle-after-cancelled state with a **Run now** action instead of silently waiting for manual restart. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)

## Developer And Maintainer Changes
- **Notification infrastructure:** adds durable notification storage, settings storage, repository/service seams, typed notification producers, desktop dispatch integration, debug smoke command support, and runtime-configurable retention pruning. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Automation restart hardening:** scheduler-owned restart recovery now retries queued-then-purged plan deliveries, re-drives plan/edit restart orphans in place, and excludes automation-owned conversations from generic chat resumption to prevent zombie agents in dead run worktrees. [9278bf1d](https://github.com/aigentive/ralphx.app/commit/9278bf1d89c17295433d418a4fa4e9151480112c)
- **Scroll implementation cleanup:** removes legacy chat scroll observers, timing-window refs, footer/context plumbing, composer `onLayoutChange`, and the old auto-scroll hook in favor of one framework-free scroll controller with targeted behavioral coverage. [ce228a8d](https://github.com/aigentive/ralphx.app/commit/ce228a8d57e2df5c2b81adf29ca33f544ee378cc)
