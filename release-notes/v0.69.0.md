# RalphX.app v0.69.0

RalphX.app 0.69.0 reworks plan verification, normalizes chat tool activity, and improves ticket, persona, and restart workflows.

## User-Facing Changes

- Plan verification now runs through the normal Plan workflow: `Verify Plan` queues an ordinary plan conversation turn, and acceptance is governed by the current plan artifact plus live verification state instead of the retired verifier-specific UI. [f0d5d09d](https://github.com/aigentive/ralphx.app/commit/f0d5d09db362dc4105063c284d7a9179753729a2)
- Chat tool activity now renders through classified transcript activity instead of the deprecated streaming tool panel, with delegated, edit, and command-style calls following a shared Claude/Codex path. [5d13dc52](https://github.com/aigentive/ralphx.app/commit/5d13dc52b1ed9b76ff41c95ef9ec9401d39680fc)
- Artifact tabs in conversations can now be hidden and restored per conversation, with a tab customizer, hide action, visible-tab fallback, and recoverable empty state when every available tab is hidden. [d55a8887](https://github.com/aigentive/ralphx.app/commit/d55a8887183e68d9915de18d8ee5b85b7296e1cd)
- ClickUp ticket references can now be associated with RalphX conversations and PR context, improving traceability during review and reconciliation when upstream metadata is consistent. [7e2e01e2](https://github.com/aigentive/ralphx.app/commit/7e2e01e23e04f4c4068bd3c0500312d4b43b23bb)
- Persona update flows now preserve draft provenance and conversation binding, support cumulative batched context ingestion with file/folder picker entry points, and allow update-mode persona chats without ingested files. [959f2f3e](https://github.com/aigentive/ralphx.app/commit/959f2f3e92d9923c538879169a87d31a85da0275)

## Fixes And Polish

- Notifications now clear unread counts reliably when using `Mark all as read`, reset the dock badge to zero, and surface persistence failures instead of reporting false success. [5cd5b0c7](https://github.com/aigentive/ralphx.app/commit/5cd5b0c704fae5191019c55fad814b872bb98434)
- Opening a review plan now lands on the intended conversation with the Plan artifact selected instead of preserving stale local artifact state. [3d9c9d19](https://github.com/aigentive/ralphx.app/commit/3d9c9d191532569ba27ce838c8f42f12d6897548)
- Restarting an implementation attempt now shows clearer destructive confirmation copy and is more conservative around preserved branches, existing PRs, and worktree ownership before discarding attempt state. [252247b4](https://github.com/aigentive/ralphx.app/commit/252247b4f8c53f7bc654cdf90490aa5a1b49bfef)

## Developer And Maintainer Changes

- Plan verification internals were replaced with backend-derived verification identity, typed action-run authority, exact proof fields, updated prompts/docs/MCP surfaces, and a supporting SQLite migration. [f0d5d09d](https://github.com/aigentive/ralphx.app/commit/f0d5d09db362dc4105063c284d7a9179753729a2)
- Automation maintenance restored Rust CI gates and expanded automation utility-agent and bridge-recovery test coverage; no user-visible behavior was attributed from the supplied diff context. [0cb066d2](https://github.com/aigentive/ralphx.app/commit/0cb066d20222ec17b2a11d45f1de793f3a8041f9)
