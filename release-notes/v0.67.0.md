# RalphX.app v0.67.0

RalphX.app 0.67.0 focuses on flag-gated agent personas, more reliable ideation/task completion flows, and cleaner conversation/workspace UI behavior.

## User-Facing Changes
- **Agent Personas v1 ships behind a default-off feature flag**: when enabled, RalphX adds Settings → Personas, Build with agent, start-composer persona selection, and an active-chat persona chip while keeping personas prompt-only and scoped to Project-context conversations. [a55896ee](https://github.com/aigentive/ralphx.app/commit/a55896ee3fbfecb89963e6551d40798ee453f60f)
- **Plan review notifications open the right surface**: plan approval and team plan approval notifications from the sidebar now open the linked conversation with the Plan tab selected, including when you are already in that conversation. [4088430b](https://github.com/aigentive/ralphx.app/commit/4088430b9ca199f108c5882bfa577dde9a711154)
- **Ideation approval and restart flows are more resilient**: approved ideation flows can recover from tool-only completion without final assistant text, and restart can relocate an owned conversation worktree into the linked plan worktree location while rejecting branch drift. [4747f60a](https://github.com/aigentive/ralphx.app/commit/4747f60a806f6ca1c1adcde900e5fc2c1ecbb9ac), [6dc2bfc1](https://github.com/aigentive/ralphx.app/commit/6dc2bfc1b7f5c7b9e084c5ac68a796ea92b96ce0)
- **Automation run history is easier to scan**: run timeline cards and markers now use status-aware colors, with successful runs green, active runs orange, and failed or cancelled runs muted gray. [d1455758](https://github.com/aigentive/ralphx.app/commit/d1455758010e7a4d9f66dda90d3a3d9beffa7673)

## Fixes And Polish
- **Notifications sidebar layout now closes and aligns correctly**: closing the sidebar hides the panel surface instead of leaving visible chrome, and the panel/backdrop extend to the bottom edge without the footer gap. [82ed38f4](https://github.com/aigentive/ralphx.app/commit/82ed38f4e1b16ac128a839d17c6c7804f518b625)
- **Conversation scrolling stays pinned to the true bottom**: when timestamps, actions, or metadata render after the last message, the viewport now keeps bottom-following users aligned without forcing users who scrolled up back down. [eda88cdc](https://github.com/aigentive/ralphx.app/commit/eda88cdcee7a4adef2a0a9136630999bd84b10b2)
- **Completion and retry state now better reflect accepted outcomes**: accepted `execution_complete` results preserve successful runs from late local diagnostics, while rejected completion attempts still remain failed. [b388a8c2](https://github.com/aigentive/ralphx.app/commit/b388a8c206018b119eb92cde0ec028cbd017944c)
- **Workspace publishing and freshness checks avoid stale or unsupported rows**: archived conversations are excluded from direct auto-publish scans, and Plan-mode workspaces no longer enter unsupported freshness inspection paths. [b57f72ec](https://github.com/aigentive/ralphx.app/commit/b57f72ecf0ee2e612bfc1e77436789fe37aeef37)
- **Follow-up ideation sessions dedupe repeated Rails test database blockers**: repeated execution-blocked reports for the same setup failure now reuse the existing follow-up conversation instead of fragmenting the workspace list. [fdc10395](https://github.com/aigentive/ralphx.app/commit/fdc10395ef8389a9ee4e27b033e35d19058880d6)
- **Cancelled Codex turns clear stale provider session state**: incomplete cancelled Codex turns now start the next send from a fresh provider state instead of attempting to resume a dead thread. [b889a734](https://github.com/aigentive/ralphx.app/commit/b889a73471c9d2e913ec92737af25bdaf80afc22)

## Developer And Maintainer Changes
- Restores main-branch Rust integration CI reliability by fixing confirmed scheduling, startup-recovery, and freshness auto-commit success-reporting failures; external runner setup failures remain outside the repository-owned fixes. [fd715606](https://github.com/aigentive/ralphx.app/commit/fd71560654ddaa1f5b82da39a74abb263ace9333)
- Expands persona-system validation and coverage across backend commands, prompt rendering, resolver entry paths, MCP redaction, frontend surfaces, and flag-off absence behavior. [a55896ee](https://github.com/aigentive/ralphx.app/commit/a55896ee3fbfecb89963e6551d40798ee453f60f)
