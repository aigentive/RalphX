# RalphX.app v0.90.0

RalphX.app 0.90.0 improves delegate coordination and child-runtime delegation, makes PR-based workspaces recover after base PRs merge, and prevents affected local databases from blocking startup.

## User-Facing Changes
- **Delegated-agent coordination** now lets coordinators wait in the backend or park until delegates settle; parked rows show **Waiting on N delegates** and resume in the same conversation instead of polling or appearing under **Needs you**. [6207aeec](https://github.com/aigentive/ralphx.app/commit/6207aeecc14af6beb822fc565102d81fa9046779)
- **Child agent conversations** can now delegate from Workspace Review, forked, and started child runtimes; Delegate widgets and streaming state remain attached to the runtime that initiated the work. [5a207efe](https://github.com/aigentive/ralphx.app/commit/5a207efe77ff0e28da1ba1a824223c5459469bbe)
- **PR-based workspaces** now retarget a selected base PR to its merge target after it merges; the base picker identifies merged PRs and the publish panel offers a one-click rebase. [ccb8312e](https://github.com/aigentive/ralphx.app/commit/ccb8312ead5500c2f7e39fc11b27bace83a58e8a)
- **Workspace publication recovery** corrects foreign PR associations when a PR’s head branch does not match the workspace branch, restoring affected workspaces so publishing creates a fresh draft PR. [ccb8312e](https://github.com/aigentive/ralphx.app/commit/ccb8312ead5500c2f7e39fc11b27bace83a58e8a)

## Fixes And Polish
- **Startup migration handling** now permits historical foreign-key orphans unrelated to the chat-block rebuild, warning about the existing data instead of repeatedly failing to open the local workspace. [8694af8a](https://github.com/aigentive/ralphx.app/commit/8694af8a41f74a4f86e44b3410d51901c58deabd)

## Developer And Maintainer Changes
- **Delegation integrations** now expose bounded multi-job waits and durable `delegate_park` wake handling; parks persist across restarts, reconcile overdue wakes, and surface wake-dispatch failures. [6207aeec](https://github.com/aigentive/ralphx.app/commit/6207aeecc14af6beb822fc565102d81fa9046779)
