# RalphX.app v0.34.2

RalphX.app 0.34.2 focuses on safer chat composer reference validation, improved Atlassian reference search, and clearer integration failure feedback.

## User-Facing Changes

- **Chat composer references** now store and expand only explicitly selected or validated references; invalid free-form tokens such as `@invalid-reference` are no longer promoted into structured reference metadata. [f53772d4](https://github.com/aigentive/ralphx.app/commit/f53772d4c50252565f60b759ea0e6ce7584da714)
- **Atlassian reference search** now keeps `@jira:` and `@confluence:` queries active across spaces, so multi-word searches continue working in the composer. [f53772d4](https://github.com/aigentive/ralphx.app/commit/f53772d4c50252565f60b759ea0e6ce7584da714)
- **Jira and Confluence lookup** is broader and more precise, including exact Jira issue-key lookup, numeric Confluence page-ID lookup, closed Jira work items, and less restrictive Jira filtering. [f53772d4](https://github.com/aigentive/ralphx.app/commit/f53772d4c50252565f60b759ea0e6ce7584da714)

## Fixes And Polish

- **Atlassian composer failures** now surface in the reference menu when auth or integration setup is missing, instead of appearing as an empty result set. [f53772d4](https://github.com/aigentive/ralphx.app/commit/f53772d4c50252565f60b759ea0e6ce7584da714)

## Developer And Maintainer Changes

- Added backend coverage for Jira JQL and Confluence CQL helper behavior, plus frontend coverage for invalid tokens, space-containing Atlassian triggers, and Atlassian failure states. [f53772d4](https://github.com/aigentive/ralphx.app/commit/f53772d4c50252565f60b759ea0e6ce7584da714)
