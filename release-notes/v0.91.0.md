# RalphX.app v0.91.0

RalphX.app 0.91.0 improves Workspace Review control, streamlines composer runtime selection, and prioritizes Claude model choices.

## User-Facing Changes
- **Workspace Review controls** now expose an automatic fixer-cycle cap (default: 3); when reached, the panel shows automatic fixing is paused while keeping **Fix Issues** available for manual follow-up. [a65794dd](https://github.com/aigentive/ralphx.app/commit/a65794dd99738c7b3003c884d94b521ee5b9e13b)
- **Workspace Review results** now distinguish Blocking, Fold In, Backlog, and Informational findings, with post-fixer fold-ins demoted unless they are genuinely blocking. [a65794dd](https://github.com/aigentive/ralphx.app/commit/a65794dd99738c7b3003c884d94b521ee5b9e13b)
- **Composer runtime menus** return to the main Advanced popover after successful Model, Effort, or Speed selections and restore focus to the originating row; rejected Persona updates remain open for retry. [9564d7f0](https://github.com/aigentive/ralphx.app/commit/9564d7f062a814d05df929a7e469ff003315d2bd)
- **Claude model pickers** now order options by capability and version: Fable, Opus 5, Opus 4.8, Opus 4.7, Opus, Sonnet 5, Sonnet 4.6, Sonnet, then Haiku. [0c9a65e2](https://github.com/aigentive/ralphx.app/commit/0c9a65e233ab5dee9eb122239737d6e92c75bfae)
- **Stable upgrades** now present one combined changelog covering all builds since the previous Stable release, rather than only the latest per-build notes. [b4b0cf7b](https://github.com/aigentive/ralphx.app/commit/b4b0cf7b2c2687d8f3b67a537c403dc2c57fab4c)

## Developer And Maintainer Changes
- Stable-release promotion now resolves the prior Stable baseline, combines committed per-build notes with Codex, validates them before mutation, and supports a no-mutation notes dry run with artifact output. [b4b0cf7b](https://github.com/aigentive/ralphx.app/commit/b4b0cf7b2c2687d8f3b67a537c403dc2c57fab4c)
- Workspace Review persists automatic fixer-cycle state and aligns review settings, completion behavior, and reviewer guidance around capped automatic routing. [a65794dd](https://github.com/aigentive/ralphx.app/commit/a65794dd99738c7b3003c884d94b521ee5b9e13b)
