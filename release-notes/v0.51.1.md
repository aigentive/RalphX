# RalphX.app v0.51.1

RalphX.app 0.51.1 stabilizes plan verification round reporting, queued verifier continuation reconciliation, and verification snapshot persistence.

## User-Facing Changes
- Plan verification can now report verification rounds instead of failing with `No such tool available`, preventing parent plans from being left unverified with zero rounds recorded. [67f0ef6e](https://github.com/aigentive/ralphx.app/commit/67f0ef6e518a3a12a48de309b644c4e2c54757c6)
- Queued verifier continuations now run the same parent reconciliation path as top-level verification streams, so hidden verifier completions can archive/terminalize the child and update the parent native verification snapshot. [76096255](https://github.com/aigentive/ralphx.app/commit/76096255ed3ae74698b38592d8717517987f6524)
- Verification snapshot saves now use an immediate SQLite transaction, reducing `database is locked` failures during concurrent verification/delegate writes without changing the persisted snapshot shape. [76096255](https://github.com/aigentive/ralphx.app/commit/76096255ed3ae74698b38592d8717517987f6524)

## Developer And Maintainer Changes
- Silences repeated Node 24+/25 WebStorage warnings in Vitest fork workers while preserving jsdom-owned `localStorage`, with a warning-check script and `npm run test:check-warnings` regression guard. [0e374541](https://github.com/aigentive/ralphx.app/commit/0e3745418574013e0fda7b96e0b491b8b0f8f56b)
- Expands backend IPC command-wrapper coverage for activity, QA, methodology, research, workflow, task step, agent profile, API key, and permission commands. [ef94e4c8](https://github.com/aigentive/ralphx.app/commit/ef94e4c883fabacd894118a3d99ad4c171b3795e)
- Adds Rust lib coverage for verification snapshot persistence so the SQLite snapshot transaction path is exercised by the lib coverage gate. [8c5f9809](https://github.com/aigentive/ralphx.app/commit/8c5f98091e863627129ac8797378ddc552d99b8c)
