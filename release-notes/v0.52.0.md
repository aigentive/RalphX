# RalphX.app v0.52.0

RalphX.app 0.52.0 focuses on safer review-gated publishing, more reliable chat workflows, and richer dashboard filtering.

## User-Facing Changes

- **Local workspace reviews now act as first-class publish gates**: the Review tab explicitly shows pass, blocking, running, failed, and not-required states, and Commit & Publish is blocked until the current review gate passes or is not required. [5e6db685](https://github.com/aigentive/ralphx.app/commit/5e6db685bee1b03034f63ba50671cdd7faaac192)
- **Workspace review actions are better synchronized with agent runtime state**: Update Review is disabled while the parent workspace or review runtime is actively generating, while idle `waiting_for_input` runtimes remain eligible. [5e6db685](https://github.com/aigentive/ralphx.app/commit/5e6db685bee1b03034f63ba50671cdd7faaac192)
- **Chat composer drafts survive navigation between conversations**: unsent text and pending attachments restore when returning to an agent conversation or the new-agent starter composer, and sending clears the matching draft. [ce7755cb](https://github.com/aigentive/ralphx.app/commit/ce7755cba4fc847445d48b3ad308f37bfcd91351)
- **Dashboard filters are more flexible**: GitHub dashboard results can now be narrowed by multiple assignees, authors, and review state, with assignee multi-select behavior aligned across integrations. [55c7b311](https://github.com/aigentive/ralphx.app/commit/55c7b311d6cae10fafdc56774de75aaaff82d474)
- **Chat timelines behave more consistently during live runs**: messages sent mid-stream now appear at their send point instead of jumping ahead of later streamed rows, and macOS chat-bottom scrolling avoids visible overscroll bounce while resuming follow-bottom after manual return. [517dcd10](https://github.com/aigentive/ralphx.app/commit/517dcd106fc55727c0599af4f187692b85f2de32) [a5172e1f](https://github.com/aigentive/ralphx.app/commit/a5172e1f525023e6e4d3a20df5ffbf966e9d2ee6)

## Fixes And Polish

- **Ideation proposal finalization now fails closed while verification is active**, preventing accepted sessions and scheduled proposal tasks from being created while the verification child still owns the plan, even when verification is optional for acceptance. [51594a90](https://github.com/aigentive/ralphx.app/commit/51594a90c43927d78a2c45ca9b335ce3edabcad4)
- **Queued chat messages replay in a more accurate order** by persisting the queue entry timestamp when available, so replayed timelines better match the original live conversation. [517dcd10](https://github.com/aigentive/ralphx.app/commit/517dcd106fc55727c0599af4f187692b85f2de32)

## Developer And Maintainer Changes

- Added backend and regression coverage for verification finalize gates, including the domain gate, proposal application path, and all-foreign finalize branch. [51594a90](https://github.com/aigentive/ralphx.app/commit/51594a90c43927d78a2c45ca9b335ce3edabcad4)
- Persisted workspace review outcome and gate state through the backend monitor and SQLite layer, with updated review command flow, MCP prompt contract, and publish-readiness behavior. [5e6db685](https://github.com/aigentive/ralphx.app/commit/5e6db685bee1b03034f63ba50671cdd7faaac192)
- Extended chat draft, attachment, live-row, and queue timestamp test coverage around draft restoration, clearing behavior, and live-stream ordering. [ce7755cb](https://github.com/aigentive/ralphx.app/commit/ce7755cba4fc847445d48b3ad308f37bfcd91351) [517dcd10](https://github.com/aigentive/ralphx.app/commit/517dcd106fc55727c0599af4f187692b85f2de32)
