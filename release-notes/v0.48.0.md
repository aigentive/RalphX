# RalphX.app v0.48.0

RalphX.app 0.48.0 focuses on visible Agent planning and follow-up workflows, per-provider launch configuration, and more reliable review/publish/runtime state handling.

## User-Facing Changes

- **Agent planning** now keeps planning work visible in Agents UI: the standalone Ideation page is hidden by default behind `ideation_page`, Agent conversations get an Issues surface for blockers/drift/decision points, and follow-ups can be linked to new Agent conversations instead of hidden sessions. [1efb1d60](https://github.com/aigentive/ralphx.app/commit/1efb1d60e8b830f304dd3859ce7e03af62dc4914)
- **Provider settings** now include a per-provider custom env-file toggle and path field; saved env files are applied across provider launches, queued resumes, recovery retries, workspace review, and PR-description sidecars without changing RalphX-owned model selection. [50ce46f4](https://github.com/aigentive/ralphx.app/commit/50ce46f45fabe535b151c7e2c0f9dc14a6772c17)
- **Task execution completion** is more reliable for validated work: zero-step runs with output can complete, HEAD-matched green validation caches can rescue stuck failed-step gates, incomplete successful exits are classified as non-transient, and worktree setup now runs even when merge validation is off. [73590712](https://github.com/aigentive/ralphx.app/commit/735907123af10399b58e60e7d294d22a9f47b150)
- **Workspace Review** is now explicit and stateful: opening the Review tab no longer starts review work by itself, the panel shows current/outdated/running/blocked states with `Run review`, `Update review`, `Run again`, and `Retry review`, and current no-op refreshes no longer emit redundant toasts. [2e46cef9](https://github.com/aigentive/ralphx.app/commit/2e46cef9031e01fe75308a8f8c3ecd67fe4b7564) [fa324d82](https://github.com/aigentive/ralphx.app/commit/fa324d825a379006d555f72fd47b212bd38f94b1)
- **Publish and repair workflows** surface more useful state in-place: clean workspaces can auto-refresh from their configured base, repair mode avoids duplicated status copy, conflicted repair conversations render actual file conflict diffs/counts, publish progress is scoped to the active conversation, and stale-base PR descriptions use the captured base diff. [1cd6b984](https://github.com/aigentive/ralphx.app/commit/1cd6b984fe0ef01f6a62a08ec9c43847889a32c0) [90cf35ac](https://github.com/aigentive/ralphx.app/commit/90cf35ac5d1811954b6f84b3a4ec6646b8b0e2a4) [43c1dbc1](https://github.com/aigentive/ralphx.app/commit/43c1dbc14581e96946e312d78c9877cadf6a8649) [5134ec66](https://github.com/aigentive/ralphx.app/commit/5134ec6643e6478b365bcd0438e538c0a7556c14) [6f6bf842](https://github.com/aigentive/ralphx.app/commit/6f6bf8427c0fb9457ff15b534c3d2d95a42f52f4)

## Fixes And Polish

- **Runtime status** now distinguishes a live Claude IPR process that is awaiting input from active generation, with waiting badges/non-spinning presentation; the agent mode picker also stays enabled while waiting but remains disabled during generation. [6b00f2aa](https://github.com/aigentive/ralphx.app/commit/6b00f2aab9c0c17cdfc1e13165d9a629d8174788) [6adcbcff](https://github.com/aigentive/ralphx.app/commit/6adcbcff6096750f5b58bdc8910314f087760177)
- **Agent sidebar labels** better match workspace reality: dirty or behind-base workspaces no longer appear fully closed just because the PR closed, and repair/fix publication labels take precedence over generic running/waiting text. [0a39a6aa](https://github.com/aigentive/ralphx.app/commit/0a39a6aa0902a0ffd44097393e58751ffe8a1ad6) [80800957](https://github.com/aigentive/ralphx.app/commit/80800957d6ab640191e3287d4d959a31e9fee46a)
- **Archived workspace terminals** now show an archived terminal state for merged or cleaned-up workspaces instead of a raw missing-worktree terminal error; continuing in chat still creates the fresh workspace. [3fc33e13](https://github.com/aigentive/ralphx.app/commit/3fc33e134df6f1d33df10f4408a331ee81ddf9b8)
- **Conversation continuity forks** get better generated titles from parent context and recent messages, reducing fallback titles like `Discuss {user message}` while keeping fork creation non-blocking if naming fails. [83a1050e](https://github.com/aigentive/ralphx.app/commit/83a1050eb100fc1963451e42b5fec1ea86df2253)
- **Chat streaming scroll** avoids the initial bottom-pin race when a new streamed reply starts in an already-scrolled conversation, reducing visible up/down jiggle. [6dfbfb16](https://github.com/aigentive/ralphx.app/commit/6dfbfb166aeb20314ed04b33ace1c860ed38d5fe)
- **PR autofix wake-ups** now recover from stale `fixing`/`publishing` suppression after a pushed publication when no active agent run exists, allowing CI failures to route a fixer again. [ccc6dffe](https://github.com/aigentive/ralphx.app/commit/ccc6dffe10204d1f64c3d7af8b7ff5a3815ab211)

## Developer And Maintainer Changes

- Added durable stateful-workflow review guardrails for completion, cache, retry, recovery, state-machine, and execution-prompt changes, including false-success review checks for stale attempts/cache, fail-open reads, event ordering, prompt/schema drift, and task-scoped delegation. [2d65cdba](https://github.com/aigentive/ralphx.app/commit/2d65cdba7365ada35709fdb8b40248a30c9735b3)
- Reworked workspace-review internals around a bounded review-packet contract across backend handlers, MCP transport, generated tool bundles, prompts, and catalog tests, keeping the reviewer surface narrower and more deterministic. [46ae4844](https://github.com/aigentive/ralphx.app/commit/46ae48448cad988cfc04b591a1a5e1cba8f4cc7d)
- Provider env-file support includes persistence/API fields, SQLite migration coverage, launch-time parsing, protected env handling, and spawn-path coverage for provider retries and sidecars. [50ce46f4](https://github.com/aigentive/ralphx.app/commit/50ce46f45fabe535b151c7e2c0f9dc14a6772c17)
