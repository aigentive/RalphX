# RalphX.app v0.57.0

RalphX.app 0.57.0 improves plan-to-conversation handoffs, managed-workspace publish inspection, and delegation/recovery across agent workspaces.

## User-Facing Changes

- **Plan tab workflows** now let users start a new agent conversation from the selected plan artifact, preserving the viewed plan version and rendering it as a structured composer reference. [4afef566](https://github.com/aigentive/ralphx.app/commit/4afef56639bd818f7ec0f50cd601cdafd639361a)
- **Commit & Publish inspection** now shows pending diffs for linked-plan managed ideation workspaces before a PR exists, while merged workspaces can still show PR-backed diff summaries after the local workspace is gone. [9936392c](https://github.com/aigentive/ralphx.app/commit/9936392c48f0029a9786bf121b0438e1108a8667), [0a3b34cc](https://github.com/aigentive/ralphx.app/commit/0a3b34cc935b5dc46ba5fbf90c6b147c8f2b8b9a)
- **Workspace delegation** now works from any agent workspace context with delegation enabled, with delegated jobs linked back to the invoking conversation instead of requiring an ideation parent session. [44c45557](https://github.com/aigentive/ralphx.app/commit/44c45557b620fb0534d264894c2bae9a097bdc99)
- **Focused child runtime chats** now show the composer-area tasks ledger when a task-runtime context is available, matching normal agent workspace chats. [6b028d17](https://github.com/aigentive/ralphx.app/commit/6b028d17ab2f588baadcae826e367e98a48bc997)
- **Chat timelines** restore the grouped “agent called x tools” toggle for dense raw tool-call activity while keeping structured cards, such as diffs and delegate/task widgets, rendered directly. [865d2fbf](https://github.com/aigentive/ralphx.app/commit/865d2fbf9d9e1f76c1f8564e50119f079e600d49)

## Fixes And Polish

- **Startup recovery** no longer automatically resumes terminal merged workspaces, preventing closed workspaces from being reopened by hidden recovery sends. [0a3b34cc](https://github.com/aigentive/ralphx.app/commit/0a3b34cc935b5dc46ba5fbf90c6b147c8f2b8b9a)
- **Settings > Setup reset** now persists cleared setup data, so reopening Settings reflects the reset state instead of restoring previous custom values. [54cf9f9a](https://github.com/aigentive/ralphx.app/commit/54cf9f9a87daac9705bb6935837b8cb055a1bee0)
- **Plan PR description drafting** now creates and cleans up the required scratch conversation/workspace rows, avoiding the SQLite foreign-key failure previously seen on that path. [ff67c664](https://github.com/aigentive/ralphx.app/commit/ff67c664d646b59cc9dfee9755d591d549824d5f)

## Developer And Maintainer Changes

- **Worktree pre-commit hooks** now detect incomplete frontend dependency trees via required `tsc` and `eslint` executables and repair the local worktree install instead of failing early. [3b957a8f](https://github.com/aigentive/ralphx.app/commit/3b957a8f0178afdc303ee71fcafc731db3395097)
- **Regression coverage** was expanded across startup recovery, timeline grouping, plan-reference composer hydration, scoped task ledgers, managed ideation diffs, delegation handlers, setup reset persistence, and plan PR scratch cleanup. [0a3b34cc](https://github.com/aigentive/ralphx.app/commit/0a3b34cc935b5dc46ba5fbf90c6b147c8f2b8b9a), [865d2fbf](https://github.com/aigentive/ralphx.app/commit/865d2fbf9d9e1f76c1f8564e50119f079e600d49), [4afef566](https://github.com/aigentive/ralphx.app/commit/4afef56639bd818f7ec0f50cd601cdafd639361a), [6b028d17](https://github.com/aigentive/ralphx.app/commit/6b028d17ab2f588baadcae826e367e98a48bc997), [9936392c](https://github.com/aigentive/ralphx.app/commit/9936392c48f0029a9786bf121b0438e1108a8667), [44c45557](https://github.com/aigentive/ralphx.app/commit/44c45557b620fb0534d264894c2bae9a097bdc99), [54cf9f9a](https://github.com/aigentive/ralphx.app/commit/54cf9f9a87daac9705bb6935837b8cb055a1bee0), [ff67c664](https://github.com/aigentive/ralphx.app/commit/ff67c664d646b59cc9dfee9755d591d549824d5f)
