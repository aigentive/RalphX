# RalphX.app v0.8.0

RalphX.app 0.8.0 improves Agents chat feedback, installed-app CLI discovery, and Commit & Publish reliability for agent workspaces.

## User-Facing Changes
- **Installed app CLI resolution:** installed macOS launches can now find NVM-managed JavaScript CLIs from validated versioned Node directories, so project agent starts no longer fail just because the app’s PATH is stripped compared with an interactive shell. [e2e366f3](https://github.com/aigentive/ralphx.app/commit/e2e366f333c5dfb04ca28f9df603e107245939b6), [ad0cdb25](https://github.com/aigentive/ralphx.app/commit/ad0cdb25a2e141fc1806e2202f361338742022d8)
- **Agents chat state:** starting an agent while global execution is paused now shows the queued prompt in the selected conversation, displays paused/stopped queue-aware empty states, and changes the composer action to `Queue Prompt` instead of leaving a blank chat. [9eb688f1](https://github.com/aigentive/ralphx.app/commit/9eb688f1b7564b92da21d417547e768c17dc8f71)
- **Live chat and long-running status:** project and generic task chats now render assistant text chunks during active runs, and long-running Agents conversations keep the Stop control and blue sidebar working indicator while backend liveness says the agent is still running. [abeea9a6](https://github.com/aigentive/ralphx.app/commit/abeea9a6d3d68d876b8bb94dff160de0c1037d28), [5907248e](https://github.com/aigentive/ralphx.app/commit/5907248ee9c1c49ffb98ecce51eeaf0afef80563)
- **Agent workspace publishing on changed bases:** workspaces whose saved base branch was merged and deleted can retarget to the project default branch when containment proves it is safe; unsafe bases now block update/publish/rollover with an explicit reason instead of showing stale branch labels. [1e81faf9](https://github.com/aigentive/ralphx.app/commit/1e81faf91de33345868580785f57e31bed6069ac)
- **Commit & Publish / PR output:** the publish CTA now avoids no-op paths when there are no changed files or an existing PR is already current, and new PRs get reviewer-oriented descriptions generated from the PR template, commits, diff stats, patch excerpts, and recent conversation context. [d869a73a](https://github.com/aigentive/ralphx.app/commit/d869a73abeddfb298072bb7b3b87b22d25a99b26), [809a2ec4](https://github.com/aigentive/ralphx.app/commit/809a2ec422272bab5e628e8c1e26fe053389aebc), [39d0f587](https://github.com/aigentive/ralphx.app/commit/39d0f587d244d15bf2b0a5deb6d0c43fef6b075a)

## Fixes And Polish
- **Task dependency correctness:** completed dependencies no longer remain in `blocked_by` or hold execution context in a blocked shape, so tasks depending on already-merged work proceed with accurate dependency hints. [b1013086](https://github.com/aigentive/ralphx.app/commit/b1013086ba6f7cdc254c6db218a7e2b6d435249d)
- **Execution finalization safety:** stale late finalizers re-check the active execution attempt before writing failure state, preventing a completed run from regressing tasks already in `PendingReview` or `Reviewing` back to `Failed`. [b1013086](https://github.com/aigentive/ralphx.app/commit/b1013086ba6f7cdc254c6db218a7e2b6d435249d)
- **Topbar/sidebar and Agents polish:** refreshed navigation styling, Agents sidebar rows, shared toasts, and Git auth repair UI; visible examples include the restored Sign in action, active runtime badge, sidebar search clear, and project chevron toggle behavior. [7bf3ff1e](https://github.com/aigentive/ralphx.app/commit/7bf3ff1e4535c38bd09c8f29c3c7f85eec5b5b2b)

## Developer And Maintainer Changes
- **Frontend regression coverage:** expanded unit and visual coverage across PlanBrowser, AgentsSidebar, agentSessionStore, AppTopBar, UpdateChecker, Git auth repair, task/verification/review widgets, graph controls, filters, and dialog flows. [7bf3ff1e](https://github.com/aigentive/ralphx.app/commit/7bf3ff1e4535c38bd09c8f29c3c7f85eec5b5b2b)

[39d0f587](https://github.com/aigentive/ralphx.app/commit/39d0f587d244d15bf2b0a5deb6d0c43fef6b075a)

## Known Issues
- Queued prompts created while execution is paused still use the existing in-memory queue behavior; queue durability across app restarts remains separate scope. [9eb688f1](https://github.com/aigentive/ralphx.app/commit/9eb688f1b7564b92da21d417547e768c17dc8f71)
- Persisted workspaces without a saved `base_commit` cannot be automatically retargeted and will be blocked until resolved manually. [1e81faf9](https://github.com/aigentive/ralphx.app/commit/1e81faf91de33345868580785f57e31bed6069ac)
