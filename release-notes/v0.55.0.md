# RalphX.app v0.55.0

RalphX.app 0.55.0 focuses on review workflows, cross-repository inspection, and runtime reliability around workspace setup and resumption.

## User-Facing Changes

- Workspace diffs now have a review-focused mode that foregrounds file cards, hunk headers, and review annotations without rendering full code by default; reviewers can load code per file and use the inline legend to interpret annotation colors. [cb6149cc](https://github.com/aigentive/ralphx.app/commit/cb6149cc877037ed505d6a6dd7bece80cfe7b21f)
- Workspace Review is more goal-aware: reviewer context now includes parent goal context, resolved artifacts, and linked plan evidence, so review findings are evaluated against the intended workspace goal rather than only the raw diff. [0ba3a6a6](https://github.com/aigentive/ralphx.app/commit/0ba3a6a621e47143aca87a68879272190f160a47)
- Read-only filesystem MCP tools can now inspect absolute paths outside the current RalphX checkout, including other repositories or service checkouts, while remaining read-only. [2b3f79f0](https://github.com/aigentive/ralphx.app/commit/2b3f79f02081cdbfff9246cf269447f4c38e0ab3)
- RalphX-native delegation is exposed across chat, plan, edit, and PR review surfaces where appropriate: chat/plan/review can delegate to the read-only explorer, and edit mode can also delegate to the general worker. [2b8fc95d](https://github.com/aigentive/ralphx.app/commit/2b8fc95d15ea58db55efeb4d198c0dae40f914cb)

## Fixes And Polish

- Starting or updating a workspace review now focuses the newly created review conversation and invalidates its transcript data, so live review messages appear immediately instead of waiting for a manual pane switch. [ffd04b56](https://github.com/aigentive/ralphx.app/commit/ffd04b5634619b093f5bbff3d243062138998ea5)
- Granola note markdown now uses RalphX theme-aware prose styling in dark mode, improving contrast for headings, links, quotes, code, tables, and note detail content. [4efbef12](https://github.com/aigentive/ralphx.app/commit/4efbef12ebf6236e9ea592bca30f89e8e3f979bc)
- Startup resumption now guards terminal or cleaned agent workspaces so invalid continuations do not resume through the wrong workflow. [bd6b4742](https://github.com/aigentive/ralphx.app/commit/bd6b4742fdc6bcd719550a6c758d1452a2e47637)
- Task install commands now inherit the production `PATH`, reducing command-not-found failures for setup tools such as `npm` when those binaries are available to the app process. [a6eab276](https://github.com/aigentive/ralphx.app/commit/a6eab2763423ea5143df9a1f1e927f4b1eb406c6)

## Developer And Maintainer Changes

- Delegation authorization and MCP catalog resolution now use canonical agent/profile metadata, including profile-aware tool loading for plan mode. [2b8fc95d](https://github.com/aigentive/ralphx.app/commit/2b8fc95d15ea58db55efeb4d198c0dae40f914cb)
- Workspace review writes now thread active review metadata such as `created_by_run_id`, `head_sha`, and `diff_fingerprint` through artifacts, hunk annotations, and completion records. [0ba3a6a6](https://github.com/aigentive/ralphx.app/commit/0ba3a6a621e47143aca87a68879272190f160a47)
- Filesystem MCP tool docs, error text, and tests were updated for the relaxed read-only path-resolution behavior, including external absolute paths and symlinked paths outside the workspace. [2b3f79f0](https://github.com/aigentive/ralphx.app/commit/2b3f79f02081cdbfff9246cf269447f4c38e0ab3)
