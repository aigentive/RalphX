# RalphX.app v0.11.0

RalphX.app 0.11.0 improves existing-PR publishing, Agents sidebar navigation, and agent runtime reliability across macOS launches, resume, and provider handling.

## User-Facing Changes
- Existing agent workspace PRs can refresh from the base branch, commit, and publish from the backend after agent completion or stale-base detection, so users no longer need to keep the conversation open or manually step through behind-base checks for already-open PRs; first-time PR creation remains manual. [52f437a8](https://github.com/aigentive/ralphx.app/commit/52f437a8639753fb349e96bdbec0358c025facbc)
- The Agents sidebar now shows richer project/session metadata and grouping: PR-backed sessions render `PR #N`, branch-backed sessions show branch/base refs, publication states such as `draft`, `merged`, `closed`, `uncommitted`, and `unpushed` appear when useful, and sessions can be grouped by project or publication state. [cfceb31a](https://github.com/aigentive/ralphx.app/commit/cfceb31a67400642e8b446195af3d62484a09779)
- macOS GUI launches can detect Claude CLI installs that work in Terminal but were hidden from Finder/Dock/Spotlight processes, including user-local binaries under `~/.local/bin`; the same discovery path stays aligned for Codex. [b71b6dbb](https://github.com/aigentive/ralphx.app/commit/b71b6dbba29e873fc09335a7921be777bf965025)
- Commit & Publish now checks the Codex PR-description helper’s submit-tool contract before launch and produces more specific errors if the helper exits without submitting, including preserved raw tool-unavailable output. [c519a532](https://github.com/aigentive/ralphx.app/commit/c519a532e571d11a6befb72ed9ee51298f132059)
- Agent sessions are less likely to be interrupted or shown incorrectly: startup cleanup no longer cancels conversations started during the current app boot, global resume ignores stale terminal events from older runs, and local tool output containing text like `rate_limit` no longer pauses all execution. [ae57b1bf](https://github.com/aigentive/ralphx.app/commit/ae57b1bf320f4549817db2ac5a9351a0f38340c7) [51b822b2](https://github.com/aigentive/ralphx.app/commit/51b822b2cbc5b0d706c5f9ae14a906fa43a663e6) [8e00b8ed](https://github.com/aigentive/ralphx.app/commit/8e00b8ed679a818fa886bbae4858c7062ec87ecc)

## Fixes And Polish
- Chat autoscroll now targets the rendered timeline bottom during active turns, keeping the typing indicator visible and making the scroll-to-bottom control land below the live indicator instead of the last persisted message. [412a99ee](https://github.com/aigentive/ralphx.app/commit/412a99ee081fbc057d7296a5dce6f0856e6c80ab)
- The Agents sidebar filter popover is tighter and quieter: Projects and Publication state collapse by default with selection summaries, rows use check icons instead of checkboxes, and focus styling is softened inside the popover. [cfceb31a](https://github.com/aigentive/ralphx.app/commit/cfceb31a67400642e8b446195af3d62484a09779)

## Developer And Maintainer Changes
- Adds backend auto-publish orchestration for existing agent workspace PRs, with turn/run completion listeners, a periodic active-workspace freshness scan, per-conversation in-flight serialization, and eligibility/recovery coverage. [52f437a8](https://github.com/aigentive/ralphx.app/commit/52f437a8639753fb349e96bdbec0358c025facbc)
- Introduces backend-owned grouped Agents sidebar API/schema support, persisted sidebar group/filter/pin state migration, mock API support, query invalidation paths, and expanded sidebar coverage. [cfceb31a](https://github.com/aigentive/ralphx.app/commit/cfceb31a67400642e8b446195af3d62484a09779)
- Hardens runtime cleanup and lifecycle plumbing with cutoff-aware registry/repository cleanup, run-ID-bearing lifecycle payloads, queue run-ID propagation, and stale-event guard tests. [ae57b1bf](https://github.com/aigentive/ralphx.app/commit/ae57b1bf320f4549817db2ac5a9351a0f38340c7) [51b822b2](https://github.com/aigentive/ralphx.app/commit/51b822b2cbc5b0d706c5f9ae14a906fa43a663e6)
- Refines provider/tool launch infrastructure with Codex runtime-vs-local failure classification, validated user-local CLI resolver candidates, interactive-login zsh fallback validation, profile-scoped generated Claude plugin runtime directories, and generated-plugin cache repair. [8e00b8ed](https://github.com/aigentive/ralphx.app/commit/8e00b8ed679a818fa886bbae4858c7062ec87ecc) [b71b6dbb](https://github.com/aigentive/ralphx.app/commit/b71b6dbba29e873fc09335a7921be777bf965025) [c519a532](https://github.com/aigentive/ralphx.app/commit/c519a532e571d11a6befb72ed9ee51298f132059)
