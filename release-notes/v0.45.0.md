# RalphX.app v0.45.0

RalphX.app 0.45.0 expands ticketing with ClickUp, improves ticket dashboard controls, and fixes active conversation and branch-publish status handling.

## User-Facing Changes

- **ClickUp ticketing integration** now joins Linear and Jira in the unified ticketing dashboard, with ClickUp settings, workspace/space-backed task loading, provider summaries, dashboard routing, and mock data for web/test mode. [e8f3a268](https://github.com/aigentive/ralphx.app/commit/e8f3a2687c5e20a125297c3106d3e663c61018a5)
- **ClickUp ticket details and references** render richer task context, including threaded comments, attachments/previews, visible ticket counts, branch metadata, multi-assignee display, accessible assignee avatars, and composer ticket references. [e8f3a268](https://github.com/aigentive/ralphx.app/commit/e8f3a2687c5e20a125297c3106d3e663c61018a5)
- **Ticketing dashboard access and controls** now depend on valid Linear or Atlassian integration state instead of a separate Linear settings toggle, keep ticketing out of the legacy top navigation, and replace native selects with searchable controls for filters and detail-sheet fields. [1fbbe96d](https://github.com/aigentive/ralphx.app/commit/1fbbe96d7b25e5ddecb071bffdcaa084343602e9)
- **Ideation squash commits** now include the originating task title, description, and full task UUID, making generated commits easier to trace back to RalphX tasks. [00fc7c2d](https://github.com/aigentive/ralphx.app/commit/00fc7c2d1cd29622c36187d6d43b834ecef4ec30)

## Fixes And Polish

- **Workspace conversation status** now stays visibly `running` while child ideation work is active, so the parent sidebar row no longer appears status-less during live work. [67393409](https://github.com/aigentive/ralphx.app/commit/6739340972ff344a181cbe6c026092cef1257514)
- **Branch PR publish readiness** now counts commits against the review/base branch when the local publish branch has no remote tracking ref, avoiding false “no publishable commits” states. [e810d85d](https://github.com/aigentive/ralphx.app/commit/e810d85dd445eea3a4e93b7c9195808a793e0bb7)
- **Project selection in ticketing** can reveal additional projects as the menu scrolls, matching incremental loading behavior used elsewhere in the app. [1fbbe96d](https://github.com/aigentive/ralphx.app/commit/1fbbe96d7b25e5ddecb071bffdcaa084343602e9)

## Developer And Maintainer Changes

- Expanded ClickUp coverage across settings, backend fetch/mapping, ticketing resources, composer references, dashboard fallbacks, and filter behavior. [e8f3a268](https://github.com/aigentive/ralphx.app/commit/e8f3a2687c5e20a125297c3106d3e663c61018a5)
- Updated ticketing and feature-flag tests for integration-driven dashboard visibility and searchable select behavior. [1fbbe96d](https://github.com/aigentive/ralphx.app/commit/1fbbe96d7b25e5ddecb071bffdcaa084343602e9)
- Added disk cleanup before Rust coverage jobs to reduce runner storage pressure. [e810d85d](https://github.com/aigentive/ralphx.app/commit/e810d85dd445eea3a4e93b7c9195808a793e0bb7)
