# RalphX.app v0.60.0

RalphX.app 0.60.0 focuses on spec-anchored automation setup and judging, clearer automation run management, and safer branch/PR conversation starts.

## User-Facing Changes

- **Automation setup** now supports draft creation from an automation-mode conversation, with setup-agent configuration persisted into structured automation fields and editable draft/run settings in the artifact panel. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Spec-anchored automations** can load or author a linked Specification artifact, then carry goal, phase status, progress counts, and spec context into runs and judge cycles. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Automation views** now surface formatted specs, phase progress, live run status, gated run triggers, collapsible run cards, and a live task ledger for the active agent. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Automation deletion** is archive-first: setup/run conversations and linked specs are archived before automation rows are removed, and the confirmation dialog lists the durable history affected. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Branch and PR conversation starts** now default to isolated branch mode; normal starts can still opt out to linked mode, while Review PR mode forces isolation and requires PR metadata. [ad0fb144](https://github.com/aigentive/ralphx.app/commit/ad0fb144e07dffe532010e62977263486f85c84c)

## Fixes And Polish

- **Automation publishing and chaining** now keep run bases on the automation branch, push that base before PR creation, chain successor runs from the advanced remote ref, and resume initial PR publishing after a passing workspace review. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Blocked automation reviews** now pause the automation with `workspace_review_blocked` notes instead of publishing flagged code. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- **Linked branch setup failures** now preserve the composer input, avoid leaving active empty “Untitled agent” conversations, and offer an explicit retry with isolation. [ad0fb144](https://github.com/aigentive/ralphx.app/commit/ad0fb144e07dffe532010e62977263486f85c84c)
- **Conversation rendering** now prefers logical transcript history when the timeline window is incomplete, and avoids collapsing widget-backed tool calls into generic grouped output. [ad0fb144](https://github.com/aigentive/ralphx.app/commit/ad0fb144e07dffe532010e62977263486f85c84c)

## Developer And Maintainer Changes

- Expanded the automation platform with repository/state-machine primitives, scheduler foundation, Tauri/HTTP command surfaces, frontend API contracts, setup/judge MCP surfaces, and run-now controls. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- Extended automation persistence and validation for config patches, linked spec artifacts, `agent_completed` run completion, judge verdict retry clearing, and draft/paused-only config updates. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- Added regression coverage for automation repositories, commands, config persistence, setup allowlists, branch isolation defaults, linked setup cleanup, and IPC start-service paths. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38) [ad0fb144](https://github.com/aigentive/ralphx.app/commit/ad0fb144e07dffe532010e62977263486f85c84c)

## Known Issues

- Automation specs can be re-authored as new versions, but the linked `spec_artifact_id` cannot be cleared in this release; active automations must be paused before re-authoring. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
- Deleting an automation archives conversations, specs, and workspaces, but does not remove local git worktrees or the isolated setup branch. [b568a9d0](https://github.com/aigentive/ralphx.app/commit/b568a9d0717391fddabf14a1f6b94b43d8a1ce38)
