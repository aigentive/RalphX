# RalphX.app v0.46.0

RalphX.app 0.46.0 improves live transcript scrollback, agent runtime navigation, and PR/ticket workflow handling.

## User-Facing Changes
- **Live chat transcripts** now keep long streaming turns scroll-accessible: live text, task cards, and grouped tool activity render as timeline rows instead of a clipped tail, with consecutive tool calls still shown as one “Agent called X tools” row. [80167264](https://github.com/aigentive/ralphx.app/commit/80167264b3c5a6614c8bac60f0fc16fd6094bcf8)
- **Agent conversation runtime state** now appears as an explicit running-state bar for associated workspace, ideation, verification, task execution, review, and merge activity, with CTAs that jump back to the relevant conversation or task context. [498b1d1e](https://github.com/aigentive/ralphx.app/commit/498b1d1e940e01c316000557883787d1b48bace2)
- **GitHub PR publish conflicts** now surface as a dedicated conflict banner/status pill with a `Resolve conflicts` action that uses the existing update-from-base/repair flow, including auto-publish repair routing for conflicted PRs. [fcabbcf2](https://github.com/aigentive/ralphx.app/commit/fcabbcf23aff398c6316864af4e21a1340fb1fb9)
- **Plan-mode and artifact routing** now better follow the active conversation: plan creation auto-selects the `Plan` tab, PR review data is filtered to the active conversation, plan CTAs show/lock on “Checking recommended next action,” and task creation preserves execution-plan scope. [56d89c5e](https://github.com/aigentive/ralphx.app/commit/56d89c5e55fdd82a048efbf3c19b9a3ab8f5332f) [15322eaf](https://github.com/aigentive/ralphx.app/commit/15322eaf2302a6a405329b487b6840bf6e3f32fa) [7e06be1a](https://github.com/aigentive/ralphx.app/commit/7e06be1af262ece3a1a29c5ccd66c69a1dfc1c3f)
- **ClickUp-backed ticket views** now sync a broader source ticket set and can filter by watcher state when follower metadata is available, including “watcher me” style filtering. [3ea06f00](https://github.com/aigentive/ralphx.app/commit/3ea06f00481512990aa469d8ca1d111e5d7909a7)

## Fixes And Polish
- **Linked ideation chats** now spawn through the linked plan-branch worktree when available, allowing PR-backed ideation conversations to continue after the original agent-conversation worktree was cleaned up instead of failing with “Agent conversation workspace is missing.” [1f4ac0be](https://github.com/aigentive/ralphx.app/commit/1f4ac0be7b4421d23ef85736cac4f7aa81c16891)
- **Settings and provider-update notifications** now stack correctly: provider update toasts no longer cover Settings, and matching update-available toasts clear after a successful provider install/update. [9be567d5](https://github.com/aigentive/ralphx.app/commit/9be567d59637e389a61b699472d2449fee6ec43f)

## Developer And Maintainer Changes
- Added a conversation-scoped runtime status read model and API surface for active workspace, ideation, verification, task execution, review, and merge runtime items. [498b1d1e](https://github.com/aigentive/ralphx.app/commit/498b1d1e940e01c316000557883787d1b48bace2)
- Expanded focused coverage across live transcript rows, plan pending-action CTAs, toast stacking/dismissal, PR review scoping, PR conflict handling, runtime status UI branches, and ClickUp watcher filtering. [80167264](https://github.com/aigentive/ralphx.app/commit/80167264b3c5a6614c8bac60f0fc16fd6094bcf8) [15322eaf](https://github.com/aigentive/ralphx.app/commit/15322eaf2302a6a405329b487b6840bf6e3f32fa) [9be567d5](https://github.com/aigentive/ralphx.app/commit/9be567d59637e389a61b699472d2449fee6ec43f) [56d89c5e](https://github.com/aigentive/ralphx.app/commit/56d89c5e55fdd82a048efbf3c19b9a3ab8f5332f) [fcabbcf2](https://github.com/aigentive/ralphx.app/commit/fcabbcf23aff398c6316864af4e21a1340fb1fb9) [3ea06f00](https://github.com/aigentive/ralphx.app/commit/3ea06f00481512990aa469d8ca1d111e5d7909a7)
