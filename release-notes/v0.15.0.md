# RalphX.app v0.15.0

RalphX.app 0.15.0 focuses on agent workspace publishing, external PR reconciliation, and faster Commit & Publish review.

## User-Facing Changes

- **Agents → Commit & Publish now opens directly onto workspace diffs**, with inline file cards under the action row and a sidebar-style filter chip for switching between the uncommitted workspace and a specific commit. The existing Review Changes dialog remains available through the fullscreen icon button. [4ac17580](https://github.com/aigentive/ralphx.app/commit/4ac17580170043aa5eb0e891ef54b608e9eb284e)
- **The Commit & Publish action is now sticky**, keeping the primary publish CTA reachable while scrolling through metadata and diffs; warnings stack under the CTA, and each file keeps its own scrollable diff body. [4ac17580](https://github.com/aigentive/ralphx.app/commit/4ac17580170043aa5eb0e891ef54b608e9eb284e)
- **Agent conversations can publish or update their own workspaces through RalphX**, so conversational publish/update requests use the same PR linkage, publication status, repair routing, and UI-visible state as the Commit & Publish tab. [c73ac9e0](https://github.com/aigentive/ralphx.app/commit/c73ac9e003319fc61a5e1de29a7e3fa7a46f282e)
- **PRs created outside the RalphX publish flow are now reconciled back to agent workspaces**, including open, draft, merged, and closed PRs matched by exact workspace branch, so conversations can show the external PR link/status and apply terminal workspace behavior after merge or close. [dd18c57f](https://github.com/aigentive/ralphx.app/commit/dd18c57f39657e74d255b1ddabbadb9289b468da)

## Fixes And Polish

- **Inline diffs stay out of PR-current and post-publish states**, preserving the existing publish-pane copy and avoiding render attempts when the workspace state is not shaped for inline review. [4ac17580](https://github.com/aigentive/ralphx.app/commit/4ac17580170043aa5eb0e891ef54b608e9eb284e)
- **Agent-driven publishing now returns structured states for in-progress publishes and repair-needed workspaces**, with duplicate concurrent publish calls guarded per conversation. [c73ac9e0](https://github.com/aigentive/ralphx.app/commit/c73ac9e003319fc61a5e1de29a7e3fa7a46f282e)
- **External PR cleanup runs through the background Git lane**, reducing foreground blocking when terminal PR cleanup needs to remove a workspace after merge or close. [dd18c57f](https://github.com/aigentive/ralphx.app/commit/dd18c57f39657e74d255b1ddabbadb9289b468da)

## Developer And Maintainer Changes

- Added internal MCP facades for agent workspace publish state, readiness, base update, and publish actions, backed by the existing workspace update and Commit & Publish orchestration. [c73ac9e0](https://github.com/aigentive/ralphx.app/commit/c73ac9e003319fc61a5e1de29a7e3fa7a46f282e)
- Added bounded, non-blocking PR reconciliation triggers on workspace load, agent run completion, and startup while keeping list/sidebar rendering DB-only. [dd18c57f](https://github.com/aigentive/ralphx.app/commit/dd18c57f39657e74d255b1ddabbadb9289b468da)
- Reused existing Tauri diff commands and `SimpleDiffView` for the inline Commit & Publish diff list; per-file diff hydration remains lazy through React Query. [4ac17580](https://github.com/aigentive/ralphx.app/commit/4ac17580170043aa5eb0e891ef54b608e9eb284e)
