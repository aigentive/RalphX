# RalphX.app v0.73.1

RalphX.app 0.73.1 restores Claude Agent starts for users upgrading from releases that registered RalphX's MCP server globally.

## Fixes And Polish

- **Upgrade-safe Claude MCP cleanup:** RalphX recognizes and removes only its exact obsolete user-scoped `ralphx` registration. Modified or user-owned collisions are preserved and remain blocked for safety.
- **Actionable Agent start recovery:** Reserved MCP conflicts now appear as a specific setup card with Settings, safe retry, and manual recovery guidance instead of a generic “Agent failed to start” toast.
- **Side-effect-free preflight:** New Agent conversations detect MCP setup conflicts before creating worktrees, conversations, workspaces, events, or runs; every final launch path still rechecks immediately before spawn.
