# RalphX.app v0.89.0

RalphX.app 0.89.0 improves agent workspace reliability, live Fable reasoning, and workspace-review/merge workflows.

## User-Facing Changes
- **Agent workspace creation** preserves an explicitly selected start-from branch through background refreshes; if that branch disappears, RalphX rechecks it before showing a clear submission error rather than silently falling back to the project default. [7cf31f04](https://github.com/aigentive/ralphx.app/commit/7cf31f04d3d010cdafda2fa9a68ddd9693d7da36)
- **Agent conversations** now stream Fable thinking text live, rather than showing only the thinking token-count indicator. [db6ef649](https://github.com/aigentive/ralphx.app/commit/db6ef649aae6e6ac76fb747aa2464bfff72faf32)
- **RX-native Team mode** now starts with the read-only `team_coordinator` profile, including profile-specific coordination prompts and fail-closed profile resolution. [cc9e5ca0](https://github.com/aigentive/ralphx.app/commit/cc9e5ca048b93bddd31589594ae12047499f687d)
- **Workspace Review** can delegate bounded file inspection to `ralphx-general-explorer`, allowing large-diff reviews to preserve reviewer capacity for verification and final artifacts. [1058d0e5](https://github.com/aigentive/ralphx.app/commit/1058d0e5968a36de980199c52aa33d586eb22c4c)

## Fixes And Polish
- **Plan-mode workspaces** now refresh and render base freshness correctly; after an update, stale “Behind base” banners and update controls clear instead of persisting. [eb141a60](https://github.com/aigentive/ralphx.app/commit/eb141a6037127227e27ff409d5c0abfd78bd3e32)
- **Auto-merge after Workspace Review** restores immediately when the reviewed changes are already published, and startup reconciliation recovers previously stuck workspaces. [e4278e4d](https://github.com/aigentive/ralphx.app/commit/e4278e4dd256fbdb6240402e11bdd3373225def2)

## Developer And Maintainer Changes
- **CI workflows** now build the Rust coverage archive once for shard consumers, cache Linux dependencies, run minimal and full Clippy lanes in parallel, retry one environmental nextest flake, and support GitHub merge-queue runs while retaining required gate behavior. [22723ffe](https://github.com/aigentive/ralphx.app/commit/22723ffe26d33099b6b86b25ddaa7269183288c8)
