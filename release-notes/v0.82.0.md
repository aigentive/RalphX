# RalphX.app v0.82.0

RalphX.app 0.82.0 expands implementation-ready planning, improves conversation continuity, and makes review and publishing outcomes easier to follow.

## User-Facing Changes
- **Plan workflows** now manage paired **Overview** and **Blueprint** artifacts, with Agents › Plan showing `Overview | Blueprint | Proposals`; execution and review paths can use the Blueprint’s implementation guidance directly. [a3878d9a](https://github.com/aigentive/ralphx.app/commit/a3878d9a2356ff91ba23c025d0b4cde14907242c)
- **Team capability** now clearly describes model-directed delegation, gives delegated agents an authoritative task envelope, and reports empty delegate completions as a typed failure with an exit code rather than raw stderr. [34d873f3](https://github.com/aigentive/ralphx.app/commit/34d873f3a6c9f7bf5aefa7ee535d08c9ea7eebac)
- **Chat transcripts** remain stable when reopening an active session, loading older history, or transitioning from live streaming to persisted history; hydrated tool and text blocks retain their ordering. [73d2550b](https://github.com/aigentive/ralphx.app/commit/73d2550b0c5a6844c5dc525b71ad999222f7a480)
- **Integration references** attached earlier in a conversation are carried into later chat and Workspace Review assembly—for example, multiple Jira references remain available after a fresh turn instead of only the primary reference. [fb48de9f](https://github.com/aigentive/ralphx.app/commit/fb48de9f88e406a10da6fd663b37a78e06ca8db7)

## Fixes And Polish
- **PR publishing** now remains in a verification state when a GitHub metadata update has an unresolved outcome, and surfaces whether the update was applied, not applied, conflicted, or still unsettled. [8d891f5d](https://github.com/aigentive/ralphx.app/commit/8d891f5db992205a4e8e281a2498ca677220b5dd)
- **Diff review** replaces the code-hiding Reviews toggle with a non-blocking Review Walkthrough: inspect one finding and its hunk at a time, navigate with arrows, J/K, or progress dots, then return to the full diff. [bba34532](https://github.com/aigentive/ralphx.app/commit/bba345322548cbc4328d312a17631c8515ee85ec)

## Developer And Maintainer Changes
- Added replay fixtures and parity coverage for transcript snapshots, pagination, hydration, and persisted streaming state. [73d2550b](https://github.com/aigentive/ralphx.app/commit/73d2550b0c5a6844c5dc525b71ad999222f7a480)
- Extended plan-bundle persistence, export/import, task context, MCP, and compatibility handling while retaining overview-only support for legacy sessions. [a3878d9a](https://github.com/aigentive/ralphx.app/commit/a3878d9a2356ff91ba23c025d0b4cde14907242c)
- Added durable, attempt-scoped PR metadata receipts and reconciliation state to prevent stale publish events from overriding the active attempt. [8d891f5d](https://github.com/aigentive/ralphx.app/commit/8d891f5db992205a4e8e281a2498ca677220b5dd)
