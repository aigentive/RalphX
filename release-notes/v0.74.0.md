# RalphX.app v0.74.0

RalphX.app 0.74.0 expands persona and standalone-conversation workflows, reworks agent workspace and review flows, and improves runtime setup.

## User-Facing Changes
- **Personas and standalone conversations:** When their feature flags are enabled, personas can be global or project-scoped, built or refined from the Agents view, edited with version history, and used alongside folder context; the project picker also offers **No project** chats in private workspaces. [6887861c](https://github.com/aigentive/ralphx.app/commit/6887861c7820872394dce363d9dcc957d1d759f4)
- **Runtime and new-run configuration:** The composer now uses one runtime menu, placing optional **Capabilities** between Effort and Speed; new-run choices lead with Plan, Agent, Review PR, and Ask, with a device-local default available in Settings. Ideation is no longer offered as a fresh-run mode. [d820e26d](https://github.com/aigentive/ralphx.app/commit/d820e26d9f8d5e4a7405141d58bc28fecb6a3ffc) [18b87722](https://github.com/aigentive/ralphx.app/commit/18b87722778e387544f7702e8ec4a4c1cb3adf70) [0ceb304e](https://github.com/aigentive/ralphx.app/commit/0ceb304e8f3e7a6db293e870502f5354684d6384)
- **Agent workspaces:** A persistent toolbar now keeps the branch/base, PR link, PR state, and check summary visible while switching artifact tabs; Automation starts from the selected custom or linked branch rather than silently defaulting to `main`. [6d989b97](https://github.com/aigentive/ralphx.app/commit/6d989b972088c22582bb2228d3527292cc218de2) [094ee1ac](https://github.com/aigentive/ralphx.app/commit/094ee1ac652d05ff8a378508863e083bdb14aa2d)
- **Review workflows:** Local Workspace Review is now explicitly distinct from remote Review PR: reviewers can page truncated workspace diffs, while Review PR proposals recover after navigation and become read-only once the linked PR is merged or closed. [f7f4825a](https://github.com/aigentive/ralphx.app/commit/f7f4825abf46d93850967e5f6ec6806c6976ab53) [9dd19f9e](https://github.com/aigentive/ralphx.app/commit/9dd19f9e1db77a524cb54356843f200aa284946e) [6492b8d8](https://github.com/aigentive/ralphx.app/commit/6492b8d8324d8a0b97a8cad7ca2a44dcfd1e67e5)
- **Tasks-off behavior:** Disabling Tasks now preserves existing task history as read-only, suppresses task mutation controls, and keeps direct Agent implementation available instead of implying task work can continue. [e5c0f32e](https://github.com/aigentive/ralphx.app/commit/e5c0f32e26a43b063cb1e07ac05487b740333f54)

## Fixes And Polish
- **Artifact excerpts:** “Add to conversation” now applies only to registered artifact content—for example, rendered plan Markdown—and no longer appears when selecting buttons, lifecycle banners, or surrounding pane chrome; the legacy Plan line-selection UI has been removed. [84cf4b9b](https://github.com/aigentive/ralphx.app/commit/84cf4b9b83033ce2f631c5405ca519705e3335bb)
- **Composer resources:** The attachment menu no longer offers New project and only shows integrations that are enabled and connected; for example, Jira, Linear, and ClickUp remain hidden until their project-aware provider is ready. [f7a005b6](https://github.com/aigentive/ralphx.app/commit/f7a005b6d4db8c59a4052c8ccc201f0e7d7c4478)
- **PR automation safety:** Disabling **Autofix CI & Reviews** now prevents fixer dispatches even after stale polling state, and Review PR workspaces cannot enter owned-PR autofix, publish, or auto-merge paths. [c5b83328](https://github.com/aigentive/ralphx.app/commit/c5b83328d58e0f3107d123ceafb8f9ec1c23e088) [6d1760c8](https://github.com/aigentive/ralphx.app/commit/6d1760c863eea65e80016477c03a6f5d28924c88)
- **Delegated chats:** Delegate cards now recover active child text, tool calls, and runtime metadata such as provider, model, and effort; terminal updates fold into the original card without collapsing an expanded transcript. [98ba7ebf](https://github.com/aigentive/ralphx.app/commit/98ba7ebf40b916188b307916b2431ecea09284d0)
- **Claude MCP upgrade recovery:** Agent starts now surface a targeted recovery path for the exact legacy user-scoped `ralphx` registration written by older RalphX versions, while other reserved-ID conflicts remain fail-closed. [b82a4488](https://github.com/aigentive/ralphx.app/commit/b82a4488cd53b0c5739141b633ca0e67d7705a2d)
- **Workspace Review responsiveness:** Review context refreshes now coalesce instead of overlapping, so active Review, PR review, and workspace-review panes avoid repeated reloads while terminal snapshots hydrate once. [5a008adc](https://github.com/aigentive/ralphx.app/commit/5a008adcccc7fbd85969433a47cbf17d3e1d90c3)

## Developer And Maintainer Changes
- **Workspace Reviewer tooling:** The reviewer MCP surface now includes cursor-based changed-file inventory and diff-page reads, validated against the current workspace-review target and source snapshot. [f7f4825a](https://github.com/aigentive/ralphx.app/commit/f7f4825abf46d93850967e5f6ec6806c6976ab53)
- **Review-mode guidance:** Canonical rules and reviewer prompts now distinguish Workspace Review from Review PR, including their respective artifacts, tools, and side effects. [6492b8d8](https://github.com/aigentive/ralphx.app/commit/6492b8d8324d8a0b97a8cad7ca2a44dcfd1e67e5)
- **Rust test hygiene:** Codex and Claude instructions now require `cd src-tauri && cargo clean` after a Rust test phase, including failed or interrupted runs. [6b4bf432](https://github.com/aigentive/ralphx.app/commit/6b4bf432d8377ce57eb391f2e3f89ad28142ae50)
