# RalphX.app v0.8.2

RalphX.app 0.8.2 improves Agents sidebar behavior, conversation rename persistence, and macOS release-runner controls.

## User-Facing Changes
- **Agents navigation** restores sidebar controls and resizing, normalizes project/session menu hover, status-dot, and filter-toolbar behavior, and fixes cases where expanding a project selected a conversation or collapsed projects kept expanded styling. [f4fb56ed](https://github.com/aigentive/ralphx.app/commit/f4fb56ed7c1af9c738afbb09c45c09b0daad9329)
- **Conversation rename** moves selected agent conversation rename into the top breadcrumb and fixes the production rename payload used by all rename surfaces, so breadcrumb renames now persist. [f4fb56ed](https://github.com/aigentive/ralphx.app/commit/f4fb56ed7c1af9c738afbb09c45c09b0daad9329)
- **Chat and workspace layout** stabilizes transcript settling so chats are not stranded behind placeholder covers, and keeps Kanban, artifact, and chat panes readable with enforced minimum widths. [f4fb56ed](https://github.com/aigentive/ralphx.app/commit/f4fb56ed7c1af9c738afbb09c45c09b0daad9329)

## Fixes And Polish
- **Kanban and graph chrome** refreshes expanded column sizing, default empty-column behavior, and related visual snapshots for the restored sidebar and layout updates. [f4fb56ed](https://github.com/aigentive/ralphx.app/commit/f4fb56ed7c1af9c738afbb09c45c09b0daad9329)
- **macOS titlebar controls** center traffic-light buttons against the titlebar container and reapply positioning after native layout events. [f4fb56ed](https://github.com/aigentive/ralphx.app/commit/f4fb56ed7c1af9c738afbb09c45c09b0daad9329)

## Developer And Maintainer Changes
- **Visual and release CI** keeps regular CI on standard `ubuntu-latest`, pins visual snapshots to `macos-15`, and adds an explicit `macos_runner_size` release option for standard versus larger GitHub-hosted macOS runners. [03c371db](https://github.com/aigentive/ralphx.app/commit/03c371db889be1a89970c71bab2834f01444b0ab)
- **Daily Release workflow** now passes `macos_runner_size` through to the downstream Release Build workflow, with scheduled runs retaining the safe `standard` default and manual runs able to choose the paid larger-runner path intentionally. [67886d5d](https://github.com/aigentive/ralphx.app/commit/67886d5d8c09a5dabeaf42298ce1268c9056fb6a)
