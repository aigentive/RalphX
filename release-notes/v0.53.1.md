# RalphX.app v0.53.1

RalphX.app 0.53.1 focuses on Workspace Review freshness, publish-gate behavior, review runtime selection, and chat scroll stability.

## User-Facing Changes
- **Workspace Review freshness** now survives equivalent publish/merge transitions: a passing review should not become `Review is outdated` after Commit & Publish when the code content is unchanged, and a review can remain valid if the reviewed PR merges while review is running. [6a7d1790](https://github.com/aigentive/ralphx.app/commit/6a7d17903d8e6f558647d47c53e450b8f9bd0f52) [7872ea4c](https://github.com/aigentive/ralphx.app/commit/7872ea4c1fb9c20e96ea9035ddde6cef42994fbd)
- **Publish and auto-publish flows** better respect Workspace Review state: workspaces waiting on a passed review can continue into publish automatically, while disabling `Require Workspace Review before publishing` lets eligible workspaces publish without a review-required block. [1ddf4710](https://github.com/aigentive/ralphx.app/commit/1ddf4710936d593dec0b86e7620b28831b4848fb) [6236d107](https://github.com/aigentive/ralphx.app/commit/6236d1077a9744b100295d9cb06a243e609ed58c)
- **Review runtime UI** now reaches the main workspace chat: active review state and the review runtime widget can appear above the composer, sidebar/runtime badges stay aligned for non-project review contexts, and Review chat defaults to review-specific utility-tier models instead of inheriting the parent workspace model such as `gpt-5.5`. [29990ef4](https://github.com/aigentive/ralphx.app/commit/29990ef4b122d5f114ab068d2501fbcfd52e6cf2) [afcd844a](https://github.com/aigentive/ralphx.app/commit/afcd844ad94a5b3bfb94af5347ee2645334b994a)
- **Review output and diffs** are cleaner and more complete: generated review bodies no longer echo base/head provenance such as `Reviewed the workspace_delta change against ...`, while commit diffs now include untracked/new files. [e5a4fcb5](https://github.com/aigentive/ralphx.app/commit/e5a4fcb558fb55ebd93beff81b0274b6e247597f) [dac8cdb5](https://github.com/aigentive/ralphx.app/commit/dac8cdb5435929b11a48e67cc5c00be2bf3de130)
- **Chat bottom pinning** is more stable: transcripts should stay pinned to the true bottom, including the newest message or typing row, unless the user explicitly scrolls away. [04c266f7](https://github.com/aigentive/ralphx.app/commit/04c266f743c75c9491040177725272159cbb66f8)
