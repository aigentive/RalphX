# RalphX.app v0.70.0

RalphX.app 0.70.0 expands scripted agent workflows, agent context/personas, and reliability around notifications, workspace reviews, and GitHub status.

## User-Facing Changes
- **Scripted agent workflows**: Expands Agent conversations with workflow-enabled agents that can create, approve, start, inspect, pause, resume, and cancel durable workflow runs; the chat UI renders approval and progress state with phases, invocations, logs, usage, and child-transcript navigation. [8235d957](https://github.com/aigentive/ralphx.app/commit/8235d957f518d0cd8566bb7be9aea4a99144faf1)
- **Agent personas**: Adds the flag-gated persona system with Settings management, manual editing, build-with-agent split view, start-composer persona selection, active-chat persona chips/switching, and run attribution for which persona was used. [92da55c9](https://github.com/aigentive/ralphx.app/commit/92da55c936568a72b9f09f619d0bbb7e82c98018)
- **Ticket and artifact context**: Expands agent-facing Jira/Linear/ClickUp ticket attachments through provider-neutral list/fetch operations, preserves line-range selection snapshots in chat history for Plan, ticket, and Granola content, and hides Jira/Linear/Granola tabs until a conversation has the matching attachment. [92da55c9](https://github.com/aigentive/ralphx.app/commit/92da55c936568a72b9f09f619d0bbb7e82c98018) [c8c944dc](https://github.com/aigentive/ralphx.app/commit/c8c944dc91decc80cea04d019314d98b4333d2a9) [efd207f3](https://github.com/aigentive/ralphx.app/commit/efd207f3fd0cef14fc34043f53893403524d8b0e)
- **Conversation cleanup**: Adds Agents sidebar bulk archive mode for visible eligible conversations, including selection checkboxes, an `Archive selected` confirmation, open-PR eligibility blocking, and partial-failure retry behavior. [fd445f93](https://github.com/aigentive/ralphx.app/commit/fd445f93690968504358e47f26c4eb1f9aadcf1d)
- **Jira workflows**: Expands Jira integration with Agile board discovery, board configuration/status-column mappings, and active sprint listing so Jira-connected workflows can distinguish provider-stable board and sprint IDs. [0a090f0c](https://github.com/aigentive/ralphx.app/commit/0a090f0caf8d9687ded7c4491df88a067f5ab0ff)

## Fixes And Polish
- **Notifications**: Keeps history read state explicit, filters archived conversation targets out of history/counts/attention, unifies top-nav and Dock badge totals, and keeps CTA toasts like `Respond`, `Answer`, and `Review plan` visible until the action reaches its target UI. [a68a3a1c](https://github.com/aigentive/ralphx.app/commit/a68a3a1c46b380ad00fefd5fc0a3384b84b77b5f) [bd886221](https://github.com/aigentive/ralphx.app/commit/bd8862212f0a10c0b2f443c149426bf9ee9e1501)
- **Workspace review and publishing**: Makes GitHub auto-merge pause/restore explicit in Review and Commit & Publish panels, prevents disabled provider selection in review/fixer flows, and separates transient GitHub or CLI probe failures from credential loss. [512d5294](https://github.com/aigentive/ralphx.app/commit/512d5294c2f43dbe76aae8c262d99fdeaad270bc) [f37b54bc](https://github.com/aigentive/ralphx.app/commit/f37b54bcf1398c3c6dd5e195e6e3f6b56676d431) [8eaac8da](https://github.com/aigentive/ralphx.app/commit/8eaac8da3216b47fee1687669fdc27d5941a80c8)
- **Delegated chat details**: Hydrates delegated timeline/tool-call details from durable state, including wrapped MCP payloads, and shows live child output while delegated conversations stream before settling onto persisted history. [a50d7e4b](https://github.com/aigentive/ralphx.app/commit/a50d7e4b19a957c9ec09dedb8bc39f9bf9e39353)
- **Dark-mode toast readability**: Fixes Sonner toast title/body/description contrast in dark and high-contrast themes while leaving light-theme styling unchanged. [9927e2cf](https://github.com/aigentive/ralphx.app/commit/9927e2cfd2e8e28c93c419653d85554688a655c2)

## Developer And Maintainer Changes
- **Agent and prompt governance**: Consolidates AGENTS/CLAUDE/rule docs around current canonical agent, MCP, and harness configuration sources; moves volatile tracker content into `docs/governance/active-trackers.md`; and adds GPT-5.5/GPT-5.6 prompt guidance alongside refreshed GPT-5.4 material. [88880f0c](https://github.com/aigentive/ralphx.app/commit/88880f0c1cd123bb32a2caee9276d1942bf77140)
- **Coverage automation**: Hardens the Codecov polling workflow so transient GitHub API parse/transport failures are retried and missing external status is treated as non-blocking only after successful uploads. [a50d7e4b](https://github.com/aigentive/ralphx.app/commit/a50d7e4b19a957c9ec09dedb8bc39f9bf9e39353)
