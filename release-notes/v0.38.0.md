# RalphX.app v0.38.0

RalphX.app 0.38.0 focuses on PR-backed agent workspaces, plan-driven publishing, and more durable agent conversation recovery.

## User-Facing Changes
- **Plan-based ideation starts** now clone a referenced plan into an isolated ideation session and honor the selected analysis base: choosing `Project default (main)` while checked out on `pr/366` locks `main`, while `Current branch (pr/366)` remains an explicit opt-in. [536bfb09](https://github.com/aigentive/ralphx.app/commit/536bfb09c20b797b12a7a37fda888467533ff619) [56ca2eec](https://github.com/aigentive/ralphx.app/commit/56ca2eeceba3938f85933600e1fedf00db40d8a4)
- **PR-backed agent workspaces** can use pull requests as base selections and retain source PR metadata, so workspace updates, conversation base labels, and prompt context reflect the originating PR instead of only a branch name. [d5fb5c13](https://github.com/aigentive/ralphx.app/commit/d5fb5c13297b206fd1c653170510f55c74279ee4) [45a585e6](https://github.com/aigentive/ralphx.app/commit/45a585e65ca3741086051776670d53898062878e)
- **Publishing workflows** now expose initial Auto Publish before the first PR, keep Commit & Publish and PR supervision controls available for linked plan-branch ideation workspaces, and draft plan PR descriptions from commit/diff context with fallback to the existing template. [4f63fb95](https://github.com/aigentive/ralphx.app/commit/4f63fb95231145b7c32bed0229cac09583a99884) [f127ae72](https://github.com/aigentive/ralphx.app/commit/f127ae7221b544e96677baeb36427a71b2fa5e84) [b12266f6](https://github.com/aigentive/ralphx.app/commit/b12266f6afd468f3fe9e645951a68647e70e1b54)
- **Agent chat continuity** improves provider-switch and restart behavior: queued messages continue draining after completion, project chats that silently complete can recover on startup, and linked edit-mode workspaces regain internal terminal access while plan-owned/non-edit workspaces remain blocked. [506bf87a](https://github.com/aigentive/ralphx.app/commit/506bf87a17dd38600fb37b037bdeb2ebe0cd4382) [af137123](https://github.com/aigentive/ralphx.app/commit/af137123c510de7edc31e2911cf4b79d4ea04d8e) [955b7e7a](https://github.com/aigentive/ralphx.app/commit/955b7e7a907234eebe5b7e6ad545b194e3817f14)
- **Conversation-linked Jira** now persists issue references and surfaces a Jira artifact tab with issue details, cached description/criteria/comments/attachments, search-based reassignment, refresh, and unlink actions. [24407cfe](https://github.com/aigentive/ralphx.app/commit/24407cfe5a6c223197eb3302ca0df9a7bbc29a15)

## Fixes And Polish
- **Kanban board density** gains a default/mini toggle in board controls; mini mode keeps title and progress/status chrome while hiding description, metadata badges, blocked-reason copy, and duration details. [bc46dbdc](https://github.com/aigentive/ralphx.app/commit/bc46dbdc9b7dd46210d269c13dbc5e48d9a322df)
- **Provider CLI management** is less noisy and less stale: update-toast dismissal opens a confirmation with `Remind me again` / `Don't ask again`, RX-managed Codex resolves from app-owned storage, and provider setting/install/update changes immediately re-probe visible CLI status. [9b174623](https://github.com/aigentive/ralphx.app/commit/9b174623d8701ecf8a4726ce586590065f06e1fa) [56089b1f](https://github.com/aigentive/ralphx.app/commit/56089b1fee4089d0a60ebdee373632ba003f0376)
- **Plan action UI** is more state-aware: the hidden `Implement directly` runtime handoff no longer appears as an extra chat message, approved-plan CTAs disappear when a workspace has uncommitted changes, and chromeless plan actions move to a separate wrapping row. [bca6b571](https://github.com/aigentive/ralphx.app/commit/bca6b5718a5330cfa4a0d69c7d7d2d213fd5f550) [bc1eabc5](https://github.com/aigentive/ralphx.app/commit/bc1eabc51d2df4029ae8175907783bdff47d45d8) [9be842cc](https://github.com/aigentive/ralphx.app/commit/9be842cc039fa2d2d7dcc8e204b16154ef97f988)
- **Publishing and repair feedback** is cleaner: publish failure toasts show compact sanitized text, literal tool-call PR-description output can be recovered, and completed `UpdateOnly` repairs no longer leave publication state stuck at `fixing` when an open PR should remain monitored. [19e07238](https://github.com/aigentive/ralphx.app/commit/19e072381f1d99472a33d6866203b222bc829f45) [6650cf14](https://github.com/aigentive/ralphx.app/commit/6650cf146467b278b8ab346e5fe07a3ba23e1e95)
- **Agent chat scrolling** no longer jiggles near the bottom on ordinary mouse-wheel input; bottom-settle behavior is limited to scrollbar-driven intent and click-based scroll-to-bottom remains direct. [ee61cbf8](https://github.com/aigentive/ralphx.app/commit/ee61cbf8e3ee84a16da328d53cf9a136d5f4bf58)

## Known Issues
- Existing ideation sessions already locked to the wrong branch are not backfilled by this release; repairing or re-cutting those worktrees requires a separate flow. [56ca2eec](https://github.com/aigentive/ralphx.app/commit/56ca2eeceba3938f85933600e1fedf00db40d8a4)
- Managed CLI installs under the old project-local `.artifacts/managed-cli` path are no longer discovered and need to be reinstalled into the app-data-backed managed CLI location. [56089b1f](https://github.com/aigentive/ralphx.app/commit/56089b1fee4089d0a60ebdee373632ba003f0376)
