# RalphX.app v0.31.0

RalphX.app 0.31.0 focuses on queued chat continuity, transcript scrolling/layout polish, and clearer file-path and terminal placement UI.

## User-Facing Changes
- **Queued chat messages** can now be sent immediately: RalphX interrupts the current CLI provider process, continues on the existing provider session, preserves queued attachments and context, and keeps the agent visibly running through the continuation. [dd189b18](https://github.com/aigentive/ralphx.app/commit/dd189b188fce83af010701bcbe8149a6ac9eb8af)
- **Chat transcript layout** now keeps user-authored attachments and references aligned with the user message bubble, so related message artifacts read as one grouped unit. [d48645f1](https://github.com/aigentive/ralphx.app/commit/d48645f133cf3131583a79706136d724728157db)
- **Chat bottom scrolling** now settles to the true end of the transcript instead of stopping a few pixels short, with sticky-bottom behavior preserved across wheel scrolling, scrollbar use, scroll-to-bottom actions, transcript growth, and viewport resizing. [0b22831a](https://github.com/aigentive/ralphx.app/commit/0b22831afe1d76607b379bb601a465f817c80c12)
- **Diff headers** now show workspace-relative file paths when possible instead of forcing a generic `.../` prefix; paths outside the workspace remain fully qualified, with full paths still available through hover and copy affordances. [0ca28512](https://github.com/aigentive/ralphx.app/commit/0ca285128b68d32fa37b332f7239f08d4a5d0087)
- **Terminal placement controls** stay synchronized after closing the side panel: when an open terminal automatically moves under chat, the selector now reflects the effective `chat` placement instead of a stale side-panel state. [baa0ed15](https://github.com/aigentive/ralphx.app/commit/baa0ed150063ba00b38de1ecf9817dee5e0d9a8d)

## Developer And Maintainer Changes
- Expanded focused coverage for queued send-now continuation paths, diff header tooltip/provider behavior, chat bottom-scroll settle paths, resize cleanup, transcript-root resize behavior, and updated visual snapshot handling for affected chat and ideation surfaces. [dd189b18](https://github.com/aigentive/ralphx.app/commit/dd189b188fce83af010701bcbe8149a6ac9eb8af) [0ca28512](https://github.com/aigentive/ralphx.app/commit/0ca285128b68d32fa37b332f7239f08d4a5d0087) [0b22831a](https://github.com/aigentive/ralphx.app/commit/0b22831afe1d76607b379bb601a465f817c80c12)
