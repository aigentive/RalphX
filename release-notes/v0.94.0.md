# RalphX.app v0.94.0

RalphX.app 0.94.0 accelerates Workspace Review startup, adds per-conversation review automation control, and makes PR autofix recovery states actionable.

## User-Facing Changes

- **Workspace Review startup** presents confirmation sooner by using cached provider readiness while refreshing in the background; hover and focus can warm the review path, and stale preview or provider state can be refreshed and reopened without a full reset. [aede223b](https://github.com/aigentive/ralphx.app/commit/aede223b5e08b5a87312bcb511b7b465765ac9c6)
- **Auto Review & Fix** can now be set per conversation with an **Inherit / On / Off** override in the publish automation and review surfaces, allowing a review → fix → review loop without changing global Review defaults. [08de7890](https://github.com/aigentive/ralphx.app/commit/08de7890ff05f8744ea43abdd1251026c050f0e4)
- **Composer runtime selection** now refreshes the model list immediately after a provider change; provider, model, effort, and provider-specific controls remain aligned across workspace review and active-role sends. [813a7612](https://github.com/aigentive/ralphx.app/commit/813a7612d3f209a797445227e40aa31b0a6d7f11)
- **PR autofix recovery** now shows held repairs as a distinct publish state with re-check, retry, stop, and budget/history controls; branches behind their configured base are routed for base refresh before remaining on a CI-evidence hold. [19bcc754](https://github.com/aigentive/ralphx.app/commit/19bcc75473afd9754a35e91ca919b84ce0984959) [bba85edb](https://github.com/aigentive/ralphx.app/commit/bba85edb2bee6b8cb77c781ead560a7cc34fb95c)
- **Agent coordination** now receives fresh runtime context at turn start and resume, including active delegation identities, task state, branch status, linked plans, and team state; resumed delegates can re-arm only the exact jobs authorized by the backend wake. [00e64a4e](https://github.com/aigentive/ralphx.app/commit/00e64a4e1b624991fcff6403f7290fe89c2bdb0e) [6a13a81d](https://github.com/aigentive/ralphx.app/commit/6a13a81d9734da03b11ff69220f22b4903c25a16)

## Fixes And Polish

- **Inbox attention lanes** now refresh from accepted project and standalone lifecycle events, so an active conversation moves from **Needs you** to **Working** rather than retaining a stale grouping. [ee683c55](https://github.com/aigentive/ralphx.app/commit/ee683c55f8220c9dd07c11ff34981186b17cb047)

## Developer And Maintainer Changes

- **Rust CI and coverage workflows** now use a maximum of two shards, with matching artifact and aggregation updates. [aede223b](https://github.com/aigentive/ralphx.app/commit/aede223b5e08b5a87312bcb511b7b465765ac9c6)
