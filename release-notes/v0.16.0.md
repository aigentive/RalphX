# RalphX.app v0.16.0

RalphX.app 0.16.0 expands Commit & Publish diff scoping, makes large diffs hunk-based with lazy context loading, and surfaces agent CLI launch failures in chat.

## User-Facing Changes

- **Commit & Publish diff scopes** now cover Uncommitted, Unstaged, Staged, All commits, and specific commits; for example, All commits shows the `base..HEAD` cumulative diff and uses a commit-count label. [dae7ae67](https://github.com/aigentive/ralphx.app/commit/dae7ae673845a3d21430f8ca63d609bccf1d7670)
- **Large diff rendering** now uses server-parsed hunks instead of full-file payloads, so an 8,556-line file with a 232-line diff opens immediately instead of hitting the “Diff too large to render quickly” placeholder. [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab)
- **Diff context expansion** now lazy-fetches “Show N unchanged lines” ranges on demand, including in Commit & Publish and the Review Changes dialog’s Workspace Changes and History tabs. [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab)
- **Agent chat errors** now show a visible assistant error message when Claude/Codex CLI startup fails before streaming begins, instead of leaving the conversation with a stopped typing indicator and no explanation. [7ebfc1bc](https://github.com/aigentive/ralphx.app/commit/7ebfc1bc462af04d0683d92ff51abbf9fa9ca35f)

## Fixes And Polish

- **Streaming chat responses** compact older live text blocks during active conversations, reducing unbounded message-node growth while preserving scrollback history. [d0d00764](https://github.com/aigentive/ralphx.app/commit/d0d00764860e14d40e630eb3eba600031d49721a)

## Developer And Maintainer Changes

- **Diff API internals** now return `FileDiff` as hunks, total line counts, and binary metadata, with staged, unstaged, worktree, between-ref, and commit-specific diff callers sharing the unified diff parser. [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab)
- **Diff transport** adds staged, unstaged, cumulative, and file-content-range Tauri/HTTP surfaces while reusing existing `FileChange` / `FileDiff` response shapes. [dae7ae67](https://github.com/aigentive/ralphx.app/commit/dae7ae673845a3d21430f8ca63d609bccf1d7670) [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab)
- **Regression coverage** expands across diff parsing, path safety, range endpoint branches, ref-kind plumbing, conflict hunk synthesis, pre-spawn chat failures, and streaming text compaction. [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab) [7ebfc1bc](https://github.com/aigentive/ralphx.app/commit/7ebfc1bc462af04d0683d92ff51abbf9fa9ca35f) [d0d00764](https://github.com/aigentive/ralphx.app/commit/d0d00764860e14d40e630eb3eba600031d49721a)

## Known Issues

- Existing `*_file_diff` commands do not yet use the new range endpoint’s file-path validator; this remains a follow-up hardening item. [04e32b32](https://github.com/aigentive/ralphx.app/commit/04e32b32b25955dce21f97aa8ac3d57f6ade86ab)
