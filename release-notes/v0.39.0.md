# RalphX.app v0.39.0

RalphX.app 0.39.0 improves agent chat ergonomics, Jira-linked conversations, and workspace publish/review flows.

## User-Facing Changes
- **Jira-linked conversations** now refresh issue details when a conversation gains or changes a Jira link, render markdown correctly in dark theme, use a more compact details layout, hide empty metadata, and show unassigned issues with an inline self-assign action. [54e87ba9](https://github.com/aigentive/ralphx.app/commit/54e87ba90e536c95898ebb9c36b6b787779d177d)
- **Agent chat composer** now minimizes when inactive, expands on textarea focus, and keeps the `+` attachments/references menu separate from the mode selector so opening menus no longer resizes the chat block. [8669302a](https://github.com/aigentive/ralphx.app/commit/8669302aec7532db14f125a1135a63f3db68db94)
- **Agent workspace review** now opens merged workspaces on the cumulative **All commits** diff by default while preserving manual diff-mode changes, making merged results immediately reviewable. [22fb4dbf](https://github.com/aigentive/ralphx.app/commit/22fb4dbf2e93afa50cb78392a91253e8087dc881) [628ba50d](https://github.com/aigentive/ralphx.app/commit/628ba50d2780757de4665a3d6de15073c9b31bda)
- **Agents project sidebars** now continue loading long conversation lists as users scroll near the bottom, fixing projects with 200+ conversations stopping after the first visible page. [628ba50d](https://github.com/aigentive/ralphx.app/commit/628ba50d2780757de4665a3d6de15073c9b31bda)
- **Plan and publish workflows** now hide stale Plan-mode actions after **Implement Directly**, only show the **Verification** tab when verification evidence exists, and enforce backend auto-publish after update-from-base flows. [327019db](https://github.com/aigentive/ralphx.app/commit/327019db505301ed1bda7088f1174a42570a5816) [a1b34dea](https://github.com/aigentive/ralphx.app/commit/a1b34dea035a38a038b39b75603d2296e92b04d2)

## Fixes And Polish
- **Agent chat scrolling** no longer jiggles between near-bottom and true-bottom states during normal manual scrolling, while preserving the explicit scroll-to-bottom button behavior. [6507b26a](https://github.com/aigentive/ralphx.app/commit/6507b26a8d6965fc84ab478bc1ccd526cac5dda8)
- **Workspace publish notifications** now clear successful publish-progress toasts instead of leaving a forever-spinning “Publishing workspace” message visible. [1a0619e7](https://github.com/aigentive/ralphx.app/commit/1a0619e7c3812377d8313e81118f61d7f0601f44)
- **Claude permission prompts** now resolve the correct MCP permission-request tool for transport/profile-specific agents, fixing ideation starts and chat panels that could get stuck at “No messages yet” when preapproval was routed to the wrong server. [748eba9e](https://github.com/aigentive/ralphx.app/commit/748eba9e8fd1369732c361ef484f470feca357e0)

## Developer And Maintainer Changes
- Expanded test coverage for composer focus/menu behavior, Agents sidebar pagination, merged diff-mode defaults/resets, and Plan/Verification visibility rules; refreshed affected composer visual baselines. [8669302a](https://github.com/aigentive/ralphx.app/commit/8669302aec7532db14f125a1135a63f3db68db94) [22fb4dbf](https://github.com/aigentive/ralphx.app/commit/22fb4dbf2e93afa50cb78392a91253e8087dc881) [628ba50d](https://github.com/aigentive/ralphx.app/commit/628ba50d2780757de4665a3d6de15073c9b31bda) [327019db](https://github.com/aigentive/ralphx.app/commit/327019db505301ed1bda7088f1174a42570a5816)
- Reworked Claude permission CLI argument construction to share transport-aware, profile-aware resolution with allowed-tool injection while preserving configured defaults for non-external agents. [748eba9e](https://github.com/aigentive/ralphx.app/commit/748eba9e8fd1369732c361ef484f470feca357e0)
