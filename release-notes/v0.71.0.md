# RalphX.app v0.71.0

This release expands scripted and supervised agent orchestration, clarifies workspace review control, and preserves richer context across agent conversations.

## User-Facing Changes
- **Scripted Agent workflows** now support approval, start/pause/resume/cancel controls, durable run progress, phases, invocations, logs, usage, and child-transcript navigation; returning to a conversation rehydrates workflow state. [8235d957](https://github.com/aigentive/ralphx.app/commit/8235d957f518d0cd8566bb7be9aea4a99144faf1)
- **Orchestration flows** now guide native Agent work through Plan → Create Proposals → Tasks → Start Tasks, while Automation setup exposes its versioned plan, shared Commit & Publish surface, and explicit lifecycle/judge-retry actions. [f072375e](https://github.com/aigentive/ralphx.app/commit/f072375e7bc7a195922615806685d7f14118cca0) [f45b09e6](https://github.com/aigentive/ralphx.app/commit/f45b09e6de624c93599efe0481d853f9317fdae6)
- **Settings > Agents** now provides role-based manual runtime defaults for provider, model, effort, capability, speed, and persona; composers use the active role default until locally overridden and can reset back to it. [40021133](https://github.com/aigentive/ralphx.app/commit/4002113357afe0512c4d8227b1020df1faf4bac5)
- **Agent context** now includes provider-neutral Jira, Linear, and ClickUp ticket attachments; frozen plan, ticket, and Granola selections remain viewable from message history, while contextual tabs appear only when the matching attachment exists. [92da55c9](https://github.com/aigentive/ralphx.app/commit/92da55c936568a72b9f09f619d0bbb7e82c98018) [c8c944dc](https://github.com/aigentive/ralphx.app/commit/c8c944dc91decc80cea04d019314d98b4333d2a9) [efd207f3](https://github.com/aigentive/ralphx.app/commit/efd207f3fd0cef14fc34043f53893403524d8b0e)
- **Workspace Review** now makes GitHub auto-merge pauses and restoration visible, and lets a user approve an exact blocking review snapshot after confirmation while preserving its blocking findings distinctly from a passing review. [512d5294](https://github.com/aigentive/ralphx.app/commit/512d5294c2f43dbe76aae8c262d99fdeaad270bc) [2084285d](https://github.com/aigentive/ralphx.app/commit/2084285d533f34b687b3ca9303b13f8f5e1db7f4)

## Fixes And Polish
- **Conversation management** now supports bulk-archiving visible eligible sessions; conversations requiring pull-request handling remain available through the individual archive flow, and failed rows stay selected for retry. [fd445f93](https://github.com/aigentive/ralphx.app/commit/fd445f93690968504358e47f26c4eb1f9aadcf1d)
- **Notifications** no longer mark History items read on open, exclude archived conversations from counts, keep CTA toasts until their target action settles, and open the exact conversation when a macOS notification is clicked. [a68a3a1c](https://github.com/aigentive/ralphx.app/commit/a68a3a1c46b380ad00fefd5fc0a3384b84b77b5f) [bd886221](https://github.com/aigentive/ralphx.app/commit/bd8862212f0a10c0b2f443c149426bf9ee9e1501) [19b046a6](https://github.com/aigentive/ralphx.app/commit/19b046a653f020021df3587fd46d1f243c335560)
- **Delegation** now keeps direct and nested delegates in the parent workspace worktree; expanded delegate cards recover in-progress child output and show an explicit waiting state before text arrives. [8b23cfdb](https://github.com/aigentive/ralphx.app/commit/8b23cfdbc80a6cc5a71d2ed421c84fbc63117875) [a50d7e4b](https://github.com/aigentive/ralphx.app/commit/a50d7e4b19a957c9ec09dedb8bc39f9bf9e39353)
- **Fresh installs** no longer begin with the first Agent conversation globally paused before provider onboarding completes; provider readiness remains the launch gate. [e7e14b8](https://github.com/aigentive/ralphx.app/commit/e7e14b8a76d1a4a5374953691715215d2d771e0a)
- **Failed-task restarts** now recover proven completed work into review when validation evidence permits; uncertain recovery leaves existing work intact and surfaces a blocking result. [b60ce856](https://github.com/aigentive/ralphx.app/commit/b60ce856e694c0d5112df6e74dc833af67b7df05)
- **Workspace Open** now offers iTerm2 and macOS Terminal targets alongside a separate Built-in Terminal action; file links opened through terminal targets use the file’s parent directory. [b797ec0b](https://github.com/aigentive/ralphx.app/commit/b797ec0b43bdbef525def10c4cbcbedb4c44cab8)
- **GitHub connection handling** now distinguishes provider or probe failures from credential loss; future `gh` launches remove inherited GitHub token variables by default, with a Repository settings opt-out. [8eaac8da](https://github.com/aigentive/ralphx.app/commit/8eaac8da3216b47fee1687669fdc27d5941a80c8) [031447a4](https://github.com/aigentive/ralphx.app/commit/031447a49d35deeea25fd66efcf351199e90f3cc)

## Developer And Maintainer Changes
- **Daily Release recovery** now accepts a validated `release_notes_from` tag, allowing cumulative notes and GitHub metadata to cover a skipped published range without changing version selection. [d588bc98](https://github.com/aigentive/ralphx.app/commit/d588bc98bb7255d4edf201f18bca03ec6783f638)
- **Contributor guidance** now reflects canonical agent/MCP ownership, the current task-state model, verified architecture patterns, and model-specific GPT-5.5/GPT-5.6 prompting guidance. [88880f0c](https://github.com/aigentive/ralphx.app/commit/88880f0c1cd123bb32a2caee9276d1942bf77140) [ace91982](https://github.com/aigentive/ralphx.app/commit/ace91982eddf3c6a0f10d272c77684a1fccd4695) [6ab473fc](https://github.com/aigentive/ralphx.app/commit/6ab473fc27b1d1be5afc78560fcc53d58e623084)
