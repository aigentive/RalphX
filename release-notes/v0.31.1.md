# RalphX.app v0.31.1

RalphX.app 0.31.1 stabilizes active chat recovery, live turn hydration, and streaming timeline consistency.

## User-Facing Changes
- Chat conversations now restore in-progress turn state when you switch away and back, so the panel keeps the live tail of the timeline instead of showing only persisted history while the turn is still running. [69515c08](https://github.com/aigentive/ralphx.app/commit/69515c085867ede6e13dfb9a9bd52f52b2fd97fa)
- Active-turn hydration now covers streaming tasks, streaming tool calls, and streaming content blocks, keeping partial text and live indicators visible during recovery. [69515c08](https://github.com/aigentive/ralphx.app/commit/69515c085867ede6e13dfb9a9bd52f52b2fd97fa)

## Fixes And Polish
- Tool-call and task indicators now reconcile more consistently after hydration: tool calls are replaced by id, existing task metadata is preserved when active state only carries status updates, and duplicate tool-call blocks already represented as task cards are suppressed. [69515c08](https://github.com/aigentive/ralphx.app/commit/69515c085867ede6e13dfb9a9bd52f52b2fd97fa)

## Developer And Maintainer Changes
- Adds shared active-state merge helpers and regression coverage for the recovery hook, partial-text hydration, task metadata preservation, id-based tool-call replacement, and duplicate block suppression. [69515c08](https://github.com/aigentive/ralphx.app/commit/69515c085867ede6e13dfb9a9bd52f52b2fd97fa)
