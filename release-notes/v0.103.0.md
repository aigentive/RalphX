# RalphX.app v0.103.0

This release reworks project setup around explicit intents, guided repository checks, and cancellable cloning.

## User-Facing Changes
- **Project setup** now starts with explicit **Clone Repository**, **Create New Repository**, and **Add Existing Repository** choices, with plain-language explanations of each flow. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)
- **Repository cloning** now shows live progress, supports cancellation, and continues into the shared project configuration flow after a successful clone. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)
- **Folder selection** now preflights candidate directories before registration—for example, offering to create a repository when a folder is not yet one, or to open an already-registered repository instead of adding it again. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)
- **Clone setup** can surface authenticated GitHub repositories for selection, offers advanced options for depth, branch, and submodules, and suggests an SSH URL when HTTPS authentication fails. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)

## Fixes And Polish
- **Clone failures** no longer leave the wizard stuck on an undismissable progress screen when starting the clone is rejected; it returns to configuration and shows the start error. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)
- **Clone progress recovery** can re-check a clone’s current or completed status if an event arrives before the UI listener attaches, avoiding a falsely stuck operation. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)

## Developer And Maintainer Changes
- **Clone execution** uses a dedicated Git command lane and configurable timeout (`RALPHX_GIT_CLONE_TIMEOUT_SECS`, default 900 seconds), preventing long clones from occupying workspace automation’s background Git lane. [281f721f](https://github.com/aigentive/RalphX/commit/281f721fa364509da55692ec2891e5f871ce457a)
