# RalphX.app v0.99.0

RalphX.app 0.99.0 expands role-scoped Atlassian agent access, improves auto-repair recovery and hold visibility, and stabilizes desktop notifications.

## User-Facing Changes
- **Atlassian integration** now gives RalphX-spawned agents direct Jira and Confluence MCP tools using the existing validated integration; per-role permissions in **Settings → Agents → Roles** offer Role default, None, Read, and Read + write access. [10b1a1b2](https://github.com/aigentive/RalphX/commit/10b1a1b2061725fb0e5a8874923bd41d0677d98f)
- **Auto-repair holds** now use a redesigned card with a status strip, clear headline, repair-agent narrative, primary action, and expandable Details timeline; transient base-parity CI holds offer **Re-run failed checks**. [4906c9ba](https://github.com/aigentive/RalphX/commit/4906c9baa6cbd928a53e4a11af9e074071a1c8f1)
- **Workspace publishing and repair** no longer fail solely because PR-description generation fails: existing PR metadata is preserved, while new PRs use programmatic title and managed-body fallbacks. [54353733](https://github.com/aigentive/RalphX/commit/54353733616cbfbcdc9ee640ef4b4dd83981f544)
- **Desktop notifications** now cap concurrent actionable click-waits and clear stale RalphX notifications after 15 minutes, preventing long unattended sessions from starving app responsiveness. [45a5b9b0](https://github.com/aigentive/RalphX/commit/45a5b9b03451518d06184bda4bf0be306a3d1099)

## Fixes And Polish
- **Blocked repair retries** can now recover when an orphaned PR-update handoff has a durably observed branch push, clearing the effect fence so retry evaluation can continue. [2452359e](https://github.com/aigentive/RalphX/commit/2452359e18797b7f6427a8d0b87ac467dc35ca12)
- **Conflict-routed repairs** no longer treat an unverified target base commit as integrated, preventing base-freshness workflows from being incorrectly parked. [54353733](https://github.com/aigentive/RalphX/commit/54353733616cbfbcdc9ee640ef4b4dd83981f544)

## Developer And Maintainer Changes
- Rust coverage CI timeouts were extended to accommodate normal shard runtime variation while retaining per-test hang detection. [4906c9ba](https://github.com/aigentive/RalphX/commit/4906c9baa6cbd928a53e4a11af9e074071a1c8f1) [54353733](https://github.com/aigentive/RalphX/commit/54353733616cbfbcdc9ee640ef4b4dd83981f544)

## Known Issues
- Atlassian tools apply to RalphX-spawned agents and RalphX-native delegates; Claude native `Task` subagents do not receive role-tiered Atlassian access. Runs started before this update must be respawned for access. [10b1a1b2](https://github.com/aigentive/RalphX/commit/10b1a1b2061725fb0e5a8874923bd41d0677d98f)
- When more than three actionable notification click-waits are pending, additional notification clicks focus RalphX but do not deep-navigate until a slot is reclaimed. [45a5b9b0](https://github.com/aigentive/RalphX/commit/45a5b9b03451518d06184bda4bf0be306a3d1099)
