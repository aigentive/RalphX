# RalphX.app v0.12.1

RalphX.app 0.12.1 focuses on publish-progress behavior, faster Agents breadcrumb title lookup, and sidebar tracking after publication.

## User-Facing Changes

- Publishing now switches from confirmation into a publish-specific live progress dialog that can be dismissed after confirmation, while the Commit & Publish panel remains the durable progress surface. [d9a9801c](https://github.com/aigentive/ralphx.app/commit/d9a9801c0d15a4698bf51e968a1a683032db380e)
- Agents breadcrumb titles now resolve through a metadata-only conversation summary path instead of loading message history, avoiding title lookups that populate the history cache with a one-message window. [541b8f0d](https://github.com/aigentive/ralphx.app/commit/541b8f0dcfff89a302bda883d08f339a288d81d0)
- Renaming an agent conversation continues to update the breadcrumb and now keeps the new summary cache in sync with existing conversation/history caches. [541b8f0d](https://github.com/aigentive/ralphx.app/commit/541b8f0dcfff89a302bda883d08f339a288d81d0)

## Fixes And Polish

- When a selected conversation moves from Active to Draft after a PR is published, the sidebar now expands and prioritizes Draft so the conversation remains easy to find. [d9a9801c](https://github.com/aigentive/ralphx.app/commit/d9a9801c0d15a4698bf51e968a1a683032db380e)

## Developer And Maintainer Changes

- Added the `get_agent_conversation_summary` Tauri command, frontend API wrapper, dedicated summary query key, and unit/mock coverage for summary lookup, rename updates, and cache invalidation. [541b8f0d](https://github.com/aigentive/ralphx.app/commit/541b8f0dcfff89a302bda883d08f339a288d81d0)
- Isolated publish-specific confirm/progress dialog state without changing the generic async confirmation hook or backend publish orchestration. [d9a9801c](https://github.com/aigentive/ralphx.app/commit/d9a9801c0d15a4698bf51e968a1a683032db380e)
- The attempted move of core Rust, IPC, frontend, visual snapshot, and coverage CI jobs to a self-hosted macOS ARM64 runner was reverted in this release. [6aaf39fe](https://github.com/aigentive/ralphx.app/commit/6aaf39fe49e4812e1ea03c4e35d33feb9090634a), [ef308bcb](https://github.com/aigentive/ralphx.app/commit/ef308bcb0c1ca5967d778480ce3c8dccbe9342fb)
