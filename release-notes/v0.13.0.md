# RalphX.app v0.13.0

RalphX.app 0.13.0 improves agent chat continuity, macOS GUI-launched provider CLI auth, and Agents workspace/composer feedback.

## User-Facing Changes

- Project and Task chats preserve context more reliably across silent agent respawns: follow-up turns receive prior session history, Claude project agents resume stored provider sessions when available, and finalized or no-output assistant turns render in the chat timeline instead of blank bubbles. [4b8bbc82](https://github.com/aigentive/ralphx.app/commit/4b8bbc82551d0d1c553b28a8ed64d262981cafe5), [d1ae80b6](https://github.com/aigentive/ralphx.app/commit/d1ae80b62f811ecd3349abbdb283cbd1a1fea8b2)
- Finder, Spotlight, and Dock launches now forward the user’s login-shell environment into spawned Claude and Codex CLIs, fixing unauthenticated agent runs when credentials such as `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, or `CODEX_HOME` are set in shell profiles. [f4d374e1](https://github.com/aigentive/ralphx.app/commit/f4d374e17677a8982d1e90eeb8d5ab3ebf1755a9)
- The Agents composer now has shell-style input history: Up/Down recalls up to 50 deduplicated sent messages from local storage while preserving the current draft. [9c707185](https://github.com/aigentive/ralphx.app/commit/9c7071859abe2e490b07c485d42c0d1d1c833f4e)
- The Agents sidebar now refreshes workspace publication state in near real time with bulk polling, so published/unpublished status updates without manual refresh or navigation. [b5d7df04](https://github.com/aigentive/ralphx.app/commit/b5d7df04856b5e0748c435bd75b9baa0a0edac48)
- Agent conversation workspace cleanup now runs after startup to reduce stale worktree and branch accumulation, pausing while agents are active and only removing clean RalphX-owned worktrees already contained in the target ref. [44907ca6](https://github.com/aigentive/ralphx.app/commit/44907ca683bcea4872ee7abadf0ffe5e38f9d849)

## Fixes And Polish

- AppTopBar breadcrumbs now update live when the session namer saves titles for ideation and other non-project agent conversations; previously these often required a manual refresh. [7464938e](https://github.com/aigentive/ralphx.app/commit/7464938e2067ea0679909066bd5d98b8e377572e)
- Ideation chats avoid a duplicate queue-path completion after an idle silent shutdown, preventing an empty or waiting state from obscuring an already-persisted assistant reply. [148fd978](https://github.com/aigentive/ralphx.app/commit/148fd978a6980b44724ae581b79a03c4ca64e4fd)
- Log redaction now covers environment variable names containing `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, or `CREDENTIAL`, including examples such as `GITHUB_TOKEN`, `AWS_SECRET_ACCESS_KEY`, and `DB_PASSWORD`. [4d95907e](https://github.com/aigentive/ralphx.app/commit/4d95907ee33437192c673546b2416230c41aa949)

## Developer And Maintainer Changes

- The local Tauri/Vite dev loop now pins the dev server to `127.0.0.1` and adds TIME_WAIT diagnostics for dev ports, avoiding macOS IPv6 `localhost` bind failures after crashed dev sessions. [e98dc6b4](https://github.com/aigentive/ralphx.app/commit/e98dc6b45f793461c83f0c4923ce0980494c5629)
