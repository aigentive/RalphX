# RalphX.app v0.23.0

RalphX.app 0.23.0 improves Agents navigation and tool access, Commit & Publish diff refresh behavior, and terminal interaction reliability.

## User-Facing Changes
- Agents sidebar conversations now toggle: clicking the selected conversation again deselects it and returns to the start-new-run composer. [532dc673](https://github.com/aigentive/ralphx.app/commit/532dc673ad37bd231902c5b2ef5b2cef87f6dcc4)
- Claude-backed Agents screen modes now have web search tools available in agent, chat, and ideation modes through `WebFetch` and `WebSearch`. [1141a13a](https://github.com/aigentive/ralphx.app/commit/1141a13acc67f16837d3a348bfdfd28e9e013242)
- Agent-mode runs receive clearer task-ledger guidance for multi-step work, with generated ledger appendices preserved in Claude-spawned prompts and a warning when substantial tool-backed work bypasses ledger tools. [e6229353](https://github.com/aigentive/ralphx.app/commit/e6229353b352e69ef87edb6fb80cac3e3615d78d)
- Commit & Publish keeps published diff bodies hydrated after publishing instead of showing only file headers, and stops showing the auto-merge pipeline spinner once PR supervision is already monitoring. [3f0a70c2](https://github.com/aigentive/ralphx.app/commit/3f0a70c25aa90f3716d83495fca73efb8024baa0)

## Fixes And Polish
- The collapsed terminal header remains clickable after an agent conversation starts, and terminal drag/drop handling no longer gets stuck from stale listener cleanup paths. [7f9125f2](https://github.com/aigentive/ralphx.app/commit/7f9125f27a8d3478808565a515b02bdc900e2495)

## Developer And Maintainer Changes
- Claude prompt construction now writes generated system prompts to a temporary file for `--append-system-prompt-file`, with inline prompt injection as a fallback if temp-file creation fails. [e6229353](https://github.com/aigentive/ralphx.app/commit/e6229353b352e69ef87edb6fb80cac3e3615d78d)
- The canonical Claude harness config, tool-alignment rule, and regression tests now agree on the readonly `WebFetch` and `WebSearch` tool set for Agents screen modes. [1141a13a](https://github.com/aigentive/ralphx.app/commit/1141a13acc67f16837d3a348bfdfd28e9e013242)
- Focused regression coverage was added or updated for sidebar deselection, terminal listener cleanup, prompt generation, Claude command construction, ledger-warning heuristics, diff hydration, publish state, and auto-merge sync. [532dc673](https://github.com/aigentive/ralphx.app/commit/532dc673ad37bd231902c5b2ef5b2cef87f6dcc4), [7f9125f2](https://github.com/aigentive/ralphx.app/commit/7f9125f27a8d3478808565a515b02bdc900e2495), [e6229353](https://github.com/aigentive/ralphx.app/commit/e6229353b352e69ef87edb6fb80cac3e3615d78d), [3f0a70c2](https://github.com/aigentive/ralphx.app/commit/3f0a70c25aa90f3716d83495fca73efb8024baa0)
