# RalphX.app v0.61.0

RalphX.app 0.61.0 focuses on safer task/worktree recovery, Agent workspace navigation and publishing, and clearer review/provider controls.

## User-Facing Changes

- **RalphX-launched commands and provider paths** now preserve the user’s shell PATH ordering so shim/toolchain managers stay ahead of Homebrew/system binaries, while Settings > Providers autosaves custom binary/env-file paths on blur or Enter, accepts `~`/`~/...`, and keeps rejected drafts visible with inline errors. [1159dc83](https://github.com/aigentive/ralphx.app/commit/1159dc83a63dbe661fcea1e3a5ad2ce67d945acc), [d47035cf](https://github.com/aigentive/ralphx.app/commit/d47035cfeb3eb3690c2d6e0f94af22e445f842a9)
- **Agent workspace task navigation** now sends queued, paused, running, and merge task links from the execution bar into the owning Agent conversation’s Tasks tab, focusing the selected task; merge rows prefer the Agent workspace title when available. [77e1e342](https://github.com/aigentive/ralphx.app/commit/77e1e3429cb1b51ab6e2df0b40681ef3992698b9)
- **Linked plan workspaces** now resolve their effective worktree for Open in Cursor, file-link opens, and the built-in terminal, so linked plan branches can be opened directly instead of failing against a stale conversation worktree path. [6b92dd41](https://github.com/aigentive/ralphx.app/commit/6b92dd41d8dadb170191a090729ed6e889c3d7ad)
- **Plan and publish workflows** now scope Plan-tab restart UI to the attached ideation session and linked plan-branch worktree, and plan-mode workspaces show the Commit & Publish tab so Update from Base and publish readiness remain reachable even before publication state exists. [75ce141d](https://github.com/aigentive/ralphx.app/commit/75ce141d5e2b46929fdde9c4a49e6715ee1acc5b), [86ee283c](https://github.com/aigentive/ralphx.app/commit/86ee283ce29e91f18e67a7acebe0638800bc66be)
- **Workspace Review** now keeps synthetic review/fixer prompts out of chat, adds a Workspace Review autofix toggle plus a manual Fix Issues path for current blocking findings, and derives review run identity from backend/runtime context instead of model-supplied payload fields. [3b87ff98](https://github.com/aigentive/ralphx.app/commit/3b87ff98997d53d02d910179360de1bd23fa6fe9), [b51b1336](https://github.com/aigentive/ralphx.app/commit/b51b1336e1c844cabbe0da417799d998613696a2)

## Fixes And Polish

- **Task restart and recovery** now routes stopped execution restarts through the normal Ready path, blocks restart preparation when the task worktree has uncommitted changes, preserves fresh retry metadata during reconciliation, and labels recovery-driven stream cancellations separately from user stops. [a12b1f5b](https://github.com/aigentive/ralphx.app/commit/a12b1f5b9fb8233e27cb8aa6eee58e595d78a4c7)
- **Task execution worktrees and merge freshness** now keep worktree claim/guard behavior aligned through execution entry and classify missing source branches as `branch_missing`, improving retry and recovery behavior for stale or unavailable branches. [ca851928](https://github.com/aigentive/ralphx.app/commit/ca851928dab73b7131d0d143606da5faac1c3634)
- **PR detail views** now render GitHub `<details>/<summary>` sections as native disclosure blocks and use more visible loading placeholders in the Agents PR tab and PR status strip. [e7a08a41](https://github.com/aigentive/ralphx.app/commit/e7a08a41fde37fbb6faa91723f9379e45ed07fd4)

## Developer And Maintainer Changes

- **Workspace Review settings persistence** adds the autofix setting through domain config, command/handler types, SQLite schema/migration, repository tests, and frontend settings wiring. [3b87ff98](https://github.com/aigentive/ralphx.app/commit/3b87ff98997d53d02d910179360de1bd23fa6fe9)
- **Workspace Review MCP/runtime alignment** removes `created_by_run_id` from the model-facing workspace review schemas and prompt guidance, then threads `agentRunId` through the MCP runtime context for Claude/Codex launch paths and tool transport. [b51b1336](https://github.com/aigentive/ralphx.app/commit/b51b1336e1c844cabbe0da417799d998613696a2)
- **Coverage workflow hardening** passes explicit PR/head metadata to Codecov and avoids failing solely because Codecov omits a `codecov/patch` status after successful coverage uploads. [3b87ff98](https://github.com/aigentive/ralphx.app/commit/3b87ff98997d53d02d910179360de1bd23fa6fe9)
