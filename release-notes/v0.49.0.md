# RalphX.app v0.49.0

RalphX.app 0.49.0 improves plan navigation, issue-tab visibility, and PR-backed task execution recovery.

## User-Facing Changes
- **Plan-mode conversations** now show a secondary **View Plan** CTA when the right-side plan tab is hidden, while keeping **Approve Plan** available and hiding **View Plan** once the plan tab is already open. [34f9b415](https://github.com/aigentive/ralphx.app/commit/34f9b415c81fa67c7f254ef9eac1817005c4cc48)
- **Project conversation tabs** no longer show an empty **Issues** tab when there are no open issues; conversations with open issues still expose the tab as before. [a23d4a2b](https://github.com/aigentive/ralphx.app/commit/a23d4a2b68d2934331b4a5dd6eea5d52ea1cfbfd)
- **PR-backed task execution** now fails closed when plan PR branch publication fails, keeping the task in `MergeIncomplete` with failed push status instead of reporting a green state before the branch is actually pushed. [2b73d055](https://github.com/aigentive/ralphx.app/commit/2b73d0559abd581c80cafa4aaf308b91af6f2ce5)

## Fixes And Polish
- **Artifact tab availability** now refreshes after agent run and turn completion events so issue-driven tab visibility stays aligned with the current conversation data. [a23d4a2b](https://github.com/aigentive/ralphx.app/commit/a23d4a2b68d2934331b4a5dd6eea5d52ea1cfbfd)

## Developer And Maintainer Changes
- Centralizes agent-conversation issue query wiring behind a shared React Query hook/key helper used by both the artifact pane and issues panel. [a23d4a2b](https://github.com/aigentive/ralphx.app/commit/a23d4a2b68d2934331b4a5dd6eea5d52ea1cfbfd)
- Adds focused frontend coverage for hidden and already-visible plan-tab CTA states, plus artifact-pane coverage for empty and non-empty issue lists. [34f9b415](https://github.com/aigentive/ralphx.app/commit/34f9b415c81fa67c7f254ef9eac1817005c4cc48) [a23d4a2b](https://github.com/aigentive/ralphx.app/commit/a23d4a2b68d2934331b4a5dd6eea5d52ea1cfbfd)
- Expands Rust recovery coverage for PR-mode publication failures and regular plan-task completion failures. [2b73d055](https://github.com/aigentive/ralphx.app/commit/2b73d0559abd581c80cafa4aaf308b91af6f2ce5)
