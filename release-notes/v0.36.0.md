# RalphX.app v0.36.0

RalphX.app 0.36.0 expands provider/model workflows, improves Agents project-context handoffs, and polishes plan/publish and chat-history UI states.

## User-Facing Changes
- **Provider switching in active conversations** now lets users change providers mid-chat; queued next turns preserve the selected provider, model, and effort, while historical assistant messages keep their own provider attribution. [2874b65e](https://github.com/aigentive/ralphx.app/commit/2874b65e009f1f0122c52445017900f4c3a70568)
- **Fable model support** is available across Claude model selection surfaces, including agent selection and ideation team configuration; provider-aware model choices now better reflect available provider capabilities. [68d5d425](https://github.com/aigentive/ralphx.app/commit/68d5d42543932b173e7707269fe03667e499cd45)
- **Agents project handoffs** now move directly into the newly created project with a fresh conversation state, and narrowed sidebar filters keep the new project visible instead of hiding it after creation. [bb8f7c25](https://github.com/aigentive/ralphx.app/commit/bb8f7c2563d9de6d78a3dad1e6ab8082e0cf1498)
- **Project context on conversation selection** now follows the selected Agents conversation, so project-aware views such as Kanban no longer remain on a previous project after switching conversations. [0526520a](https://github.com/aigentive/ralphx.app/commit/0526520afff464660a115e15ced39e96642e857c)
- **Plan-linked edit workspaces** keep the relevant Plan shortcut and Commit & Publish action visible after a direct plan implementation handoff returns the workspace to edit mode. [d6ef79e8](https://github.com/aigentive/ralphx.app/commit/d6ef79e84fe9ae5b2d72cce6e29ac1c778fa181d)

## Fixes And Polish
- **Publish dialog progress** now initializes from the active run state, avoiding a stale completed-step snapshot that could briefly appear and then revert when live state arrives. [33911c27](https://github.com/aigentive/ralphx.app/commit/33911c27f1a8dcf990e5d18d82584c796a70d442)
- **Paged chat history previews** preserve structured artifact/tool-result preview data in collapsed entries, including compact JSON/text fallback previews for parseable MCP payloads. [0cf4b31f](https://github.com/aigentive/ralphx.app/commit/0cf4b31fe84ab12d43bb19bc1cf583293a431b24)

## Developer And Maintainer Changes
- Expanded provider CLI management plumbing with managed/unmanaged provider policy handling, startup update checks, settings routing, and IPC/API coverage for the new provider-management surface. [68d5d425](https://github.com/aigentive/ralphx.app/commit/68d5d42543932b173e7707269fe03667e499cd45)
- Added focused regression coverage for provider-switch queue replay, per-message provider attribution, project creation/filter preservation, linked edit publish visibility, publish progress initialization, and paged preview shaping. [2874b65e](https://github.com/aigentive/ralphx.app/commit/2874b65e009f1f0122c52445017900f4c3a70568) [bb8f7c25](https://github.com/aigentive/ralphx.app/commit/bb8f7c2563d9de6d78a3dad1e6ab8082e0cf1498) [d6ef79e8](https://github.com/aigentive/ralphx.app/commit/d6ef79e84fe9ae5b2d72cce6e29ac1c778fa181d) [0cf4b31f](https://github.com/aigentive/ralphx.app/commit/0cf4b31fe84ab12d43bb19bc1cf583293a431b24)
