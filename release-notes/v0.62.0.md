# RalphX.app v0.62.0

RalphX.app 0.62.0 focuses on Plan/Proposal workflow cleanup, task-runtime transcript and validation clarity, and safer Git/ticket automation behavior.

## User-Facing Changes

- **Plan and proposal navigation** now keeps proposal content inside the Plan tab, removes the standalone Agent Proposals tab/header shortcut, and falls back legacy `proposal` tab state to Plan. The Plan lifecycle banner now covers needs-approval, approved, and accepted/work states with state-specific actions and colors. [661a573f](https://github.com/aigentive/ralphx.app/commit/661a573f204eac156c9b4c5662ef69775c70b434), [1ab529a1](https://github.com/aigentive/ralphx.app/commit/1ab529a1a676a8db3b9d06fdf951bd81f64e2d18)
- **Agents task details** now use a one-column runtime-stage view, preserving repeated execution/review/merge attempts and routing historical stages with transcripts into the main Agents chat while showing an explicit no-transcript state when none exists. [7a7f623f](https://github.com/aigentive/ralphx.app/commit/7a7f623fe195e363434f266f77e36f2c065ba018)
- **Task execution and review transcripts** now hide backend bootstrap rows such as task-start control messages while injecting compact task runtime context for execution, review, and re-execution starts. [2dd32ac0](https://github.com/aigentive/ralphx.app/commit/2dd32ac0fd7c7bd04746295b3abc367817667d00)
- **Agents sidebar grouping** now has a dedicated Group control before Filters and can group conversations by automation, with automation group labels refreshing after automation rename, status, or deletion changes. [903031d7](https://github.com/aigentive/ralphx.app/commit/903031d7d156c3878dae55d0407e6e00e51ba181)
- **Ticket-linked Agent workspaces** no longer let Jira, Linear, or ClickUp references override the selected base branch; ticket metadata is instead reflected in generated workspace branch names such as `ralphx/{project}/agent-jira-{ticket-token}-{conversation}`. [a61f11f0](https://github.com/aigentive/ralphx.app/commit/a61f11f0903afe6aaabaa5d10184d4ebea81b719)

## Fixes And Polish

- **Task execution chat updates** now surface new execution messages instead of leaving the conversation pane stuck on older content while progress continues elsewhere. [937e5c2d](https://github.com/aigentive/ralphx.app/commit/937e5c2d2ae7c7f43ae44e78472b8dc9522e2bd9)
- **GitHub auto-merge toggles** now stay visually in sync after successful supervision changes, allow disabling auto-merge on plan-managed workspaces without requiring the plan worktree checkout, and show backend-provided error messages more reliably. [424c812f](https://github.com/aigentive/ralphx.app/commit/424c812f5c3afed57a76d67f2871685ed17b6d73)
- **Task validation evidence** now distinguishes approving post-change evidence from baseline-only, stale, failed, or otherwise ineligible passed runs, so validation panels do not present diagnostic baselines as final review proof. [b24e7bf3](https://github.com/aigentive/ralphx.app/commit/b24e7bf36478378be7468a4147f298aad2374933)

## Developer And Maintainer Changes

- **Application event wiring** was de-genericized across transition, scheduler, reconciliation, PR polling, startup, and recovery services, consolidating emission through the concrete application event sink instead of carrying Tauri runtime generics through the service graph. [c3142146](https://github.com/aigentive/ralphx.app/commit/c3142146f4aaef0be536c491833c165ec7490bce)
- **Execution validation contracts** were aligned across prompts, MCP schema text, backend validation eligibility, event payloads, and frontend validation state so `run_task_validation` is treated as post-change evidence by default, with baseline use reserved for explicit diagnostics. [b24e7bf3](https://github.com/aigentive/ralphx.app/commit/b24e7bf36478378be7468a4147f298aad2374933), [2dd32ac0](https://github.com/aigentive/ralphx.app/commit/2dd32ac0fd7c7bd04746295b3abc367817667d00)
- **Local development seeding** gained a compact production snapshot path for `dev-fresh`, retaining recent agent chat conversations while copying the rest of the database intact. [7a7f623f](https://github.com/aigentive/ralphx.app/commit/7a7f623fe195e363434f266f77e36f2c065ba018)
