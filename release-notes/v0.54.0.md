# RalphX.app v0.54.0

RalphX.app 0.54.0 focuses on Workspace Review annotations, Commit & Publish review flow, and Claude Sonnet model selection.

## User-Facing Changes
- **Workspace Review annotations** now flow from the review agent into Commit & Publish diffs: file cards can show local review-note counts, and matching hunk notes render under the relevant hunk headers in inline and paged diff views. [ac18a2c5](https://github.com/aigentive/ralphx.app/commit/ac18a2c5bfa3ca94f3d3c3391ee8172b285233d8)
- **Review-to-publish flow** promotes `Commit & Publish` when the current Review has passed and is not outdated, keeps `Run again` available from the Review actions menu, and returns idle Review chat focus to the workspace conversation when switching tabs. [590aeb40](https://github.com/aigentive/ralphx.app/commit/590aeb40a9111dc956ab91f8e15f60ca5903115b)
- **Inline publish diffs** page by default, reserve row-count-based placeholder height while content loads, and preserve upward paging scroll anchors to reduce jumpiness while expanding files or moving through large diffs. [fede5543](https://github.com/aigentive/ralphx.app/commit/fede55438b5db63d336881acf08fbb58a673b2a7)
- **Claude model selection** adds pinned `claude-sonnet-4-6` and `claude-sonnet-5` entries alongside the moving `sonnet` alias, with Claude Code CLI capability gating so unsupported exact model IDs are not shown or launched. [61ba198b](https://github.com/aigentive/ralphx.app/commit/61ba198b8950fb9dd5ce01bde4c3495393114814)
- **Workspace Review setup and repair** now resolve global/project defaults for project-backed workspaces, let repair agents fetch blocking Review artifacts before editing, and pause for a fresh review when a repair changes a stale blocking review. [f3ac00a0](https://github.com/aigentive/ralphx.app/commit/f3ac00a052fb48f7af300df0d327c099bb1a6973) [dec5f538](https://github.com/aigentive/ralphx.app/commit/dec5f5383a0acc5f3c60e13793dfb1b6fd77a023) [f5d5a5bd](https://github.com/aigentive/ralphx.app/commit/f5d5a5bd6b847309ceb6626a678f692770ba4250)

## Fixes And Polish
- **Forked and review conversation routing** now follows the visible/owning conversation: plan-mode proposal UI prefers the active forked conversation, and Review tab context follows the conversation that owns the newly started review. [ec82fac7](https://github.com/aigentive/ralphx.app/commit/ec82fac7aeb3dd90051e36a43d0fc5011818a350) [b42fce92](https://github.com/aigentive/ralphx.app/commit/b42fce929e7c8760733e478200007aa7b24416ea)
- **Live running chats** preserve already-streamed assistant text, task markers, and tool calls after switching away and returning to a still-running conversation. [82250ee0](https://github.com/aigentive/ralphx.app/commit/82250ee04c01c0a6e233880f572bc14c4d4ee3ce)
- **Review and publish status rendering** is more accurate: refreshed PRs that are already synced no longer keep `Commit & Publish` enabled, actively running reviews show `reviewing` instead of stale `blocked`, and stopped/orphaned reviews no longer remain stuck in `Running` or `Waiting` after stop or app restart. [4029166e](https://github.com/aigentive/ralphx.app/commit/4029166e4b87e345fd54abf0ada63c753b1d5e70) [0efe5e46](https://github.com/aigentive/ralphx.app/commit/0efe5e4684540bbb99b464b1c7002547895f9ddb) [b6ad473c](https://github.com/aigentive/ralphx.app/commit/b6ad473c10aa38971d6232230882b2139c651d80)
- **Publish progress feedback** keeps the in-flight publishing toast visible across conversation or pane navigation until the operation finishes. [57db5216](https://github.com/aigentive/ralphx.app/commit/57db5216be8a03d76a7c7ddf6711ad9adf899aaa)
- **Agents sidebar and runtime widgets** use space and scroll more predictably: expanded project panels can fill unused vertical space beside collapsed siblings, and background child-runtime updates no longer scroll the parent chat transcript. [cf2d8ae4](https://github.com/aigentive/ralphx.app/commit/cf2d8ae4f46e8c0636b34bd2c75c2523369a6be7) [e2a14962](https://github.com/aigentive/ralphx.app/commit/e2a14962944235211908c7df3c719876503b0ce4)

## Developer And Maintainer Changes
- **Workspace Review hunk annotation infrastructure** adds typed annotation storage, a SQLite migration, backend read/write flows, frontend diff API types/transforms, and regenerated MCP bindings for the structured review-note path. [ac18a2c5](https://github.com/aigentive/ralphx.app/commit/ac18a2c5bfa3ca94f3d3c3391ee8172b285233d8)
- **Agent review/repair contracts** keep review artifacts and hunk annotations on bounded MCP surfaces: repair gains `get_artifact` for blocking review inputs, and the reviewer write path accepts structured hunk annotations independently from the Markdown artifact. [dec5f538](https://github.com/aigentive/ralphx.app/commit/dec5f5383a0acc5f3c60e13793dfb1b6fd77a023) [ac18a2c5](https://github.com/aigentive/ralphx.app/commit/ac18a2c5bfa3ca94f3d3c3391ee8172b285233d8)
