# RalphX.app v0.24.0

RalphX.app 0.24.0 focuses on provider selection UX, reliable chat image attachments, and clearer agent/sidebar workflow tracking.

## User-Facing Changes

- Provider selection now uses a split layout with cleaner provider states: disabled providers can be clicked to show context without changing the active runtime, dropdown tooltips no longer auto-open, and provider icon focus styling is cleaner. [ff89dbc1](https://github.com/aigentive/ralphx.app/commit/ff89dbc16ef84482be343eea4c4920cd9ec29c27)
- Chat image attachments now persist through send, storage, and reload, rendering as visual previews in both sent messages and the composer attachment gallery instead of falling back to filename/size pills. [a8f659c4](https://github.com/aigentive/ralphx.app/commit/a8f659c4e601efd2494810da0537ee6256b0fbf2)
- Agents sidebar project grouping now sorts “Latest” by each project’s newest conversation and auto-expands the project containing the last selected conversation when returning to the view. [66915fe8](https://github.com/aigentive/ralphx.app/commit/66915fe8a1fadcfdec8b938062fb73464a16e8a1)
- Agent task decomposition now splits multi-part read-only audits and numbered investigation lists into separate ledger tasks, making checklist-style work easier to track and less likely to collapse into one broad task. [50c6f175](https://github.com/aigentive/ralphx.app/commit/50c6f1752a62c63c3b5ca222f20eeddc5d5cde5d)

## Fixes And Polish

- Image preview dialogs now include accessibility description text for screen readers. [a8f659c4](https://github.com/aigentive/ralphx.app/commit/a8f659c4e601efd2494810da0537ee6256b0fbf2)
- Provider branding and theme polish were refreshed, including an updated Claude logo and effort bar colors moved onto theme tokens. [ff89dbc1](https://github.com/aigentive/ralphx.app/commit/ff89dbc16ef84482be343eea4c4920cd9ec29c27)

## Developer And Maintainer Changes

- Added focused attachment validation, storage, rendering, and preview coverage for the end-to-end chat attachment path. [a8f659c4](https://github.com/aigentive/ralphx.app/commit/a8f659c4e601efd2494810da0537ee6256b0fbf2)
- Updated Agents sidebar backend/frontend coverage for group-by-project latest ordering and persisted-selection auto-expand behavior. [66915fe8](https://github.com/aigentive/ralphx.app/commit/66915fe8a1fadcfdec8b938062fb73464a16e8a1)
- Tightened generated agent prompt/catalog regression coverage for task-ledger behavior, including empty-ledger gating before other tool-backed investigation work. [50c6f175](https://github.com/aigentive/ralphx.app/commit/50c6f1752a62c63c3b5ca222f20eeddc5d5cde5d)
