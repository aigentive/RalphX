# RalphX.app v0.68.0

RalphX.app 0.68.0 focuses on automation lifecycle reliability, continuous PR review monitoring, and safer branch/workspace recovery.

## User-Facing Changes
- **Automation setup and completion flows** now avoid creating empty setup conversations on click, route new automations through the Agent composer with Automation preselected, publish an integration PR after the first merged run, and archive/clean merged-success run workspaces. [aa5d4e77](https://github.com/aigentive/ralphx.app/commit/aa5d4e777e85e8c60ec3953e6d73fee9bbe3b788), [f5ea567f](https://github.com/aigentive/ralphx.app/commit/f5ea567f81b47c88851f1c88731796ddab4edf99), [a1819284](https://github.com/aigentive/ralphx.app/commit/a1819284f82af432973919cf557e84e39f91f7e1)
- **Review PR mode** now continuously monitors new pushes, exposes pause/restart controls, prompts before stopping an active review, and keeps PR-review controls separate from workspace-review actions. [489780f2](https://github.com/aigentive/ralphx.app/commit/489780f2ca8421d91a1378f0f58ade67065d320f)
- **Branch freshness conflicts** now have dedicated plan/task branch-update states, visible task details for progress or blocked conflict resolution, and a retry path for blocked updates. [6d2daf4c](https://github.com/aigentive/ralphx.app/commit/6d2daf4cf2a515edb8785890dd5308ef56736977)
- **Restart Implementation** can recover previously cleaned linked workspaces or plan branches before recreating tasks, and now presents safer, less path-specific failure copy when recovery is not safe. [e6a6195d](https://github.com/aigentive/ralphx.app/commit/e6a6195ded27b3ec929b22a3f16c1fcecb1d1f62)
- **macOS release artifacts** are now validated before publication so ambiguous, wrong-architecture, unsigned, unstapled, or Gatekeeper-rejected DMGs are blocked earlier. [bd45c07a](https://github.com/aigentive/ralphx.app/commit/bd45c07a31bc87f7046a6176ca34b038b724fac4)

## Fixes And Polish
- **Provider/model selection** now uses desktop cascading flyouts, compact Back-based drill-in navigation, a flatter Advanced menu, and a single provider settings entry. [6d910e47](https://github.com/aigentive/ralphx.app/commit/6d910e47bfce0aba0598449799418856385884ad)
- **Linked workspace review diffs** now use the merge base as the review baseline, so change counts no longer include unrelated upstream commits; linked workspaces also show the effective review base label. [3e415363](https://github.com/aigentive/ralphx.app/commit/3e4153637049ec1e2da11f85630abde1f53dc00e)
- **Plan review notifications** in the sidebar now resolve linked agent workspaces and navigate to the associated review conversation instead of failing to open a target. [c6372a06](https://github.com/aigentive/ralphx.app/commit/c6372a066d63b113ebf2458989052d2d192ec2a0)
- **Automation judge phase handling** now keeps repeated runs for the same unfinished goal item on the same phase label and validates `stop` verdicts against the goal state that will be persisted. [087dbb08](https://github.com/aigentive/ralphx.app/commit/087dbb08109de45212cd7f29e028ef473e7cc7b6)
- **Automatic follow-up Agent conversations** are now opt-in by default: fresh installs start disabled, upgraded installs are reset off once, and users can re-enable the setting afterward. [447dcdf8](https://github.com/aigentive/ralphx.app/commit/447dcdf85036d2c2ee9afb87dda07cc1b0f0862c)

## Developer And Maintainer Changes
- Added release-path hardening for final-DMG notarization/stapling, exact single-DMG selection, read-only artifact validation, sanitized process telemetry, and updated release documentation. [bd45c07a](https://github.com/aigentive/ralphx.app/commit/bd45c07a31bc87f7046a6176ca34b038b724fac4)
- Expanded backend/frontend coverage across branch-update states, PR review monitor recovery, automation cleanup/publishing, restart workspace recovery, review settings migration, and runtime selector edge cases. [6d2daf4c](https://github.com/aigentive/ralphx.app/commit/6d2daf4cf2a515edb8785890dd5308ef56736977), [489780f2](https://github.com/aigentive/ralphx.app/commit/489780f2ca8421d91a1378f0f58ade67065d320f), [e6a6195d](https://github.com/aigentive/ralphx.app/commit/e6a6195ded27b3ec929b22a3f16c1fcecb1d1f62), [6d910e47](https://github.com/aigentive/ralphx.app/commit/6d910e47bfce0aba0598449799418856385884ad)
