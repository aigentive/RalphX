# RalphX.app v0.30.0

RalphX.app 0.30.0 focuses on release-history browsing, publish-review navigation, and chat/terminal timeline stability.

## User-Facing Changes
- **Release notes and updates:** adds a two-column release notes dialog with a month-grouped sidebar timeline, current-version badge, bundled + GitHub release metadata, and an inline “Update to vX.Y.Z” action for newer versions; cached or bundled notes remain available when GitHub metadata cannot be fetched. [916357a2](https://github.com/aigentive/ralphx.app/commit/916357a2af657d5188f589d8803bd909bc144eed)
- **Publish review diffs:** reworks inline diff rows so file cards fill the content width without colliding with the scrollbar lane, moves the full-diff action next to jump-to-file, and makes collapse all / expand all apply predictably to files loaded later. [876480fe](https://github.com/aigentive/ralphx.app/commit/876480fedb6953e21633c2d27a21bd6b719e75ba)
- **Collapsed task tray:** windows the task list around the first active task so in-progress work remains visible even when it is not among the newest tasks, with reveal controls for hidden tasks before or after the window. [e847f477](https://github.com/aigentive/ralphx.app/commit/e847f477b0612bd73bf1abd4a10f6de87a33c6b7)
- **Chat transcript rendering:** stabilizes assistant message grouping across hydrated conversations, live streaming rows, and virtualized offsets, while keeping sticky-bottom chats pinned when the finalized last message grows. [33b0636e](https://github.com/aigentive/ralphx.app/commit/33b0636ea8bb46dfdc2e5a6cd6d8c31062ed3769), [d9ca6370](https://github.com/aigentive/ralphx.app/commit/d9ca6370d1c54df609afffddd12bd601889eafd2)

## Fixes And Polish
- **Terminal drawer state:** preserves the terminal’s last in-app runtime status across conversation switches, so a collapsed but still-open terminal no longer returns with a stale `closed` header. [c257b3c2](https://github.com/aigentive/ralphx.app/commit/c257b3c27cd8490dd9448187a6ed78a42d7c89d7)
- **Composer tray polling:** keeps collapsed workspace-change badge updates on the lightweight review-summary path while preserving near-real-time counts and click-to-expand file lists. [d3b69ac7](https://github.com/aigentive/ralphx.app/commit/d3b69ac71425e0b79d9ede5b707e423fcd8e525a)

## Developer And Maintainer Changes
- **Release notes coverage:** expands tests for version sorting/merging, GitHub metadata caching and fallbacks, Tauri invoke wrappers, dialog loading/error states, update-button flows, and markdown sanitization. [916357a2](https://github.com/aigentive/ralphx.app/commit/916357a2af657d5188f589d8803bd909bc144eed)

## Known Issues
- The release-notes update flow follows Tauri’s forward-only updater path; rollback to an earlier version is not supported in this release. [916357a2](https://github.com/aigentive/ralphx.app/commit/916357a2af657d5188f589d8803bd909bc144eed)
