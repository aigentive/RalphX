# RalphX.app v0.17.0

RalphX.app 0.17.0 focuses on workspace opening, cleaner project boundaries, and faster Commit & Publish diffs.

## User-Facing Changes

- **Chat workspaces can now be opened directly from the header** with a split `Open` control: use the last-selected target immediately or pick another available editor/file-manager target from the dropdown, with an `Opening` state while launch is in progress. [a6ec41e3](https://github.com/aigentive/ralphx.app/commit/a6ec41e34a17b98cb67ed06eaaab4e2aa9386319)
- **Commit & Publish diffs now hydrate lazily and collapse generated files by default**: off-screen file bodies wait until scrolled into view, while sourcemaps, lockfiles, minified bundles, Jest snapshots, and `dist/build/out/target/` paths render as compact generated-file rows with a `Show anyway` override. [40467234](https://github.com/aigentive/ralphx.app/commit/404672340681c5b13eb2fa052c2625098ae129ef)
- **Project and mode navigation is smoother**: the project selector is back in the navbar for `graph`, `kanban`, and `ideation`, and Agents conversations that were only switched into Ideation can switch back to Chat or Edit when no active ideation/execution state owns the workspace. [d55d01d8](https://github.com/aigentive/ralphx.app/commit/d55d01d859c0db2450bf35f2e97fec1115a03f02), [b6be8b30](https://github.com/aigentive/ralphx.app/commit/b6be8b30a8a57aaec04b50897edcc00f0473c3b9)
- **Agent effort choices now reflect the installed Claude CLI’s capabilities**, so the Agents composer and active conversation controls no longer offer effort values the current CLI cannot accept. [18f82e03](https://github.com/aigentive/ralphx.app/commit/18f82e03e21c4ada2f30f9454c1c1764f495a1ac)
- **RalphX-owned artifacts are kept out of active project checkouts**: memory archive snapshots and MCP trace logs now stay on the app-owned side of the boundary, and QA examples use `RALPHX_AGENT_SCREENSHOT_DIR` for explicit screenshot storage. [e71d1196](https://github.com/aigentive/ralphx.app/commit/e71d1196444904626d00004fe55ecb7f12205bf2)

## Fixes And Polish

- **Internal MCP startup is more resilient when trace logging is unavailable**: missing or unwritable trace directories are non-fatal, reducing tool-registration failures caused by diagnostics setup. [47060039](https://github.com/aigentive/ralphx.app/commit/4706003920013d4a6b97c0dfbd882cf4ebd6bac8)

## Developer And Maintainer Changes

- **`./dev-fresh` now handles linked git worktrees more safely** by seeding an ephemeral SQLite snapshot from the main checkout, cleaning up only the snapshot it created, rebuilding MCP runtime packages before launch, and scoping external MCP cleanup by port to avoid interfering with unrelated prod-owned processes. [852e66dd](https://github.com/aigentive/ralphx.app/commit/852e66dd641a414412a083f26074033f9cf743fe)
- **MCP trace path handling is safer and more contained**: trace writes are routed to process-owned locations, unsafe configured trace directories are rejected, and path-safety coverage now includes relative paths, unexpected leaf directories, project-local paths, and symlink escapes. [47060039](https://github.com/aigentive/ralphx.app/commit/4706003920013d4a6b97c0dfbd882cf4ebd6bac8), [e71d1196](https://github.com/aigentive/ralphx.app/commit/e71d1196444904626d00004fe55ecb7f12205bf2)
