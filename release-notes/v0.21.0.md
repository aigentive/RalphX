# RalphX.app v0.21.0

RalphX.app 0.21.0 improves chat composer attachments and context-tagging, stabilizes Terminal controls, and fixes linked PR publication reconciliation.

## User-Facing Changes
- **Chat composer attachments** now accept drag-and-drop files, including native Tauri/Finder drops and browser file drops, using the same attachment flow and accepted file-type rules as the existing `+` button. [bb64dae0](https://github.com/aigentive/ralphx.app/commit/bb64dae02b4dbc1aa5c1dd64274fd84d76a39197)
- **Composer context guidance** now shows `/`, `@`, and `$` affordances alongside the existing send/newline hints, and selected conversations now show the same helper guidance as the new-agent composer. [45b4eda0](https://github.com/aigentive/ralphx.app/commit/45b4eda023ffb5efff503d37cda066e6f980dd33)
- **Terminal panels** now keep a stable header visible before initialization, while collapsed, and after close; collapse hides the body without ending the session, while close explicitly ends the session and leaves a `Closed` header for orientation. [d0b094f7](https://github.com/aigentive/ralphx.app/commit/d0b094f7eb0dac5a9da7720dbd67bf3937dc756b)

## Fixes And Polish
- **Linked workspace PR state** now reconciles when the associated GitHub PR reaches a merged or closed terminal state, preventing merged conversations from continuing to appear `blocked`, in `auto-merge`, `needs_agent`, or `failed`. [836e6457](https://github.com/aigentive/ralphx.app/commit/836e64575a94e3fec3b020aee1945d20171f82bd)

## Developer And Maintainer Changes
- Shared composer attachment handling now has focused coverage for helper validation plus native/browser drop paths. [bb64dae0](https://github.com/aigentive/ralphx.app/commit/bb64dae02b4dbc1aa5c1dd64274fd84d76a39197)
- Composer context-reference plumbing adds structured project-reference data to the send path and updates related frontend send-message, IPC start-conversation, and agent composer coverage. [45b4eda0](https://github.com/aigentive/ralphx.app/commit/45b4eda023ffb5efff503d37cda066e6f980dd33)
