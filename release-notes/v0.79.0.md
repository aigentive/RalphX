# RalphX.app v0.79.0

RalphX.app 0.79.0 reworks native delegation around bound task assignments, delegate-local task ledgers, and exact-run lifecycle settlement.

## User-Facing Changes
- **Bound delegate work** now reserves the selected caller task before launch and surfaces its task number, title, delegate, and assignment state in chat and task UI. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
- **Delegate-local task ledgers** keep a delegated conversation’s decomposition steps separate from its parent task, including for nested delegation; parent tasks are not mirrored into the delegate’s list. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
- **Assignment lifecycle UI** distinguishes assigned work, completion requests, and release requests from terminal delegation outcomes, making the bound work item easier to inspect. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
- **Explorer and worker delegates** can manage local coordination tasks and inspect or request settlement of their assignment; explorer filesystem and shell restrictions remain unchanged. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)

## Fixes And Polish
- **Assignment settlement** now marks a parent task done only after the exact delegate run requested completion and exits successfully; failed, cancelled, orphaned, or implicitly completed runs reopen the bound task instead. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
- **Delegate reuse and nested delegation** now preserve caller lineage and attempt-specific ownership, preventing stale or unrelated runs from settling a newer assignment. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)

## Developer And Maintainer Changes
- Adds durable, attempt-scoped delegate-assignment persistence and startup recovery across SQLite and in-memory task repositories. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
- Extends native delegation and MCP contracts with assignment lifecycle operations that derive orchestration identity from trusted runtime context rather than model-provided IDs. [71bee4e5](https://github.com/aigentive/ralphx.app/commit/71bee4e5e6af4dbc6a5e6d52ceebf2887b2f19bd)
