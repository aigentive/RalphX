# RalphX.app v0.25.0

RalphX.app 0.25.0 focuses on Atlassian chat references, cleaner model selector metadata, and PR descriptions that better reflect the reviewed net diff.

## User-Facing Changes

- Chat workflows now integrate Atlassian JIRA and Confluence references, preserving selected reference metadata through optimistic sends so reference chips can render immediately before backend hydration. [d2350d38](https://github.com/aigentive/ralphx.app/commit/d2350d388609bd8a86c00280ce5d96883f70d1ed)
- Workspace publish PR descriptions now prioritize the net branch diff over chronological commit history, with obvious merge/update noise filtered before description generation. [d5ff794c](https://github.com/aigentive/ralphx.app/commit/d5ff794cb6c3eac3377cd549c3e3c41b4b5da5f5)
- Model selectors now use the backend registry as the runtime source of truth, avoiding stale hardcoded frontend metadata; the `gpt-5.5` menu label no longer shows the stray “(Current)” suffix. [84cd48ff](https://github.com/aigentive/ralphx.app/commit/84cd48ff19b61918ef480a45364e65707d79b013)

## Fixes And Polish

- Atlassian reference chips render more cleanly: linked chips no longer show browser underlines, and long labels can wrap naturally. [d2350d38](https://github.com/aigentive/ralphx.app/commit/d2350d388609bd8a86c00280ce5d96883f70d1ed)
- Normal app startup no longer shows the Atlassian awareness toast, so the new integration does not interrupt baseline app views. [d2350d38](https://github.com/aigentive/ralphx.app/commit/d2350d388609bd8a86c00280ce5d96883f70d1ed)

## Developer And Maintainer Changes

- Removes the frontend model catalog fallback from the runtime data path, adds explicit model-registry readiness handling, and updates `AgentsView` test fixtures for the backend-owned registry contract. [84cd48ff](https://github.com/aigentive/ralphx.app/commit/84cd48ff19b61918ef480a45364e65707d79b013)
- Adds Atlassian service, client, command, and repository surfaces, with patch-coverage scoping for the new integration-heavy files. [d2350d38](https://github.com/aigentive/ralphx.app/commit/d2350d388609bd8a86c00280ce5d96883f70d1ed)
