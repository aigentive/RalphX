# RalphX.app v0.26.0

RalphX.app 0.26.0 improves PR-based workspace starts, branch/PR base selection, and HTTPS repository health diagnostics.

## User-Facing Changes
- The base selector now separates **Branches** and **Pull Requests**, so conversations and ideation sessions can start from either a local branch or a GitHub PR head branch. [673d84c5](https://github.com/aigentive/ralphx.app/commit/673d84c5c00e46fe5f432026896ad2d1a1735327)
- PR-based workspace starts now preserve structured source-PR metadata while still creating the workspace from the PR head branch for compatibility with existing branch-based flows. [673d84c5](https://github.com/aigentive/ralphx.app/commit/673d84c5c00e46fe5f432026896ad2d1a1735327)
- HTTPS GitHub repositories no longer show a warning banner solely because the remote uses `https://`; repositories configured through `gh auth setup-git` can now be presented as healthy. [4d77dc85](https://github.com/aigentive/ralphx.app/commit/4d77dc8559f0339cb88615fa0cdff87731b0b287)

## Fixes And Polish
- The PR picker can search GitHub pull requests separately from branches and keeps the selected PR visible when later searches change the result set. [673d84c5](https://github.com/aigentive/ralphx.app/commit/673d84c5c00e46fe5f432026896ad2d1a1735327)
- Repository diagnostics now distinguish missing Git credential-helper setup from a configured helper that can work with `gh`, reducing unnecessary prompts toward SSH for healthy HTTPS remotes. [4d77dc85](https://github.com/aigentive/ralphx.app/commit/4d77dc8559f0339cb88615fa0cdff87731b0b287)

## Developer And Maintainer Changes
- Threads `sourcePullRequest` through frontend APIs, Tauri commands, chat/workspace context, backend workspace models, and SQLite storage, backed by a new migration. [673d84c5](https://github.com/aigentive/ralphx.app/commit/673d84c5c00e46fe5f432026896ad2d1a1735327)
- Adds typed GitHub PR search plumbing and updates IPC/API coverage for PR base picker paths and workspace payloads. [673d84c5](https://github.com/aigentive/ralphx.app/commit/673d84c5c00e46fe5f432026896ad2d1a1735327)
- Keeps HTTPS repository diagnostics within the existing app-safe Git/`gh` subprocess resolution path used by GUI-launched apps. [4d77dc85](https://github.com/aigentive/ralphx.app/commit/4d77dc8559f0339cb88615fa0cdff87731b0b287)
