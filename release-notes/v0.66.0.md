# RalphX.app v0.66.0

RalphX.app 0.66.0 focuses on Agents-first navigation, safer PR/review handoffs, and more predictable notifications.

## User-Facing Changes
- **Agents is now the primary workspace surface**: standalone Graph, Kanban, and Ideation pages have been retired, while legacy saved views and task/ideation links route into the retained Agents conversation context. [49847e10](https://github.com/aigentive/ralphx.app/commit/49847e1072bad9adedd30a66e6739e39d21a2550)
- **Task history is easier to navigate in Agents task details**: the previous breadcrumb is now a compact dropdown with Current first, prior attempts newest-first, and transcript availability preserved for historical stages. [8d33be03](https://github.com/aigentive/ralphx.app/commit/8d33be03e9acc8fbb5dbfa00cfb563ce2558d609)
- **Notifications are more usable**: the drawer closes via outside click while preserving close button/Escape behavior, stays clamped on narrow windows, keeps long review/history content readable, and Agent notification CTAs open the exact referenced conversation. [1de68c03](https://github.com/aigentive/ralphx.app/commit/1de68c03aefa96a3cef5bbdc7746e9d3427c2ccf) [767f3b06](https://github.com/aigentive/ralphx.app/commit/767f3b061d33ca8ec9a42750dc5c01741cf2d09c)
- **PR closure on archive is now explicit**: archiving an Agent conversation no longer closes an associated PR unless the unchecked “Close pull request” option is selected, and Review PR conversations cannot close the reviewed PR through archive. [68f7ab20](https://github.com/aigentive/ralphx.app/commit/68f7ab20f24f280f5f8a9f3446850a6248d8fc56)
- **Review PR reruns can auto-approve clean follow-ups**: Review PR workspaces now include a default-on Auto Approve switch that keeps the first review manual, then can submit later passing monitor-triggered re-reviews when the proposal is an approval. [975970e7](https://github.com/aigentive/ralphx.app/commit/975970e7a04120358eff0299d357c3ed84728f4e)

## Fixes And Polish
- **Plan-to-Edit implementation starts from a fresh provider session**: approved plan handoffs no longer inherit the planning thread, model/agent mismatches are less likely to resume stale context, and empty Codex exits are reported as explicit no-output failures. [e0764e15](https://github.com/aigentive/ralphx.app/commit/e0764e15385f424f1a1ce6998f0c15292f9a8605)
- **Validation evidence now follows the tested content**: passed validation runs record working-tree fingerprints and can be promoted to the review commit only when the committed tree matches the validated snapshot; agent-reported test results no longer authorize review eligibility. [4eec43af](https://github.com/aigentive/ralphx.app/commit/4eec43af72ffe4b8539981a2da97b4412e2317f3)
- **Validation and local tool failures are no longer labeled as generic agent crashes**: task history and failure metadata can now distinguish validation failures and local tool/MCP failures from real agent exits. [5fda210f](https://github.com/aigentive/ralphx.app/commit/5fda210f3ab5b933a1d04204f9f80bc35c0fb864)
- **PR mode protects the primary checkout from automatic commits**: task completion and freshness reconciliation skip auto-commits against the main project checkout, fail closed on unsafe path resolution, and still allow isolated task-worktree safety commits. [c8e51201](https://github.com/aigentive/ralphx.app/commit/c8e5120126839414e6945fe0cbf7088b1859d099)
