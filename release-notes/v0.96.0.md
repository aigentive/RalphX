# RalphX.app v0.96.0

This release expands RX-Native Team Mode with automatic assignment-completion wakes, coordinator status visibility, and stronger setup and exit safeguards.

## User-Facing Changes
- **Coordinator workflow:** Settled member assignments now produce durable system messages and automatically resume an idle coordinator with pending Team messages, removing the need for external polling or explicit check-ins. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- **Coordinator visibility:** `team_roster` and `team_status` expose member names, roles, status, and delegated-session liveness; status reads are bounded to 32 entries and tolerate missing sessions with a null agent state. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- **Team setup:** Adding a member whose provider is disabled now fails at roster admission with a Settings pointer, rather than deferring the failure until the first assignment. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- **Team-mode integrity:** Project conversations can no longer silently leave Team Mode during an ordinary send; leaving requires the explicit capability-change action. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)

## Fixes And Polish
- **Coordinator wake reliability:** Automatic wake capacity now recovers as batches complete instead of latching off after five successful wakes. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- **Wake delivery:** Coordinator resumes no longer repeat a settlement turn, and resumed input excludes member-targeted traffic and the coordinator’s own outbound messages. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)

## Developer And Maintainer Changes
- Updated and rebuilt MCP schemas, routing, policy, agent profiles, and coordinator prompts for the `team_roster` and `team_status` tool surface. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- Expanded focused Team IPC, delivery, and wake-dispatch coverage; needs-attention observability tests now assert the emitted production event rather than process-global tracing output. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)

## Known Issues
- Automatic member-targeted wakes are not yet implemented; members currently learn about assignments through coordinator broadcasts or roster reads. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
- A dedicated Team roster, status board, assignment controls, and inbox UI are not yet available. [001be358](https://github.com/aigentive/RalphX/commit/001be35890ef710d95071e46659cf053aaba27eb)
