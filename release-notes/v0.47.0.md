# RalphX.app v0.47.0

RalphX.app 0.47.0 focuses on workspace review, execution visibility, and provider/ticketing workflow reliability.

## User-Facing Changes

- **Workspace Review tab** surfaces reviewable agent workspace changes in the artifact pane, can lazy-start `ralphx-workspace-reviewer`, and now advances past `Preparing review…` when the review artifact arrives. [eb830e6f](https://github.com/aigentive/ralphx.app/commit/eb830e6f245f26af768d3218b57469117fe80a1e) [17b9123d](https://github.com/aigentive/ralphx.app/commit/17b9123d51cdcd3f26323851fffadb7ad6ee2628)
- **Execution controls in Agents view** now scope to the selected agent conversation’s project and surface workspace sessions, lane capacity, workspace concurrency settings, and terminal-session state from the execution bar. [af57d343](https://github.com/aigentive/ralphx.app/commit/af57d343d0bb34966daaf2d1c269c7fe19e54a67)
- **Provider settings** add opt-in custom CLI binaries per provider, with manual path entry or browse selection; custom mode disables RX-managed install and auto-update actions for that provider. [b00c9a59](https://github.com/aigentive/ralphx.app/commit/b00c9a59c94a7fc85286aca07ace8e898e60838a)
- **Ticketing workflows** improve large-project navigation with provider-backed assignee/sprint filter options, offset ticket pagination, truncation/failure warnings, and ClickUp custom task ID fallback lookups. [186840f7](https://github.com/aigentive/ralphx.app/commit/186840f73a9a067f9f02c9a43c047c74d4065cd5) [feba8dce](https://github.com/aigentive/ralphx.app/commit/feba8dceeb38dfafe27e418713b25b8f7ec181c3)
- **Publishing workflows** expand with a project PR template editor for `.github/PULL_REQUEST_TEMPLATE.md` and a repair-mode diff panel that replaces normal publish controls with conflicted-file plus staged/unstaged repair details. [123ab6ca](https://github.com/aigentive/ralphx.app/commit/123ab6cac1034456309cbd2ae7d7220ace09958b) [065b64f8](https://github.com/aigentive/ralphx.app/commit/065b64f8c2971e326253b9d4cddcc7193bf39403)

## Fixes And Polish

- **Runtime status strip** hides unhelpful single-workspace rows, marks the currently viewed chat as already open, and keeps task runtime-row navigation synchronized with the Tasks artifact pane. [207081df](https://github.com/aigentive/ralphx.app/commit/207081df9fe9534a91a720b938c5ef0870aaf1e4)
- **Composer and chat layout** now let the composer collapse back to its mini state on blur during generation while keeping Stop available, and keep bottom scrolling aligned when the runtime status widget changes composer height. [b21b0810](https://github.com/aigentive/ralphx.app/commit/b21b081068b402e9671b9185d5bb1e162339be55) [7ca9e20c](https://github.com/aigentive/ralphx.app/commit/7ca9e20c8bb722db9df92524969ba41889069bc3)
- **Project conversation lists** continue infinite-scroll pagination after refreshed rows preserve the same visible count. [c6b0e022](https://github.com/aigentive/ralphx.app/commit/c6b0e022f2358d9034ed908be7b0b932c5dc6646)
- **Task failure details** preserve worker-provided error messages and keep timeout classification limited to actual timeout failures. [19cf8a29](https://github.com/aigentive/ralphx.app/commit/19cf8a29b007544e4e2f860d9cb86a5496e31c36)

## Developer And Maintainer Changes

- **Workspace review infrastructure** adds review context/run endpoints, review-monitor persistence, artifact version tracking, and read-only workspace-review MCP tooling. [eb830e6f](https://github.com/aigentive/ralphx.app/commit/eb830e6f245f26af768d3218b57469117fe80a1e)
- **Auto-review diagnostics** add structured backend lifecycle and HTTP timing logs for context loading, target resolution, sidecar spawn/wait, artifact verification, blocked states, and completion handling. [1f240a65](https://github.com/aigentive/ralphx.app/commit/1f240a652a9f24bcb8277e45d60482ea9759f336)
