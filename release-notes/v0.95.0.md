# RalphX.app v0.95.0

RalphX.app 0.95.0 improves Agents inbox states, workspace reliability, and filesystem-tool feedback.

## User-Facing Changes
- **Agents inbox:** Recent, Stale, and Done now show tier-specific empty states; Recent can offer **New agent**, filtered results offer **Clear search**, and empty groups such as Working render as compact strips. [7ef80764](https://github.com/aigentive/RalphX/commit/7ef8076497ee01768c2e22981c568d4c40e3bb0e)
- **Workspace operation notifications:** Repair, publish, and base-update toasts now remain synchronized with the underlying operation outside the Publish panel, with dismissals retained across restarts and terminal results announced once per operation. [d79b65b3](https://github.com/aigentive/RalphX/commit/d79b65b348e88d075079c7edca291439f1bd5766)
- **Conversation workspaces:** When workspace data cannot load, editable workspaces now show an inline error with a retry action instead of silently hiding workspace tabs; selecting a conversation also keeps a responsive initial view while its authoritative state loads. [98bbe1d9](https://github.com/aigentive/RalphX/commit/98bbe1d9ff8d036ba6a25d59a15b05656bbe196f)
- **Filesystem tools:** Large-file reads now return the requested line window with an accurate `LINES: … of …` header, while grep, glob, and directory listings surface exclusions and caps as readable notes rather than mistaken paths. [012dd582](https://github.com/aigentive/RalphX/commit/012dd58225a23e1ac011773d399f448fefcefece)

## Fixes And Polish
- **Filesystem search results:** `fs_grep` now renders context lines and supports content, matching-file, and count output modes; grouped separators and diagnostics display cleanly in chat tool widgets. [012dd582](https://github.com/aigentive/RalphX/commit/012dd58225a23e1ac011773d399f448fefcefece)
- **Workspace-toast controls:** Operation-toast actions now use the shared notification-style CTA layout, with dismissible progress and result notifications. [d79b65b3](https://github.com/aigentive/RalphX/commit/d79b65b348e88d075079c7edca291439f1bd5766)

## Developer And Maintainer Changes
- **Workspace API resilience:** Repair hold-reason values now serialize with explicit wire values, and unknown presentation-only hold reasons degrade without rejecting an entire workspace response. [98bbe1d9](https://github.com/aigentive/RalphX/commit/98bbe1d9ff8d036ba6a25d59a15b05656bbe196f)
- **Visual regression coverage:** Agents inbox visual tests now cover populated, empty, filtered-empty, tier-specific, and narrow-sidebar states. [7ef80764](https://github.com/aigentive/RalphX/commit/7ef8076497ee01768c2e22981c568d4c40e3bb0e)
