# RalphX.app v0.33.1

RalphX.app 0.33.1 improves manual update-check feedback and fixes long agent workspace conversation pagination.

## User-Facing Changes
- Native manual update checks now show an immediate “Checking for updates...” toast, so the action no longer appears inert while the check is running. [eb8bb54c](https://github.com/aigentive/ralphx.app/commit/eb8bb54c52b90239a349b241117ce1652ec8fec3)
- Manual update checks now resurface an available update even if that same version was previously dismissed with “Later”. [eb8bb54c](https://github.com/aigentive/ralphx.app/commit/eb8bb54c52b90239a349b241117ce1652ec8fec3)
- Agent workspace conversations now continue loading older history past the previous three-page stop, allowing long threads to scroll back to the first message when older content exists. [a473c9dc](https://github.com/aigentive/ralphx.app/commit/a473c9dccab4e5e504eeec8b05202c88c6347377)

## Fixes And Polish
- Update-check toast state now transitions cleanly across loading, success, and error states using a shared manual-check result lifecycle. [eb8bb54c](https://github.com/aigentive/ralphx.app/commit/eb8bb54c52b90239a349b241117ce1652ec8fec3)

## Developer And Maintainer Changes
- Added regression coverage for the native menu/manual update-check path, including the loading toast and redisplay of a dismissed same-version update. [eb8bb54c](https://github.com/aigentive/ralphx.app/commit/eb8bb54c52b90239a349b241117ce1652ec8fec3)
- Added hook-level pagination coverage for conversation history and timeline windows, verifying fetches continue beyond three pages until the earliest offset or sequence is reachable. [a473c9dc](https://github.com/aigentive/ralphx.app/commit/a473c9dccab4e5e504eeec8b05202c88c6347377)
