# RalphX.app v0.85.0

Improves live chat recovery, automation reliability, and navigation across Settings and the inbox.

## User-Facing Changes
- **Settings** now groups 22 entries into seven themed sections, adds searchable navigation, and provides an Integrations hub showing connection status for GitHub, Linear, Atlassian, ClickUp, Granola, API keys, and external MCP. [34cb2763](https://github.com/aigentive/ralphx.app/commit/34cb2763bbd40b930aa7945f2809c47cd4704926)
- **Inbox navigation** now uses a single selected lane with live-count chips, lane-specific empty states, persistent selection, and arrow-key navigation. [d4fa67d8](https://github.com/aigentive/ralphx.app/commit/d4fa67d897172c63857bc5aaaa2ef713e54ea89e)
- **Live chat recovery** keeps transcript rows in order and preserves separate text blocks when returning to a conversation while an agent is still streaming. [d6c6b171](https://github.com/aigentive/ralphx.app/commit/d6c6b171e2cc01894bb86292cffed4137d057d83)
- **Automation reliability** improves when a process has finished but stale-run pruning races finalization: runs can be repaired and continued rather than remaining cancelled. [3a516d83](https://github.com/aigentive/ralphx.app/commit/3a516d8300f048275c956df29677a83b81405ed4)
- **Multi-agent coordination** now keeps task ledgers isolated per conversation and restores delegation for queued or error-recovered agent-workspace sessions. [c18b892b](https://github.com/aigentive/ralphx.app/commit/c18b892bda0feb445610d7940e7ff00b2e0cf773) [a0c4f316](https://github.com/aigentive/ralphx.app/commit/a0c4f316d99e4a57fc9cdd7f0b4bb450c3aa423c)

## Fixes And Polish
- **Automation Runs** now show a milestone timeline—for example, plan published, PR opened, and merged—with elapsed time, outcome summaries, and chain-mode context. [ee7e7731](https://github.com/aigentive/ralphx.app/commit/ee7e7731d76e52a364924e59b7327a1de9eab97b)
- **Workspace repair publishing** automatically recovers orphaned dispatches, interrupted validation, and blocked automatic repairs; manual repairs remain paused for user action. [52ba943b](https://github.com/aigentive/ralphx.app/commit/52ba943b90c3c2b0635c16e26cadc4fafa2d6981)
- **Agents sidebar** returns to its prior session-list position after reopening, while frontend error fallbacks now expose actionable details and record the failure for diagnostics. [32f715aa](https://github.com/aigentive/ralphx.app/commit/32f715aab8e3d0c2de304c1fcd290494001d15c0)
