# RalphX.app v0.20.0

RalphX.app 0.20.0 improves PR supervision and fixer behavior, repair-agent launch handling, and live workspace diff feedback.

## User-Facing Changes
- **PR supervision routes pending checks more accurately:** queued or in-progress required checks now keep supervision in monitoring mode instead of launching the PR fix flow as if the PR had a concrete merge blocker. [cceeeddf](https://github.com/aigentive/ralphx.app/commit/cceeeddf0075108ed51cbc6eea216511d76d81ef)
- **Merge-triggered fixer runs get richer PR context:** PR comments are now tracked as bounded supporting evidence, while GitHub check, review, and mergeability state remain authoritative; the fixer can read full comment bodies on demand when an excerpt is relevant. [81a6e65d](https://github.com/aigentive/ralphx.app/commit/81a6e65df081dd1b1d2055b9c17d0f778244ac45)
- **Embedded repair-agent flows execute the repair request correctly:** update-from-base and workspace-repair launches now route the live repair assignment directly to the repair agent instead of wrapping it as generic project-chat data. [6c724d32](https://github.com/aigentive/ralphx.app/commit/6c724d32752385b5e1ebbba9b46df4441ffbcd50)
- **Composer diff summaries update during active agent edits:** the workspace changes summary above the composer now refreshes while the agent is generating, without requiring the Commit & Publish pane to be opened first. [9410e60f](https://github.com/aigentive/ralphx.app/commit/9410e60f0fe636c8b6629533715ca27a002eddc1)

## Fixes And Polish
- **Commit & Publish diff labels are clearer for published workspaces:** branch diffs are no longer shown as `Uncommitted` when there are no staged or unstaged edits, and already-pushed work can surface as `Published changes`. [0e3364c8](https://github.com/aigentive/ralphx.app/commit/0e3364c893a4d67ac48603408815aadb8e36bbe4)
- **Terminal PR status takes precedence over stale blocked state:** conversations linked to merged or closed PRs now reflect the terminal outcome across publish and recovery surfaces instead of continuing to show blocked supervision metadata. [5b198091](https://github.com/aigentive/ralphx.app/commit/5b198091ed5306cf1eaad4052d3f644aec056bb9)
- **PR supervision toggles handle GitHub auto-merge failures more gracefully:** requested settings still persist, and the workspace can show a waiting state with an explanatory summary instead of failing the entire toggle action. [5ac1ba22](https://github.com/aigentive/ralphx.app/commit/5ac1ba22a00dac9403240a0fb637e21e89f1f511)

## Developer And Maintainer Changes
- Expanded regression coverage for PR blocker classification, supervision toggle failure paths, repair-agent prompt construction, repair launch planning, and PR comment evidence supervision paths. - Reworked PR supervision internals around shared auto-merge reconciliation, terminal-state persistence cleanup, and bounded PR comment evidence with stable metadata and explicit full-body retrieval.
