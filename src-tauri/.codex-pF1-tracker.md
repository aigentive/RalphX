## Constraints / proof obligations
- Credential is resolved host-side through `SecretStore` and never crosses the wire.
- Stop if a registered response can expose `*_secret_ref`, token, or equivalent.
- Real remote envelope: struct param `input` with `{id, requestId, cmd, args}`; success `{outcome:"ok",result}`; failure `{outcome:"commandError",error:<unwrapped command error>}`.
- Assert each command and payload separately; never whole tuples.
- Reads: `Read`, `caps: []`, response-secret absence proof per command.
- Writes: `AgentControl`; clients without `ui:agent` are denied.
- No invented memberships; no changes to the ticketing feature flag.
