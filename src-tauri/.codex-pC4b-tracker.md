# Wave C4b tracker

## Scope and invariants

- Extend C4a's snapshot-only remote twins; local commands keep their existing return values and TTLs.
- Remote absence remains `snapshot: null` with null capture metadata; it is not an empty diff and cannot trigger host inspection.
- File snapshot keys must include conversation, path, and ref scope/mode, and reads must validate the existing `agent_workspace_diff_cache_version`.
- Excluded: repair/conflict commands, startup background wiring, commits/pushes/installs, Vitest execution, and `cargo clean` (explicit owner override for this slice).

## Caller evidence and selected set

- `AgentsPublishInlineDiffs.tsx` calls the full workspace file diff, commit-scoped file diff, cumulative file diff, and paged file diff. `AgentsPublishPanel.tsx` also calls workspace and commit-scoped file diffs when a user selects a file in the Changes/commit surfaces.
- `PagedDiffView.tsx` calls the paged file diff directly for initial and subsequent ranges. The snapshot key therefore must include ref kind (and commit SHA), path, offset, and limit; the stored `FileDiffPage` already records `offset`, `limit`, `next_offset`, and `total_rows`, so an exact-range snapshot is sound and cannot masquerade as a complete diff.
- Selected minimum: `get_agent_conversation_workspace_file_diff`, `get_agent_conversation_workspace_commit_file_diff`, `get_agent_conversation_workspace_cumulative_file_diff`, and `get_agent_conversation_workspace_file_diff_page`, each exposed through a snapshot-only remote twin.
- `useGitDiff.ts` uses task-scoped APIs (`get_file_diff` / `get_commit_file_diff`), not the agent-workspace Changes surface, so no routing change is justified there.
- `SimpleDiffView.tsx` performs only lazy file-content-range reads. That command is outside the settled backend list and is not a file-diff command, so it will not be registered in C4b; its existing unavailable-operation behavior remains unchanged.
