# Wave B3a tracker

## Scope
- Add spawn-free `&AppState` queue list/delete seams and registered remote Project-conversation twins.
- Preserve local command paths; no intent rows, dispatchers, migrations, frontend changes, startup loop changes, commit, or push.

## Required invariants
- List fails closed on durable repository errors, merges durable before memory with durable ID precedence, and filters hidden/recovery messages.
- Delete performs durable deletion before memory deletion and returns the combined deletion result.
- Remote commands reject missing, archived, and non-Project conversations before touching queue state.
- List is `Read` with no capabilities; delete is authority-reducing `Operate` with no capabilities and an exact exemption.

## Adversarial review
- Read authority is the validated live Project conversation plus successful durable list; durable errors exit before memory can be returned as a false empty/success.
- Delete authority is the same validation; durable delete completes before the infallible in-memory delete, so a durable failure leaves memory untouched and cannot create restart resurrection.
- Missing/archived/non-Project refusals return before either queue store is mutated; tests assert retained memory rows for missing and archived cases.
- Hidden/recovery metadata is filtered only after durable-first ID merge, so neither durable nor memory-only internal turns can leak and durable collisions keep the canonical payload.
