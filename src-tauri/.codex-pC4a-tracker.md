# Wave C4a tracker

## Scope

- Audit and reclassify the pure hunk-annotation read.
- Add spawn-free snapshot-only remote reads for workspace change summary and review.
- Feed real nullable snapshot envelopes into the existing frontend Changes state.
- Wire registries/manifest/census and run only the requested gates (no Vitest, Cargo clean, commit, push, or install).

## Decisions

- Storage choice: a separate long-lived in-process snapshot cache on the existing `diff_commands` cache seam. This avoids a new migration/repository family for two derived projections and keeps host-local reads byte-identical. Tradeoff: a host restart deliberately empties the snapshot, so the remote envelope returns `snapshot: null`; unlike persistence, it cannot claim continuity across restart. Entries carry a wall-clock RFC3339 `captured_at`, their workspace cache version, and context-source provenance.
- Add a separate `remote_workspace_snapshot_ttl_ms` config key; do not change `workspace_review_cache_ttl_ms = 2000` or `workspace_pr_annotations_cache_ttl_ms = 30000`.
- Snapshot envelope must preserve absence (`snapshot: null`), capture time, cache version, and workspace-context fallback provenance.
- Local cache TTL keys remain byte-identical.

## Findings

- C3 precedent is `commands/remote_mcp_policy_commands.rs`: a separate repository-only remote command with nullable snapshot/capture metadata and explicit fail-closed decode/read errors.
- Remote facade rules require distinct functions/call graphs for populate versus snapshot-only reads and real transport envelope shapes in frontend tests.
- BLOCKER (measured): `RUST_MIN_STACK=8388608 cargo test --lib --features test-utils detector_c_floors_process_spawn_authority` rejects `get_agent_conversation_workspace_review_hunk_annotations` at detector C: the production call graph resolves a CLI binary. Per the slice instruction, its attempted Read/NONE override and registry row were removed rather than forced. The requested first independent win is therefore not valid against the live detector.
