## Decisions
- R8: remote requests carry `expected_version`; request validation checks the current resolved version and host dispatch re-proves it after claim. A mismatch settles with `REMOTE_PLAN_EDIT_VERSION_CONFLICT` and performs no write.
- Host-forced provenance: dispatcher calls the shared edit seam with `caller_session_id = None` and mutation authority absent, so a remote client cannot forge agent attribution or claim the verification-freeze exemption.
- Application remains independent of `commands` and `http_server`; the mutation-authority type and update seam live in `application`.
