- Worktree bucket reads need an explicit `unknown` state; a rejected query must not participate in auto-selection as an empty bucket.

- Commit history needs its own error state because `useGitDiff` currently clears failed history reads to `[]`.
- Missing repository capability is `notInspected`, distinct from a completed inspection that failed.
- The duplicated task/agent `ChangeReviewSection` files stay duplicated and receive identical behavior/tests.
- The repository PR toggle uses the existing affordance gate, keyed to `update_github_pr_enabled`; manifest absence makes it unavailable remotely while local remains enabled.
