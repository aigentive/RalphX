# Wave B5c Tracker

## Scope
- Add one durable, kind-discriminated remote conversation lifecycle intent table for archive and fork.
- Preserve local archive/fork behavior while remote commands persist spawn-reaching work for the startup dispatcher.
- Repoint the frontend remote gate branches to submit and poll the lifecycle request; local branches remain unchanged.

## Non-negotiable invariants
- Archive and fork twins are distinct functions from local spawn/recovery-reaching paths.
- Archive re-proves project/archive/PR-closure authority at claim time.
- Fork pre-allocates the child id at request time and never creates a second child on replay.
- Repository/infrastructure errors propagate and leave a claimed request for stale sweeping.
- Stale claimed archive/fork requests become `FailedStale` and are never retried because a half-run archive may already have deleted a worktree/branch and replaying fork can create a second worktree.
- Frontend tests use the real `{outcome:"commandError", error:<unwrapped>}` envelope.

## False-success terminal-write audit
- `Failed/NOT_FOUND` ← current claimed row + current conversation lookup returned absent; lookup errors propagate.
- `Failed/NOT_PROJECT` ← current claimed row + freshly loaded context type.
- `Completed/ALREADY_ARCHIVED` ← freshly loaded conversation has `archived_at`; archive seam is not called.
- `Failed/PR_CLOSURE_FORBIDDEN` ← current workspace mode re-read after claim; PR close and archive are absent.
- archive `Completed` ← archive production seam returned success; lifecycle completion repo errors propagate and leave Starting.
- archive seam error ← no terminal write; propagates and leaves Starting because repository-vs-host failure cannot be recovered after the legacy string conversion.
- `Failed/PARENT_NOT_FORKABLE` ← current running/process authority and current mode revalidated after claim; child remains absent.
- `Completed/CHILD_EXISTS` ← the exact preallocated child id is freshly found; fork seam/worktree creation is absent.
- fork `Completed` ← fork production seam returned the exact preallocated child; completion repo errors propagate.
- fork `Failed/HOST_FAILED` ← typed non-repository/non-infrastructure host refusal; database/infrastructure errors propagate without settlement.
- `FailedStale` ← Starting + claim timestamp older than cutoff; dispatcher only claims Pending, so stale rows never replay.
